# കേരള ജാതി / കമ്മ്യൂണിറ്റി സർട്ടിഫിക്കറ്റ് ഓൺലൈൻ അപേക്ഷ 2026

**ജാതി / കമ്മ്യൂണിറ്റി സർട്ടിഫിക്കറ്റ്** ഒരു ആളുടെ ജാതി / മതവിഭാഗം (SC, ST, OBC, OEC, Forward Community) ഔദ്യോഗികമായി സ്ഥിരീകരിക്കുന്ന സർക്കാർ രേഖയാണ്. കേരളത്തിൽ ഇത് **തഹ്‌സിൽദാർ** ഇഷ്യൂ ചെയ്യുന്നു.

---

## ജാതി സർട്ടിഫിക്കറ്റ് ആർക്കാണ് ആവശ്യം?

- SC/ST/OBC/OEC സ്‌കോളർഷിപ്പ് (ePASS) അപേക്ഷിക്കാൻ
- KEAM, PSC, UPSC, NIT/IIT – സംവരണ ആനുകൂല്യം
- കേരള യൂണിവേഴ്‌സിറ്റി / MG / കാലിക്കറ്റ് — ഫീസ് ഒഴിവ്
- ഭൂ ഏറ്റെടുക്കൽ / ഭൂ സർവേ ഒഴിവ്
- ഗ്രാമ / ബ്ലോക്ക് പഞ്ചായത്ത് ഇലക്ഷൻ — SC/ST സ്ഥാനാർഥിത്വം
- Central Govt ജോലി — Form 16 സംവരണം

---

## ഓൺലൈൻ അപേക്ഷ ഘട്ടങ്ങൾ

1. **[edistrict.kerala.gov.in](https://edistrict.kerala.gov.in)** സന്ദർശിക്കുക
2. **"Citizen Login"** → **"New Registration"** ക്ലിക്ക് ചെയ്ത് അക്കൗണ്ട് ഉണ്ടാക്കുക
3. **"Revenue"** → **"Community Certificate"** തിരഞ്ഞെടുക്കുക
4. വ്യക്തിഗത വിവരങ്ങൾ, ജാതി, തലമുറ ബന്ധം (hereditary details) ഫോം പൂരിപ്പിക്കുക
5. ആവശ്യമായ രേഖകൾ PDF / JPEG ൽ അപ്‌ലോഡ് ചെയ്യുക
6. **₹15 ഫീസ്** ഓൺലൈൻ അടയ്ക്കുക
7. **Acknowledgement Number** നോട്ട് ചെയ്ത് സൂക്ഷിക്കുക
8. തഹ്‌സിൽദാർ ഫീൽഡ് വെരിഫിക്കേഷൻ (15–30 ദിവസം) ശേഷം സർട്ടിഫിക്കറ്റ് ലഭ്യമാകും
9. **"Download Certificate"** ക്ലിക്ക് ചെയ്ത് ഡൗൺലോഡ് ചെയ്യുക

---

## ആവശ്യമായ രേഖകൾ

- ആധാർ കാർഡ്
- **പിതാവിന്റെ SSLC ബുക്ക്** (കമ്മ്യൂണിറ്റി കോളം — ഏറ്റവും പ്രധാനം)
- റേഷൻ കാർഡ്
- ഇലക്ട്രിസിറ്റി ബിൽ / വിലാസ തെളിവ്
- വില്ലേജ് ഓഫീസർ / പഞ്ചായത്ത് ക്ലിയറൻസ് (ആവശ്യമെങ്കിൽ)
- ജാതി ഹെഡ്‌ക്വാർട്ടർ / ക്ഷേത്ര / ചർച്ച് രേഖ (ആവശ്യമെങ്കിൽ)

| വിശദാംശം | വിവരം |
|----------|--------|

## ഓഫ്‌ലൈൻ ബദൽ

- **അക്ഷയ കേന്ദ്രം** വഴി അപേക്ഷ സമർപ്പിക്കാം
- **വില്ലേജ് ഓഫീസ്** / **തഹ്‌സിൽ ഓഫീസ്** ൽ നേരിടെ ഫോം ജമ ചെയ്യാം

---

## പതിവ് ചോദ്യങ്ങൾ

**SC/ST സർട്ടിഫിക്കറ്റ് കേരളത്തിൽ എത്ര കാലം ചെല്ലുബ്ദ്ടി?**
SC / ST ജാതി സർട്ടിഫിക്കറ്റ് ഒരിക്കൽ ഇഷ്യൂ ചെയ്‌താൽ **ജീവിതകാലം** ചെല്ലും. OBC (OEC) — ഇടയ്ക്കിടെ പുതുക്കൽ ആവശ്യം.

**പിതാവിന്റെ SSLC ബുക്ക് ഇല്ലെങ്കിൽ?**
ജനന / ബാപ്‌തിസം / ക്ഷേത്ര രേഖ, ജില്ലാ ഡൈരക്ടർ ഓഫ് കോളനൈസേഷൻ സ്ഥിരീകരണം, മറ്റ് ജനന / ആദ്യ കാലടി രേഖകൾ ബദൽ ആയി ഉപയോഗിക്കാം. ഈ ക്ഷേത്ര / ചർച്ച് രേഖ ഹാജരാക്കണം.

**OBC (OEC) സർട്ടിഫിക്കറ്റ് KEAM-ന് ആകുമോ?**
ആകും. കേരള ഗവൺമെന്റ് OEC (Other Eligible Communities) ലിസ്‌റ്റ് ഉണ്ട്. edistrict.kerala.gov.in ൽ ഇഷ്യൂ ചെയ്ത OEC / OBC സർട്ടിഫിക്കറ്റ് KEAM / PSC / LDF ആനുകൂല്യത്തിന് സ്വീകരിക്കും.
