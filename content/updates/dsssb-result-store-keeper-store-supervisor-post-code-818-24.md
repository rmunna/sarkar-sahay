## DSSSB Result 2026 — Store Keeper & Store Supervisor Post Code 818/24 Declared

The **Delhi Subordinate Services Selection Board (DSSSB)** has declared the result for **Combined Examination Post Code 818/24** for the posts of **Store Keeper and Store Supervisor** in Directorate General of Health Services (DGHGs). The result was published via **Result Notice No. 1596** on March 5, 2026.

Along with the result, DSSSB also published **Rejection Notice No. 1595** for the same post code, listing candidates whose applications were rejected.
