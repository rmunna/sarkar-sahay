BPSC 70th CCE Prelims answer key (final) has been released at [bpsc.bihar.gov.in](https://bpsc.bihar.gov.in). The Prelims paper had **150 questions** in Sets A, B, C, and D. The final answer key (post-objection review) was used to calculate the merit list for Mains shortlisting. General category cutoff was approximately **91 marks** (out of 150).

## How to Download BPSC 70th Answer Key

1. Go to [bpsc.bihar.gov.in](https://bpsc.bihar.gov.in)
2. Click **"Important Announcements"** or **"Answer Key"** section
3. Find the BPSC 70th CCE Prelims Answer Key
4. Download the PDF for your Set (A/B/C/D)
5. Match with your responses — note the question numbering corresponds to your set

## BPSC 70th Prelims — Exam Pattern

| Detail | Value |
|--------|-------|
| Total Questions | 150 |
| Total Marks | 150 |
| Duration | 2 hours (120 minutes) |
| Negative Marking | ¼ mark deducted per wrong answer |
| Sets | A, B, C, D |
| Subject | General Studies (combined) |

**Important:** BPSC Prelims has **negative marking** (0.25 marks per wrong answer). Blind guessing reduces your score. Attempt only questions you are reasonably sure about.

## BPSC 70th Prelims — Score Calculation

```
Score = (Correct × 1) − (Wrong × 0.25)
```

Example: 110 correct, 15 wrong:
```
Score = 110 − (15 × 0.25) = 110 − 3.75 = 106.25
```

**Q: Where can I find the BPSC 70th official answer key PDF?**
