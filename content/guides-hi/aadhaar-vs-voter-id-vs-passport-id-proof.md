# आधार vs वोटर ID vs पासपोर्ट — पूरी ID प्रूफ तुलना

भारत में कई सरकारी पहचान दस्तावेज़ जारी किए जाते हैं, लेकिन सबसे ज़्यादा इस्तेमाल होने वाले तीन हैं — [आधार कार्ड](/guide/aadhaar-card-apply-online), [वोटर ID (EPIC)](/guide/voter-id-card-apply-online), और [पासपोर्ट](/guide/passport-apply-online)। हर एक का मुख्य उद्देश्य अलग है लेकिन तीनों ID प्रूफ के रूप में स्वीकार किए जाते हैं। यह गाइड आपको समझाएगी कि कब कौन सा दस्तावेज़ इस्तेमाल करना चाहिए।

---

## त्वरित तुलना तालिका

| विशेषता | आधार कार्ड | वोटर ID (EPIC) | पासपोर्ट |
|---|---|---|---|
| **जारीकर्ता** | UIDAI | भारत निर्वाचन आयोग | विदेश मंत्रालय |
| **मुख्य उद्देश्य** | यूनिक पहचान + बायोमेट्रिक्स | मतदान अधिकार | अंतरराष्ट्रीय यात्रा |
| **यूनिक नंबर** | 12 अंकों का आधार नंबर | 10 अक्षरों का EPIC नंबर | पासपोर्ट नंबर |
| **बायोमेट्रिक डेटा** | हाँ (फिंगरप्रिंट + आइरिस) | नहीं (केवल फोटो) | नहीं (फोटो + हस्ताक्षर) |
| **उम्र सीमा** | कोई नहीं (शिशु भी) | 18+ वर्ष | कोई नहीं |
| **पता प्रमाण** | हाँ | हाँ | हाँ |
| **ID प्रूफ** | हाँ | हाँ | हाँ (सबसे मज़बूत) |
| **वैधता** | आजीवन | आजीवन | 10 वर्ष (वयस्क), 5 वर्ष (नाबालिग) |
| **ऑनलाइन वेरिफिकेशन** | हाँ (e-KYC, QR कोड) | हाँ (NVSP पोर्टल) | सीमित |
| **शुल्क** | मुफ्त (पहला एनरोलमेंट) | मुफ्त | ₹1,500 (सामान्य), ₹3,500 (तत्काल) |
| **प्रोसेसिंग समय** | 15–90 दिन | 15–30 दिन | 7–30 दिन |
| **बैंकिंग में स्वीकार** | हाँ (अधिकांश में अनिवार्य) | हाँ | हाँ |
| **SIM कार्ड के लिए** | हाँ (e-KYC इंस्टेंट) | हाँ | हाँ |
| **मतदान के लिए** | नहीं (अकेला पर्याप्त नहीं) | हाँ (प्राथमिक दस्तावेज़) | हाँ (वैकल्पिक) |
| **अंतरराष्ट्रीय यात्रा** | नहीं | नहीं | हाँ (प्राथमिक) |
| **डिजिटल वर्ज़न** | e-आधार, mAadhaar | e-EPIC | DigiLocker |

## मुख्य अंतर

### 1. प्राथमिक उद्देश्य

- **आधार** बायोमेट्रिक्स से जुड़ा यूनिवर्सल आइडेंटिटी नंबर है। इसे सरकारी सेवा वितरण और सब्सिडी ट्रांसफर (DBT) के लिए बनाया गया है। यह नागरिकता का प्रमाण नहीं है।
- **वोटर ID** भारतीय चुनावों में आपके मतदान अधिकार को स्थापित करता है। यह आपके निर्वाचन क्षेत्र से जुड़ा होता है।
- **पासपोर्ट** अंतरराष्ट्रीय यात्रा के लिए आपका पहचान दस्तावेज़ है। कड़ी जाँच के कारण यह घरेलू उपयोग में भी सबसे मज़बूत ID प्रूफ माना जाता है।

### 2. ID प्रूफ के रूप में स्वीकार्यता

**आधार** भारत में सबसे ज़्यादा स्वीकार किया जाने वाला ID प्रूफ है। यह अनिवार्य है:
- बैंक खाता खोलने (KYC) के लिए
- PAN कार्ड लिंकिंग के लिए
- मोबाइल SIM एक्टिवेशन (e-KYC) के लिए
- सरकारी योजना नामांकन के लिए
- [इनकम टैक्स फाइलिंग](/guide/old-tax-regime-vs-new-tax-regime) के लिए

**वोटर ID** अधिकांश जगहों पर ID प्रूफ के रूप में स्वीकार किया जाता है, मुख्य रूप से:
- चुनावों में मतदान के लिए
- कुछ राज्यों में प्रॉपर्टी रजिस्ट्रेशन के लिए
- सरकारी नौकरी आवेदन के लिए

**पासपोर्ट** सबसे मज़बूत ID प्रूफ माना जाता है:
- अंतरराष्ट्रीय यात्रा के लिए
- वीज़ा आवेदन के लिए
- विदेश में रोज़गार के लिए
- उच्च-मूल्य वित्तीय लेनदेन के लिए

### 3. पता प्रमाण की ताकत

| दस्तावेज़ | पता प्रमाण स्वीकार्यता | अपडेट में आसानी |
|---|---|---|
| आधार | सर्वत्र स्वीकार | आसान ([ऑनलाइन अपडेट उपलब्ध](/guide/aadhaar-address-change-online)) |
| वोटर ID | व्यापक रूप से स्वीकार | मध्यम ([ऑनलाइन सुधार उपलब्ध](/guide/voter-id-correction-online)) |
| पासपोर्ट | सबसे मज़बूत स्वीकार्यता | कठिन ([री-इश्यू ज़रूरी](/guide/passport-address-change-online)) |

### 4. वेरिफिकेशन और सुरक्षा

**आधार** में सबसे मज़बूत वेरिफिकेशन है — बायोमेट्रिक ऑथेंटिकेशन (फिंगरप्रिंट/आइरिस) इसे जालसाज़ी करना लगभग असंभव बनाता है।

**वोटर ID** में मध्यम सुरक्षा है — होलोग्राम के साथ फोटो ID, लेकिन कोई बायोमेट्रिक वेरिफिकेशन नहीं।

**पासपोर्ट** में उच्च सुरक्षा है — पुलिस वेरिफिकेशन सहित कई जाँच स्तर और अंतरराष्ट्रीय मान्यता।

### 5. नागरिकता स्थिति

| दस्तावेज़ | नागरिकता साबित करता है? |
|---|---|
| आधार | नहीं (केवल पहचान/निवास) |
| वोटर ID | हाँ (केवल नागरिक मतदाता सूची में हो सकते हैं) |
| पासपोर्ट | हाँ (केवल भारतीय नागरिकों को जारी) |

## कब कौन सा दस्तावेज़ इस्तेमाल करें

### आधार का उपयोग करें:
- बैंक KYC और खाता खोलने के लिए
- मोबाइल SIM कार्ड एक्टिवेशन के लिए
- सरकारी योजना नामांकन (PM-KISAN, आयुष्मान भारत आदि) के लिए
- [PAN-आधार लिंकिंग](/guide/aadhaar-pan-link) के लिए
- इनकम टैक्स फाइलिंग के लिए
- [e-श्रम रजिस्ट्रेशन](/guide/e-shram-card-registration) के लिए

### वोटर ID का उपयोग करें:
- चुनावों में मतदान (ज़रूरी) के लिए
- जहाँ आधार स्वीकार नहीं है वहाँ ID प्रूफ के लिए
- प्रॉपर्टी रजिस्ट्रेशन के लिए
- बैकअप ID के रूप में

### पासपोर्ट का उपयोग करें:
- अंतरराष्ट्रीय यात्रा (अनिवार्य) के लिए
- वीज़ा आवेदन के लिए
- नागरिकता प्रमाण के लिए
- उच्च-सुरक्षा ID वेरिफिकेशन के लिए

---

## कौन सा ID प्रूफ पहले बनवाएं?

### हर भारतीय नागरिक के लिए प्राथमिकता क्रम:

1. **आधार कार्ड** — सबसे पहले बनवाएं (अधिकांश सेवाओं के लिए अनिवार्य)
2. **वोटर ID** — 18 साल होने पर बनवाएं (मतदान के लिए ज़रूरी)
3. **पासपोर्ट** — यात्रा या मज़बूत ID प्रूफ की ज़रूरत होने पर बनवाएं

---

## अक्सर पूछे जाने वाले प्रश्न

### क्या आधार मतदान केंद्र पर वोटर ID की जगह इस्तेमाल हो सकता है?
आधार मतदान केंद्र पर 12 स्वीकृत ID दस्तावेज़ों में से एक है, लेकिन आपका मतदाता सूची में पंजीकृत होना ज़रूरी है। वोटर ID रखना सबसे आसान तरीका है।

### क्या आधार नागरिकता का प्रमाण है?
नहीं। आधार पहचान और निवास का प्रमाण है, नागरिकता का नहीं। UIDAI ने यह कई बार स्पष्ट किया है।

### भारत में सबसे मज़बूत ID प्रूफ कौन सा है?
पासपोर्ट को आम तौर पर सबसे मज़बूत ID प्रूफ माना जाता है क्योंकि इसमें पुलिस वेरिफिकेशन सहित कड़ी जाँच होती है।

### क्या वोटर ID बैंक KYC के लिए चलता है?
हाँ। वोटर ID बैंक KYC के लिए आधिकारिक रूप से वैध दस्तावेज़ (OVD) है। हालाँकि, अधिकांश बैंक इंस्टेंट e-KYC के लिए आधार पसंद करते हैं।

### क्या मुझे तीनों दस्तावेज़ चाहिए?
कानूनी रूप से तीनों रखना अनिवार्य नहीं है, लेकिन अत्यधिक अनुशंसित है। प्रत्येक का एक अनूठा उद्देश्य है।
