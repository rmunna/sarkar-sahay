# DigiLocker से APAAR ID डाउनलोड करें

**त्वरित उत्तर:** APAAR ID generate होने के बाद छात्र के DigiLocker account में **Issued Documents** section खोलें। Search box में **APAAR**, **Academic Bank of Credits** या **ABC** search करें। अगर card नहीं दिख रहा, तो पहले school/college से confirm करें कि APAAR generate हो चुका है या नहीं।

> **7 जून 2026 को सत्यापित:** आधिकारिक APAAR portal बताता है कि generated APAAR ID student के DigiLocker account में push होती है। ABC portal learner flow में DigiLocker से APAAR card access/download करने का विकल्प दिखाता है।

## Download करने से पहले यह check करें

- APAAR ID generate हो चुकी है
- DigiLocker account student का ही है
- Aadhaar KYC details student record से match कर रही हैं
- School ने UDISE/PEN verification पूरा किया है
- College learner के लिए ABC portal पर institution, admission year और roll/enrolment details match हुई हैं
- Mobile number और OTP access student/parent के पास है

अगर APAAR सिर्फ request हुआ है और generate नहीं हुआ, तो DigiLocker में download करने के लिए document नहीं होगा।

## DigiLocker से APAAR Card download steps

1. [DigiLocker](https://www.digilocker.gov.in/) website खोलें या DigiLocker app open करें।
2. Student account से login करें।
3. **Issued Documents** section खोलें।
4. Search में **APAAR** लिखें।
5. Result न मिले तो **Academic Bank of Credits** या **ABC** search करें।
6. APAAR card/document दिखे तो open करें।
7. Download/share option का उपयोग school, college, admission, exam या scholarship portal की जरूरत के अनुसार करें।

Screenshot upload करने के बजाय official DigiLocker document/share option use करना safer है, क्योंकि कुछ portals screenshot accept नहीं करते।

## अगर APAAR ID नहीं मिल रही

| स्थिति | क्या करें |
|---|---|
| School student | School से UDISE+ APAAR module में status check करवाएं |
| College student | ABC portal में DigiLocker login से request/status check करें |
| Wrong DigiLocker account | Student का सही DigiLocker account use करें |
| Name mismatch | Aadhaar, school या institution record correction करवाएं |
| Institution not found | Academic/exam section से institution mapping पूछें |
| Recent generation | School/ABC से generation confirm करके बाद में recheck करें |

Detailed fix: [APAAR ID DigiLocker में नहीं दिख रहा](/hi/guide/apaar-id-not-showing-digilocker-fix).

## School students के लिए download flow

School student के मामले में download school-side generation पर depend करता है:

1. Parent consent voluntarily submit होता है।
2. School student details verify करता है।
3. UDISE system PEN ID के against APAAR generate करता है।
4. APAAR student DigiLocker में push होती है।
5. Student/parent Issued Documents में card check करते हैं।

अगर school ने verification या generation पूरा नहीं किया है, तो DigiLocker में card नहीं दिखेगा। इस case में DigiLocker password बदलने या नया account बनाने से problem solve नहीं होगी।

## College / ABC learners के लिए download flow

Higher education और skill learners के लिए:

1. [abc.gov.in](https://www.abc.gov.in/) खोलें।
2. Student login/register चुनें।
3. DigiLocker से authenticate करें।
4. Institution, admission year और roll/enrolment number भरें।
5. Request submit करें।
6. Matching successful होने पर APAAR card DigiLocker में access/download करें।

Step-by-step guide: [DigiLocker से APAAR ID कैसे बनाएं](/hi/guide/apaar-id-create-digilocker).

## Download करते समय privacy सावधानी

- DigiLocker password किसी को न बताएं।
- OTP school group, agent या unknown caller को न दें।
- Aadhaar screenshot unofficial site पर upload न करें।
- Paid "urgent APAAR download" service से बचें।
- Duplicate DigiLocker accounts न बनाएं।
- सिर्फ official APAAR, ABC, DigiLocker, school या institution route use करें।

APAAR academic identity है, इसलिए गलत site पर details देने से privacy risk और wrong record mapping दोनों हो सकते हैं।

## Form में APAAR number चाहिए तो क्या करें?

अगर school, college, exam, admission या scholarship form APAAR/ABC learner ID मांगता है:

- APAAR number official DigiLocker/ABC record से copy करें
- Aadhaar number को APAAR number की जगह न भरें
- Screenshot की जगह official document/PDF use करें, अगर upload मांगा गया है
- Name, DOB और institution details form submit करने से पहले match करें

अगर deadline close है और APAAR नहीं दिख रहा, तो school/college से written clarification या alternative instruction पूछें। Guess करके wrong number submit न करें।

## कब school/college से संपर्क करें?

School या institution से contact करें अगर:

- School कह रहा है APAAR generated है लेकिन DigiLocker खाली है
- Name, DOB या parent name गलत दिख रहा है
- PEN ID missing है
- ABC portal institution नहीं ढूंढ पा रहा
- Roll/enrolment number reject हो रहा है
- Admission/exam form की last date पास है

उनसे यह साफ पूछें कि issue generation का है, mapping का है, mismatch का है या DigiLocker sync का।

## FAQs

### क्या APAAR website से direct download कर सकते हैं?
Official APAAR portal के अनुसार generated APAAR ID DigiLocker में push होती है। Card access के लिए DigiLocker Issued Documents check करें।

### APAAR Issued Documents में क्यों नहीं दिख रही?
APAAR अभी generate नहीं हुई हो सकती, wrong DigiLocker account use हो सकता है, या Aadhaar/school/institution records में mismatch हो सकता है।

### क्या parent अपने DigiLocker से child की APAAR download कर सकते हैं?
School instruction follow करें। General rule यह है कि APAAR student record से linked होती है, इसलिए student account/official school process use करें।

### क्या APAAR card screenshot enough है?
जहां possible हो, official DigiLocker document/download/share option use करें। Screenshot कुछ portals reject कर सकते हैं।

### क्या APAAR download के लिए पैसे लगते हैं?
Official APAAR, ABC और DigiLocker routes use करें। Paid agent या unofficial download form से बचें।
