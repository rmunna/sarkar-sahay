# दिल्ली राशन कार्ड और e-Coupon

## e-Coupon सिस्टम क्या है?
दिल्ली सरकार की डिजिटल पहल जहां लाभार्थियों को फिज़िकल राशन कार्ड के बजाय इलेक्ट्रॉनिक कूपन मिलते हैं। पारदर्शिता बढ़ती है और धोखाधड़ी कम होती है।

## पात्रता
- दिल्ली का निवासी
- NFSA मानदंड पूरे करता हो
- आधार कार्ड अनिवार्य

## ऑनलाइन आवेदन
1. [nfs.delhi.gov.in](https://nfs.delhi.gov.in) या [edistrict.delhigovt.nic.in](https://edistrict.delhigovt.nic.in) पर जाएं
2. रजिस्टर/लॉगिन करें
3. "Apply for New Ration Card" चुनें
4. परिवार विवरण, आय, पता भरें
5. दस्तावेज़ अपलोड करें (आधार, फोटो, पता प्रमाण)
6. सबमिट → Application ID नोट करें

## e-Coupon कैसे प्राप्त करें
- राशन कार्ड स्वीकृत होने के बाद e-Coupon SMS/ऑनलाइन मिलता है
- FPS पर e-Coupon नंबर और आधार बायोमेट्रिक से राशन लें

## स्टेटस चेक
nfs.delhi.gov.in → "Check Status" → Application ID
