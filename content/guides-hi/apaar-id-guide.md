# APAAR ID क्या है - One Nation One Student ID

**त्वरित उत्तर:** APAAR ID का पूरा नाम **Automated Permanent Academic Account Registry** है। यह भारत सरकार की **One Nation, One Student ID** पहल के तहत छात्र की शैक्षणिक पहचान है। APAAR ID से छात्र के शैक्षणिक रिकॉर्ड, क्रेडिट, मार्कशीट, सर्टिफिकेट और उपलब्धियों को DigiLocker और Academic Bank of Credits (ABC) ecosystem से जोड़ा जा सकता है।

> **7 जून 2026 को सत्यापित:** आधिकारिक APAAR पोर्टल के अनुसार स्कूल छात्रों के लिए अभिभावक consent, स्कूल verification, PEN ID/UDISE प्रक्रिया और DigiLocker push शामिल है। ABC पोर्टल के अनुसार APAAR ID ABC credit system से जुड़ी learner identity है।

## APAAR ID किसके लिए है?

- स्कूल छात्र
- कॉलेज और विश्वविद्यालय छात्र
- स्किल/व्यावसायिक शिक्षा learner
- ऐसे छात्र जिन्हें admission, exam, credit transfer या academic record के लिए learner ID चाहिए

स्कूल छात्रों के लिए प्रक्रिया स्कूल/UDISE+ के माध्यम से होती है। कॉलेज या skill learners ABC portal और DigiLocker login से APAAR/learner ID बना सकते हैं, अगर institution details उपलब्ध हों।

## APAAR, ABC और DigiLocker में अंतर

| शब्द | मतलब |
|---|---|
| APAAR ID | छात्र की academic identity |
| ABC | Academic Bank of Credits, credit records का platform |
| DigiLocker | digital document wallet, जहां APAAR card दिख सकता है |
| PEN ID | school record identifier, जिसे स्कूल/UDISE में इस्तेमाल किया जाता है |

पूरी तुलना: [APAAR vs ABC ID vs DigiLocker](/guide/apaar-vs-abc-id-digilocker-difference).

## स्कूल छात्रों के लिए APAAR प्रक्रिया

आधिकारिक APAAR portal पर school flow यह बताया गया है:

1. School parents को APAAR के बारे में बताता है।
2. Parent consent voluntarily submit किया जाता है।
3. School student details verify करता है।
4. UDISE system student के PEN ID के against APAAR ID generate करता है।
5. APAAR ID student के DigiLocker account में push होती है।

विस्तार से पढ़ें: [School students के लिए APAAR ID](/hi/guide/apaar-id-school-students-parent-consent).

## College / ABC / DigiLocker route

Higher education और skill learners के लिए ABC portal पर DigiLocker based flow है:

1. [abc.gov.in](https://www.abc.gov.in/) खोलें।
2. Student login/register चुनें।
3. DigiLocker से authenticate करें।
4. Education category चुनें।
5. Institution, admission year और roll/enrolment number भरें।
6. Request submit करें।
7. Matching successful होने पर APAAR card DigiLocker से access/download करें।

विस्तार से पढ़ें: [DigiLocker से APAAR ID कैसे बनाएं](/hi/guide/apaar-id-create-digilocker).

## APAAR ID के लिए जरूरी बातें

आधिकारिक APAAR FAQ के अनुसार:

- UDISE+ student record में name Aadhaar के name से match होना चाहिए।
- PEN ID school APAAR generation के लिए जरूरी है।
- Student name, DOB, gender, mobile number, mother name, father name, Aadhaar number/name जैसे details required हो सकते हैं।

अगर नाम mismatch है, तो पहले पता करें गलती Aadhaar में है, school record में है, या institution record में।

## APAAR ID कहां दिखेगी?

Generated APAAR ID DigiLocker में दिख सकती है:

1. [DigiLocker](https://www.digilocker.gov.in/) login करें।
2. **Issued Documents** खोलें।
3. APAAR या Academic Bank of Credits search करें।
4. APAAR card/document दिखे तो download/share करें।

अगर नहीं दिख रहा: [APAAR ID DigiLocker में नहीं दिख रहा - fix](/hi/guide/apaar-id-not-showing-digilocker-fix).

## Scam और privacy सावधानी

- OTP किसी को न बताएं।
- APAAR जल्दी बनवाने के नाम पर payment न करें।
- Aadhaar screenshot unofficial website पर upload न करें।
- केवल official APAAR, ABC, DigiLocker, school या institution route use करें।
- CitizenNest APAAR ID issue नहीं करता; हम सिर्फ guide देते हैं।

## किस स्थिति में क्या करें?

| स्थिति | सही अगला कदम |
|---|---|
| School ने consent मांगा है | details verify करके consent दें |
| School कहता है PEN missing है | school से UDISE/PEN record check करवाएं |
| College form ABC ID मांग रहा है | ABC portal/DigiLocker से learner ID देखें |
| APAAR DigiLocker में नहीं दिख रहा | school/ABC status और सही DigiLocker account check करें |
| नाम गलत है | Aadhaar, school या college record में गलती पहचानें |
| Institution list में नहीं है | academic/exam section से पूछें |

## APAAR बनवाते समय क्या न करें

- Aadhaar OTP school group या agent को न भेजें।
- Google search में दिख रहे unofficial APAAR forms पर details न डालें।
- गलत school/college select करके request submit न करें।
- अगर form में APAAR ID मांगा है तो Aadhaar number न भरें।
- Parent account और student account को confuse न करें।

## Authority checklist

Student या parent को final submission से पहले यह check करना चाहिए:

- Name Aadhaar और school/college record में same है
- DOB और gender सही हैं
- Parent names सही हैं
- School student के लिए PEN ID available है
- College student के लिए roll/enrolment number exact है
- DigiLocker account student का है
- APAAR/ABC number official portal से लिया गया है

## FAQs

### APAAR ID क्या Aadhaar जैसा है?
नहीं। Aadhaar identity document है। APAAR student academic identity है।

### APAAR ID और ABC ID एक ही हैं?
ABC ecosystem में learner identity के रूप में APAAR ID इस्तेमाल होती है। कई लोग अभी भी इसे ABC ID कहते हैं।

### क्या parent खुद APAAR बना सकते हैं?
School student के लिए process school-led है। Parents consent और details verification में school के साथ coordinate करते हैं।

### APAAR ID कहां download होगी?
Generated APAAR ID DigiLocker Issued Documents में दिख सकती है।

### APAAR ID mandatory है?
हर छात्र के लिए blanket statement न मानें। School, college, admission या exam portal के current instruction को follow करें।

### APAAR ID बनवाने के लिए पैसे लगते हैं?
Official APAAR/ABC portals पर student fee का दावा नहीं दिखता। Paid agents से बचें।
