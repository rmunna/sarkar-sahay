# वोटर ID आवेदन स्टेटस ऑनलाइन कैसे चेक करें

वोटर ID (EPIC — Electoral Photo Identity Card) के लिए आवेदन करने के बाद स्टेटस ट्रैक करना ज़रूरी है। NVSP पोर्टल और Voter Helpline ऐप से आसानी से चेक कर सकते हैं।

---

## विधि 1: NVSP पोर्टल से

1. [voters.eci.gov.in](https://voters.eci.gov.in) पर जाएँ
2. लॉगिन करें (मोबाइल/ईमेल + OTP)
3. **"Track Application"** पर क्लिक करें
4. **Reference ID** दर्ज करें (आवेदन की पावती में मिला था)
5. **"Track Status"** पर क्लिक करें
6. वर्तमान स्थिति दिखेगी

### स्टेटस के अर्थ

| स्टेटस | मतलब |
|--------|-------|
| **Submitted** | आवेदन जमा हो गया |
| **Under Verification** | BLO/ERO सत्यापन चल रहा |
| **Approved** | आवेदन स्वीकृत |
| **Printed** | कार्ड छप गया |
| **Dispatched** | भेज दिया गया |
| **Rejected** | अस्वीकृत (कारण दिखेगा) |

---

## विधि 2: Voter Helpline ऐप

1. **Voter Helpline** ऐप डाउनलोड करें (Google Play / App Store)
2. मोबाइल नंबर से रजिस्ट्रेशन करें
3. **"Track Application"** चुनें
4. Reference ID दर्ज करें
5. स्टेटस दिखेगा

---

## विधि 3: SMS से

**EPIC <Space> <Voter ID Number>** → **1950** पर SMS भेजें

---

## e-EPIC (डिजिटल वोटर ID) डाउनलोड करें

1. [voters.eci.gov.in](https://voters.eci.gov.in) पर लॉगिन करें
2. **"Download e-EPIC"** पर क्लिक करें
3. **आधार या मोबाइल OTP** से सत्यापित करें
4. e-EPIC PDF डाउनलोड हो जाएगा

> **e-EPIC** डिजिटल रूप में मान्य है — DigiLocker में भी उपलब्ध है।

---

## वोटर ID में सुधार कैसे करें

1. [voters.eci.gov.in](https://voters.eci.gov.in) पर लॉगिन करें
2. **"Correction in Voter ID"** या **Form 8** चुनें
3. जो विवरण सुधारना है वो चुनें (नाम, पता, फ़ोटो, जन्मतिथि)
4. दस्तावेज़ अपलोड करें
5. सबमिट करें — BLO सत्यापन के बाद सुधार होगा
