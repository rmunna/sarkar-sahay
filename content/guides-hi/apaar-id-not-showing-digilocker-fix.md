# APAAR ID DigiLocker में नहीं दिख रहा? Fix

**त्वरित उत्तर:** अगर APAAR ID DigiLocker में नहीं दिख रहा, तो पहले confirm करें कि APAAR ID generate हुआ है या नहीं। School student के लिए school से UDISE+ APAAR module status पूछें। College learner के लिए ABC portal/DigiLocker request check करें। फिर सही DigiLocker account, Aadhaar/name match और institution mapping verify करें।

> **7 जून 2026 को सत्यापित:** आधिकारिक APAAR FAQ के अनुसार generated APAAR ID student के DigiLocker account में push होता है और school authority UDISE+ APAAR module में status check कर सकती है।

## सबसे पहले status confirm करें

| Student type | Status कैसे check करें |
|---|---|
| School student | School office/class teacher से UDISE+ APAAR module check करवाएं |
| College student | ABC portal पर DigiLocker login करके request/status देखें |
| Skill learner | Institution और ABC/DigiLocker mapping check करें |

अगर ID generate ही नहीं हुआ, तो DigiLocker में card नहीं दिखेगा।

## Fix 1: Issued Documents सही जगह देखें

1. [DigiLocker](https://www.digilocker.gov.in/) login करें।
2. **Issued Documents** खोलें।
3. APAAR search करें।
4. Academic Bank of Credits भी search करें।
5. Education related documents में card देखें।

Uploaded Documents में खोजने से APAAR card नहीं मिलेगा, क्योंकि यह issued document के रूप में आना चाहिए।

## Fix 2: सही DigiLocker account use करें

APAAR student के DigiLocker account में push हो सकता है। Parent या sibling account में login करने पर card नहीं दिखेगा।

Check करें:

- Account student के Aadhaar से linked है या नहीं
- Mobile number सही है या नहीं
- DigiLocker profile name Aadhaar/student record से match है या नहीं

## Fix 3: School से UDISE/PEN status पूछें

School student के लिए school से पूछें:

- Parent consent submit हुआ?
- Student details verify हुए?
- PEN ID available है?
- APAAR ID generate हुआ?
- Aadhaar/name mismatch आया?

PEN ID missing या UDISE record issue होने पर school action जरूरी हो सकता है।

## Fix 4: Name mismatch check करें

Official APAAR FAQ कहता है कि UDISE+ student name Aadhaar name से match होना चाहिए। Common mismatch:

- spelling अलग
- initials vs full name
- DOB अलग
- parent name अलग
- Aadhaar और school record अलग

Detailed guide: [APAAR Aadhaar name mismatch fix](/guide/apaar-id-aadhaar-name-mismatch-fix).

## Fix 5: College students ABC mapping check करें

अगर आपने ABC portal से request किया:

1. [abc.gov.in](https://www.abc.gov.in/) खोलें।
2. Student login करें।
3. DigiLocker से authenticate करें।
4. Institution, admission year और roll number check करें।
5. mismatch हो तो college academic/exam section से संपर्क करें।

## Fast Diagnosis Table

| Situation | Next Step |
|---|---|
| School says consent pending | Parent consent complete करें |
| School says PEN missing | School से UDISE/PEN update पूछें |
| School says APAAR generated | Correct DigiLocker account check करें |
| Institution not listed | College academic section से पूछें |
| Name mismatch | Aadhaar/school/institution record correct करें |
| Credits missing | ABC/NAD upload के लिए institution से पूछें |

## क्या न करें

- OTP share न करें।
- Paid agents से APAAR generate/download न करवाएं।
- Unofficial websites पर Aadhaar upload न करें।
- गलत institution select न करें।
- बार-बार नए DigiLocker accounts न बनाएं।

## Support को क्या बताएं?

School, college या official support को लिखते समय ये details दें:

- Student name
- Class/course
- School/college name
- PEN ID या roll/enrolment number, अगर available है
- Consent submitted हुआ या नहीं
- Error screenshot, OTP/password छिपाकर
- DigiLocker में APAAR search करने पर क्या दिखता है

Sensitive data जैसे OTP, password, पूरा Aadhaar screenshot या DigiLocker PIN share न करें।

## कब wait करें और कब follow-up करें?

अगर school ने कहा है कि verification pending है, तो पहले school process complete होने दें। अगर school कह रहा है कि APAAR generate हो चुका है लेकिन DigiLocker में नहीं दिख रहा, तो correct DigiLocker account और name match check करें। College students के लिए अगर ABC portal record नहीं ढूंढ पा रहा, तो wait करने से पहले institution mapping confirm करना बेहतर है।

## Parent और student के लिए quick checklist

- DigiLocker account student का है
- Aadhaar-linked mobile active है
- School record और Aadhaar name same हैं
- School ने consent और verification complete किया है
- PEN ID available है
- College student के लिए roll/enrolment number exact है
- APAAR search के साथ Academic Bank of Credits भी search किया है
- Issue screenshot सुरक्षित रखा है

अगर इस checklist में कोई भी item missing है, तो उसी जगह से fix शुरू करें। इससे बिना वजह DigiLocker support पर ticket डालने से बचेंगे।

## FAQs

### क्या मैं खुद APAAR status check कर सकता हूं?
DigiLocker और ABC login check कर सकते हैं। School UDISE+ APAAR module status के लिए school authority से पूछना पड़ेगा।

### APAAR कब दिखेगा?
Official public fixed timeline नहीं है। Consent, verification, generation और sync complete होने पर दिख सकता है।

### क्या नया DigiLocker account बनाना चाहिए?
आम तौर पर नहीं। पहले सही student account, Aadhaar KYC और school/institution status confirm करें।

### DigiLocker support को क्या भेजें?
Student name, institution, screenshot और issue बताएं। OTP/password/Aadhaar sensitive details न भेजें।

### क्या APAAR missing होने से admission रुक जाएगा?
यह institution या form के rules पर निर्भर करता है। अगर deadline नजदीक है, तो school/college से written guidance लें और issue screenshot संभालकर रखें।
