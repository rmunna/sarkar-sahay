# DigiLocker से APAAR ID कैसे बनाएं

**त्वरित उत्तर:** College, university और skill learners official ABC portal से Student login/register चुनकर DigiLocker से authenticate कर सकते हैं। फिर education category, institution, admission year और roll/enrolment number भरकर request submit करते हैं। Details match होने पर APAAR card DigiLocker से access/download किया जा सकता है।

> **7 जून 2026 को सत्यापित:** ABC official portal Student login को DigiLocker/Meri Pehchaan authentication से जोड़ता है और learner flow में institution, admission year और roll number selection दिखाता है।

## किन छात्रों के लिए यह route है?

यह page उन learners के लिए है जो:

- College/university में पढ़ रहे हैं
- Higher education या skill education learner हैं
- ABC portal से APAAR/learner ID बनाना चाहते हैं
- Institution ने APAAR/ABC ID मांगा है

School students के लिए अलग process है: [School students APAAR parent consent guide](/hi/guide/apaar-id-school-students-parent-consent).

## शुरू करने से पहले

| जरूरत | क्यों चाहिए |
|---|---|
| DigiLocker account | ABC login DigiLocker से होता है |
| Aadhaar-linked mobile | OTP/KYC के लिए |
| Institution name | सही college/university select करने के लिए |
| Admission year | record matching के लिए |
| Roll/enrolment number | student record ढूंढने के लिए |
| Name/DOB match | Aadhaar, DigiLocker और institution record match होने चाहिए |

## Step-by-Step Process

1. [abc.gov.in](https://www.abc.gov.in/) खोलें।
2. Login/Register में **Student** चुनें।
3. DigiLocker/Meri Pehchaan login page खुलेगा।
4. अपने DigiLocker account से login करें।
5. Education category चुनें।
6. Institution search करके सही नाम चुनें।
7. Admission year और roll/enrolment number exactly भरें।
8. Request submit करें।
9. अगर details match होती हैं, तो APAAR card/learner ID DigiLocker में access हो सकता है।

## Roll Number कैसे भरें?

Roll/enrolment number वही भरें जो official record में है:

- College ID card
- Admission letter
- University student portal
- Exam admit card
- Enrolment certificate

Slash, hyphen, leading zero या year prefix हटाने से mismatch हो सकता है। अगर doubt है, तो academic/exam section से पूछें।

## Institution नहीं मिल रहा तो क्या करें?

- Official institution name से search करें।
- Affiliated college है तो university name भी check करें।
- गलत similar institution select न करें।
- Academic/exam section से पूछें कि institution ABC portal पर onboarded है या नहीं।

## APAAR card download

1. DigiLocker login करें।
2. Issued Documents खोलें।
3. APAAR या Academic Bank of Credits search करें।
4. Card दिखे तो download/share करें।

Detailed page: [APAAR ID download from DigiLocker](/guide/apaar-id-download-digilocker).

## Common Problems

| समस्या | कारण | समाधान |
|---|---|---|
| Institution not found | institution onboarded नहीं या नाम अलग | official name search करें, college से पूछें |
| Record not found | roll/enrolment mismatch | exact format use करें |
| Name mismatch | Aadhaar/DigiLocker और college record अलग | record correction करें |
| Card not showing | sync/request pending | ABC और DigiLocker दोनों check करें |
| Credits missing | institution ने records upload नहीं किए | academic/exam section से संपर्क करें |

## Submit करने से पहले checklist

- Institution का नाम official है, nickname नहीं
- Admission year सही है
- Roll/enrolment number में slash, hyphen या zero नहीं छूटा
- DigiLocker profile student के Aadhaar से linked है
- Name और DOB institution record से match हैं
- आप parent या sibling के DigiLocker account से login नहीं कर रहे
- Form में APAAR/ABC learner ID मांगा है, Aadhaar नहीं

अगर doubt है, तो गलत request submit करने से बेहतर है कि college academic section से exact detail पूछ लें।

## अगर request fail हो जाए

सबसे पहले screenshot लें और error text note करें। फिर:

1. ABC portal पर institution search दोबारा करें।
2. Roll/enrolment number exact format में डालें।
3. DigiLocker KYC/name check करें।
4. College से पूछें कि record ABC/NAD में mapped है या नहीं।
5. Unofficial websites पर दोबारा data न डालें।

## College office से क्या पूछें?

अगर portal पर record नहीं मिल रहा, तो college या university office से ये सवाल पूछें:

- क्या institution ABC portal पर onboarded है?
- APAAR/ABC के लिए कौन-सा roll number format इस्तेमाल करना है?
- Admission year calendar year है या academic session?
- क्या student master data में name और DOB Aadhaar से match हैं?
- क्या credits या learner records ABC/NAD में upload हुए हैं?

इन सवालों से साफ होता है कि समस्या student की तरफ है, institution mapping में है, या portal sync में है।

## Safe submission tips

एक ही गलती के साथ बार-बार submit न करें। इससे confusion बढ़ सकता है। पहले exact record पता करें, फिर request submit करें। Cyber cafe या agent से login करवाते समय OTP और DigiLocker PIN खुद दर्ज करें, किसी को बताएं नहीं।

## FAQs

### क्या DigiLocker जरूरी है?
ABC student route official portal पर DigiLocker authentication से चलता है।

### क्या APAAR ID बनाना paid है?
Official portals fee list नहीं दिखाते। Unofficial paid agents से बचें।

### Dropper student क्या भरें?
जिस institution/admission record के लिए ID मांगी गई है, उसी का official detail भरें। अगर currently enrolled नहीं हैं, तो institution/exam authority से पूछें।

### क्या school student भी यह route use करे?
School students आम तौर पर school/UDISE/PEN parent-consent route follow करते हैं।

### क्या APAAR card तुरंत download हो जाएगा?
अगर record match हो गया तो DigiLocker/ABC flow में card दिख सकता है। लेकिन institution mapping या sync pending हो तो delay हो सकता है।
