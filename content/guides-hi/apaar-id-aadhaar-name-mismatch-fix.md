# APAAR ID Aadhaar Name Mismatch Fix

**त्वरित उत्तर:** APAAR ID generate या link नहीं होता अगर student का नाम school/UDISE record, Aadhaar, DigiLocker या college record में अलग है। पहले पता करें गलती किस record में है। Aadhaar गलत है तो UIDAI route से सुधारें। School/UDISE/PEN record गलत है तो school से correction कराएं। College record गलत है तो academic/exam section से ठीक कराएं।

> **7 जून 2026 को सत्यापित:** Official APAAR FAQ कहता है कि UDISE+ student record का name Aadhaar के name से match होना चाहिए। ABC portal update flow Aadhaar update, DigiLocker KYC और APAAR update का संकेत देता है।

## Common mismatch examples

| Problem | Example |
|---|---|
| spelling अलग | Rahul vs Raahul |
| initials | R Kumar vs Rahul Kumar |
| order अलग | Kumar Rahul vs Rahul Kumar |
| DOB mismatch | school और Aadhaar dates अलग |
| parent name mismatch | father/mother name अलग |
| roll/enrolment mismatch | college record format अलग |

## Step 1: गलत record पहचानें

इन records को compare करें:

- Aadhaar
- DigiLocker profile
- school admission record
- UDISE/PEN detail, अगर school दिखा सके
- college/university student profile
- admit card या enrolment record

जिस record में गलती है, वही सुधारें। Aadhaar सही है और school record गलत है, तो Aadhaar update न करें।

## Step 2: Aadhaar गलत है तो

1. Official UIDAI process से Aadhaar update करें।
2. Update reflect होने का इंतजार करें।
3. DigiLocker KYC/profile refresh करें।
4. School/institution से APAAR/ABC retry करवाएं।

## Step 3: School record गलत है तो

1. School office/class teacher से संपर्क करें।
2. Aadhaar और admission documents दिखाएं।
3. Student name, DOB, gender, parent names correct करवाएं।
4. PEN/UDISE record check करवाएं।
5. Correction के बाद APAAR generation retry करवाएं।

## Step 4: College record गलत है तो

1. Admission record और roll/enrolment number check करें।
2. Academic/exam section में correction request दें।
3. ABC portal पर exact institution name और roll format use करें।
4. Correction के बाद फिर DigiLocker/ABC request करें।

## Correction order

1. Aadhaar check करें।
2. DigiLocker KYC check करें।
3. School/college record check करें।
4. PEN या roll number format check करें।
5. Institution से APAAR/ABC mapping retry करवाएं।

## कौन से documents साथ रखें?

- Aadhaar/e-Aadhaar
- school/college ID card
- admission record
- birth certificate, अगर DOB issue है
- roll/enrolment/PEN detail
- error screenshot, बिना OTP/password दिखाए
- parent ID, अगर student minor है

## School/College को क्या message भेजें?

आप यह छोटा message भेज सकते हैं:

> मेरी APAAR ID generate/update नहीं हो रही है क्योंकि Aadhaar/DigiLocker और school/college record में mismatch हो सकता है। कृपया मेरा name, DOB, gender, parent names, PEN/roll number और APAAR/ABC status official system में check कर दें।

## किस record को पहले सुधारें?

अगर Aadhaar में spelling गलत है, तो UIDAI route से Aadhaar सुधारें। अगर Aadhaar सही है लेकिन school record गलत है, तो school record सुधारें। अगर college roll number या enrolment गलत है, तो university/college academic section से correction कराएं। गलत source को सुधारने से नया mismatch बन सकता है।

Correction के बाद school या institution से APAAR/ABC mapping retry करने को कहें। केवल correction करने से हर बार card तुरंत DigiLocker में नहीं दिखता।

## Common correction cases

| Case | क्या करें |
|---|---|
| Aadhaar में spelling गलत | UIDAI route से Aadhaar update करें |
| School record में short name | School से full name update करवाएं |
| DOB school और Aadhaar में अलग | सही proof के आधार पर गलत record सुधारें |
| Parent name अलग | School/institution master data check करवाएं |
| College roll number format अलग | Admit card या university portal वाला exact format use करें |
| DigiLocker KYC पुराना | Aadhaar update के बाद DigiLocker profile refresh करें |

## गलती सुधारने के बाद

Correction के बाद तुरंत नया account न बनाएं। पहले existing DigiLocker/ABC route से retry करें। School student के लिए school APAAR module status check करवाएं। College student के लिए ABC portal पर same institution और corrected roll number से request करें।

## FAQs

### क्या मैं APAAR details खुद edit कर सकता हूं?
कुछ details Aadhaar/DigiLocker/ABC flow से refresh हो सकती हैं, लेकिन school/UDISE या college record correction institution को करना पड़ सकता है।

### कौन-सा नाम use होना चाहिए?
Official APAAR FAQ के अनुसार UDISE+ student name Aadhaar name से match होना चाहिए।

### Minor student के लिए parent correction करा सकते हैं?
Parents school से coordinate कर सकते हैं, लेकिन UDISE/PEN correction school authority ही करती है।

### Correction के बाद APAAR automatically दिखेगा?
कभी-कभी retry/refresh जरूरी होता है। School, ABC या institution से status check कराएं।

### क्या initials की वजह से mismatch हो सकता है?
हां। R Kumar और Rahul Kumar जैसे नाम अलग माने जा सकते हैं। School/institution और Aadhaar में exact name format match कराना बेहतर है।
