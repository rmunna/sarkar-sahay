# [पासपोर्ट](/guide/passport-apply-online) आवेदन स्टेटस ऑनलाइन कैसे ट्रैक करें

पासपोर्ट आवेदन जमा करने के बाद इंतज़ार लंबा लगता है। स्टेटस ट्रैक करने से पता चलता है कि आपकी फ़ाइल कहाँ है — समीक्षा में, पुलिस वेरिफ़िकेशन पर, या डिस्पैच के लिए तैयार।

---

## विधि 1: Passport Seva Portal से ट्रैक करें (सबसे भरोसेमंद)

आपको **File Number** (फ़ॉर्मेट: `XX-1234567890123`) और **जन्मतिथि** चाहिए।

### स्टेप्स:

1. [passportindia.gov.in](https://www.passportindia.gov.in) पर जाएँ
2. होमपेज पर **"Track Application Status"** पर क्लिक करें
3. **"Passport/PCC/IC/GEP"** चुनें
4. **File Number** दर्ज करें — यह आवेदन रसीद पर छपा होता है
5. **जन्मतिथि** DD/MM/YYYY फ़ॉर्मेट में दर्ज करें
6. कैप्चा भरें → **"Track Status"** पर क्लिक करें

> **टिप:** File Number आवेदन की पावती रसीद पर होता है जो PSK से मिली थी। दो अक्षर (राज्य कोड) + 13 अंक।

---

## विधि 2: mPassport Seva ऐप से ट्रैक करें

1. **mPassport Seva** ऐप डाउनलोड करें (Google Play / App Store)
2. ऐप खोलें → **"Track Application Status"** पर टैप करें
3. **File Number** और **जन्मतिथि** दर्ज करें
4. **"Track Status"** पर टैप करें

---

## विधि 3: SMS से ट्रैक करें

रजिस्टर्ड मोबाइल से SMS भेजें:

**STATUS <File Number>** → **9704100100** पर भेजें

---

## स्टेटस संदेशों का मतलब

| स्टेटस | मतलब |
|--------|-------|
| **Application Received** | आवेदन मिल गया, प्रोसेसिंग शुरू नहीं |
| **Under Review at PSK** | Passport Seva Kendra पर समीक्षा चल रही |
| **Granted** | पासपोर्ट स्वीकृत — प्रिंट के लिए भेजा जाएगा |
| **Police Verification Initiated** | पुलिस वेरिफ़िकेशन शुरू |
| **Police Verification Report Received** | पुलिस रिपोर्ट मिल गई |
| **Printed** | पासपोर्ट छप गया |
| **Dispatched** | Speed Post से भेज दिया गया |

---

## पासपोर्ट डिलीवरी ट्रैकिंग

पासपोर्ट **Speed Post** से भेजा जाता है:

1. स्टेटस पेज पर **Speed Post tracking number** दिखेगा
2. [India Post ट्रैकिंग](https://www.indiapost.gov.in/_layouts/15/dop.portal.tracking/trackconsignment.aspx) पर नंबर डालकर ट्रैक करें

---

## पासपोर्ट कब तक आता है?

| प्रकार | समय |
|--------|-----|
| **सामान्य** | 30-45 दिन (पुलिस वेरिफ़िकेशन सहित) |
| **तत्काल** | 7-14 दिन |
| **री-इश्यू / नवीनीकरण** | 15-20 दिन |

---

## पुलिस वेरिफ़िकेशन अटका है — क्या करें?

1. **स्थानीय पुलिस स्टेशन** जाकर पूछें
2. **Passport Seva Kendra** में शिकायत दर्ज करें
3. **ऑनलाइन शिकायत:** passportindia.gov.in → Grievance
4. **1800-258-1800** (टोल-फ़्री हेल्पलाइन) पर कॉल करें
