# बिजली बिल ऑनलाइन भरें — राज्यवार गाइड

## प्रमुख राज्य डिस्कॉम और वेबसाइट

| राज्य | डिस्कॉम | वेबसाइट |
|---|---|---|
| दिल्ली | BSES, Tata Power | bfraud.bsesdelhi.com |
| महाराष्ट्र | MSEDCL | mahadiscom.in |
| UP | UPPCL | uppcl.org |
| तमिलनाडु | TANGEDCO | tangedco.gov.in |
| कर्नाटक | BESCOM | bescom.co.in |
| राजस्थान | JDVVNL/AVVNL | energy.rajasthan.gov.in |
| बिहार | SBPDCL/NBPDCL | sbpdcl.co.in |

## भुगतान के तरीके

### 1. डिस्कॉम वेबसाइट
कंज्यूमर नंबर दर्ज → बिल देखें → भुगतान करें → रसीद डाउनलोड

### 2. UPI ऐप (Paytm, PhonePe, Google Pay)
बिल भुगतान → बिजली → डिस्कॉम चुनें → कंज्यूमर नंबर → भुगतान

### 3. नेट बैंकिंग
बैंक लॉगिन → बिल भुगतान → बिजली → डिस्कॉम → भुगतान

## टिप्स
- नियत तिथि से पहले भरें — विलंब शुल्क से बचें
- कंज्यूमर नंबर UPI ऐप में सेव करें
- भुगतान रसीद 2 साल रखें
