## UMANG App क्या है?

**UMANG (Unified Mobile Application for New-age Governance)** भारत सरकार (MeitY) का एक **Unified Digital Platform** है जो **2,000+ Central और State Government Services** को **एक App में** उपलब्ध कराता है।

EPFO, Income Tax, PMAY, Scholarship, Aadhaar, CBSE, BIS, IRCTC — सब UMANG में।

---

## मुख्य सेवाएं

| विभाग | सेवा |
|-------|------|
| **EPFO** | PF Balance Check, Claim Status |
| **Income Tax** | ITR Status, 26AS, Form 16 |
| **PMAY** | आवास आवेदन Status |
| **NPS** | Account Balance, Statement |
| **Aadhaar** | Aadhaar Download, Update Status |
| **CBSE** | Result, Admit Card |
| **Scholarship** | NSP Application Status |
| **Gas** | LPG Booking (Indane, BPCL, HP) |
| **Transport** | RC, DL Details |
| **DigiLocker** | Integration |

## UMANG App कैसे Use करें

### Download करें:
- **Android:** Play Store → "UMANG"
- **iOS:** App Store → "UMANG"
- **Web:** [web.umang.gov.in](https://web.umang.gov.in)

### Registration:
1. App खोलें → "Register" → Mobile Number → OTP
2. MPIN (6-digit) बनाएं
3. सेवाएं Browse करें

### सेवा कैसे खोजें:
- **Search** में सेवा का नाम लिखें (जैसे "PF Balance")
- **Category** से Browse करें (Finance, Education, Health)
- **Favourite** करें — Fast Access

---

## PF Balance UMANG से कैसे देखें

1. UMANG App → "EPFO"
2. **"View Passbook"** → UAN दर्ज करें
3. **OTP** (EPFO registered mobile)
4. PF Balance और Transactions दिखेंगे
