# MP मुख्यमंत्री जन कल्याण संबल योजना

## योजना क्या है?
मध्य प्रदेश सरकार की **असंगठित क्षेत्र के श्रमिकों** के लिए व्यापक कल्याण योजना। दुर्घटना बीमा, शिक्षा सहायता, अंतिम संस्कार सहायता, मातृत्व लाभ आदि — सब एक छतरी के नीचे।

## लाभ

| लाभ | राशि |
|---|---|
| **दुर्घटना मृत्यु** | ₹4 लाख |
| **स्थायी अपंगता** | ₹2 लाख |
| **सामान्य मृत्यु** | ₹2 लाख |
| **अंतिम संस्कार** | ₹5,000 |
| **शिक्षा सहायता** | कक्षा अनुसार ₹500–₹20,000 |
| **मातृत्व सहायता** | ₹4,000 प्रसव पूर्व, ₹12,000 प्रसव बाद |
| **बिजली बिल** | ₹200/माह सब्सिडी |

## पात्रता
- मध्य प्रदेश का निवासी
- **असंगठित क्षेत्र का श्रमिक** (मज़दूर, रिक्शा चालक, नाई, कुम्हार आदि)
- BPL परिवार या गरीबी रेखा से नीचे
- **समग्र ID** अनिवार्य
- आयकर दाता न हो

## संबल कार्ड रजिस्ट्रेशन
1. [sambal.mp.gov.in](https://sambal.mp.gov.in) पर जाएं
2. या निकटतम **ग्राम पंचायत / नगर निगम** कार्यालय जाएं
3. समग्र ID, आधार कार्ड, श्रम प्रमाण लेकर जाएं
4. रजिस्ट्रेशन → संबल कार्ड जारी

## दावा कैसे करें
1. [sambal.mp.gov.in](https://sambal.mp.gov.in) पर लॉगिन
2. संबंधित लाभ का दावा चुनें
3. ज़रूरी दस्तावेज़ अपलोड (मृत्यु प्रमाणपत्र, FIR, स्कूल प्रमाणपत्र आदि)
4. सबमिट → सत्यापन → DBT से बैंक में
