# SBI Debit Card Blocked / Not Working — Fix Guide 2026

SBI (State Bank of India) ATM/debit card issues are among the most reported banking problems in India. Whether it's a PIN block, card suspension, or disabled online transactions, here's how to fix every SBI debit card problem.

---

## Types of SBI Debit Card Issues

| Issue | What Happens | Fix |
|-------|-------------|-----|
| PIN blocked (3 wrong attempts) | ATM declines "wrong PIN" | Generate new Green PIN |
| Temporarily blocked by customer | Self-blocked via YONO | Unblock via YONO |
| Hot-listed (lost/stolen) | Permanently blocked | Request new card |
| International use disabled | Foreign website/ATM declines | Enable via YONO |
| Online use disabled | e-Commerce payments fail | Enable via YONO |
| Card expired | Declines everywhere | Request renewal card |

---

## Fix 1: Generate SBI Green PIN (Reset ATM PIN)

The most common fix — PIN block after 3 wrong attempts:

### Via YONO SBI App:
1. YONO SBI → **"Cards"** → Select your debit card
2. Tap **"Generate Green PIN"**
3. OTP sent to SBI-registered mobile
4. Enter OTP → Set new 4-digit ATM PIN
5. **PIN active immediately**

### Via YONO SBI Net Banking:
1. login.onlinesbi.sbi.co.in → Cards → Green PIN generation
2. Same OTP process

### At SBI ATM:
1. Insert card → Don't enter PIN
2. Select **"PIN Change"** / **"Green PIN"** option
3. OTP on registered mobile → Enter → Set new PIN

---

## Fix 2: Unblock Temporarily Blocked SBI Debit Card

If you self-blocked via YONO:

1. YONO SBI → **"Cards"** → Select blocked card
2. Toggle: **"Unblock Card"** → Confirm
3. **Card active immediately**

---

## Fix 3: Enable SBI International Transactions

SBI disables international use by default. Enable before international travel or foreign website purchase:

1. YONO SBI → **"Cards"** → **"Card Controls"**
2. Toggle: **"International Transactions"** → Enable
3. Set daily international spending limit
4. **Works within 2 minutes**

---

## Fix 4: Enable SBI Online / e-Commerce Transactions

For Amazon, Flipkart, or any online payment failure:

1. YONO SBI → **"Cards"** → **"Card Controls"**
2. Toggle: **"Online Transactions"** → Enable
3. Works immediately for most websites

---

## Fix 5: Request New SBI Debit Card

For expired card or permanently hot-listed card:

1. YONO SBI → **"Cards"** → **"Request New Debit Card"**
2. Select card type:
   - SBI Classic (RuPay — basic)
   - SBI Global (Visa/Mastercard — for international use)
   - SBI Platinum (Visa Platinum — higher benefits)
3. Choose delivery address
4. **New card delivered in 7–10 working days**
5. Activate received card via YONO or any SBI ATM

---

## Fix 6: SBI Debit Card on UPI / PhonePe / GPay Failing

SBI debit card linked to UPI is separate from card control:
- Card block does NOT block UPI (different systems)

## Frequently Asked Questions

**SBI Green PIN — why is it called "Green PIN"?**
SBI's terminology: "Green PIN" = instant OTP-based PIN generation at ATM or via app. It replaced the old practice of banks sending a sealed envelope PIN. Now you set your own PIN instantly.

**SBI debit card shows "Card Declined" at POS but ATM works — why?**
Possible reasons: (1) POS terminal issue — try another store, (2) e-Commerce enabled but "POS/Swipe" disabled — check YONO Card Controls, (3) Daily swipe limit reached, (4) Merchant's bank/terminal issue.

**SBI RuPay debit card doesn't work on foreign websites — is this normal?**
Yes — RuPay cards are primarily domestic. They work on some international sites (Amazon global, Netflix) but not all. For international use: Request SBI Global (Visa/Mastercard) debit card from YONO or branch.

**SBI debit card replacement — is there a fee?**
Replacement card fee: ₹200–₹300 depending on card variant. Renewal (after expiry): Usually free or ₹100. Hot-list and request new (lost card): ₹200 approximate.

**SBI debit card valid for how long?**
SBI debit cards are valid for 3–5 years. Expiry date is printed on the card (MM/YY format). Request renewal 30 days before expiry via YONO so you receive the new card before the old one expires.
