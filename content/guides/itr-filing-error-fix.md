# ITR Filing Error on Income Tax Portal? Fix Common Errors

Filing your Income Tax Return (ITR) online should be straightforward, but many taxpayers face errors on the Income Tax e-Filing portal. From JSON upload failures to validation errors and server timeouts, these issues can be frustrating — especially close to the filing deadline.

This guide covers the most common ITR filing errors and how to fix each one step by step.

## Common ITR Filing Errors and Solutions

### 1. JSON Upload Error

**Error:** "Error in uploading JSON" or "Invalid JSON file" when uploading your ITR.

**Causes:**
- JSON file was generated using an outdated offline utility
- File got corrupted during download or transfer
- Wrong ITR form was used to generate the JSON

**How to Fix:**
1. Download the **latest version** of the offline utility from [incometax.gov.in](https://www.incometax.gov.in/iec/foportal/)
2. Go to **Downloads** → **Offline Utilities** → select the correct ITR form
3. Re-enter your details or import the previously saved XML
4. Generate a fresh JSON file
5. Upload the new JSON file on the portal

> **Tip:** Always clear your browser cache before uploading the JSON file.

### 2. Validation Failed Error

**Error:** "Validation failed" or specific field-level validation errors.

**Causes:**
- Mandatory fields left blank (PAN, bank account, employer details)
- Mismatch between Form 26AS/AIS data and declared income
- Incorrect tax computation or deduction amounts

**How to Fix:**
1. Open the offline utility and click **Validate** before generating JSON
2. Check all mandatory fields marked with asterisk (*)
3. Cross-verify your income details with **Form 26AS** and **Annual Information Statement (AIS)** on the portal
4. Ensure total income, deductions under [Section 80C](/guide/section-80c-deductions-guide), and tax payable are correctly calculated
5. Fix the flagged errors and regenerate the JSON

### 3. Server Error / Portal Timeout

**Error:** "Something went wrong," "Service temporarily unavailable," or portal not loading.

**Causes:**
- Heavy traffic on the portal, especially near filing deadlines
- Server maintenance or technical issues at CPC Bengaluru

**How to Fix:**
1. Try filing during **off-peak hours** — early morning (6-8 AM) or late night (after 10 PM)
2. Clear browser cache and cookies
3. Use **Google Chrome** or **Mozilla Firefox** (latest version)
4. Disable browser extensions that may interfere
5. If the error persists, try after a few hours — the IT department usually resolves server issues within 24 hours
6. Check the official [IT portal Twitter handle](https://www.incometax.gov.in/iec/foportal/) for maintenance announcements

### 4. ITR Form Mismatch

**Error:** "You are not eligible to file this ITR form" or the wrong form gets pre-selected.

**Causes:**
- Selecting ITR-1 when you have capital gains (requires ITR-2 or ITR-3)
- Choosing ITR-1 when you have income from more than one house property
- Business income shown but filing ITR-1 instead of ITR-3 or ITR-4

**How to Fix:**

| Your Income Type | Correct ITR Form |
|---|---|
| Salary + one house property (income up to ₹50 lakh) | ITR-1 (Sahaj) |
| Salary + capital gains + multiple properties | ITR-2 |
| Business or profession income | ITR-3 |
| Presumptive business income (Section 44AD/44ADA) | ITR-4 (Sugam) |

1. Check your income sources carefully
2. Select the correct ITR form
3. If you already started with the wrong form, go to **e-File** → **Income Tax Returns** → **File Income Tax Return** and select the correct form

### 5. Offline Utility Not Working

**Error:** Utility not opening, Java errors, or "utility has stopped working."

**Causes:**
- Java not installed or outdated
- Utility version is old
- System compatibility issues

**How to Fix:**
1. Install the latest version of **Java** (JRE 8 or above) from java.com
2. Download the **latest offline utility** from the portal's Downloads section
3. On Windows, right-click the utility and select **Run as Administrator**
4. If using Mac, ensure you have allowed the app in **System Preferences** → **Security & Privacy**
5. For persistent issues, use the **online filing mode** on the portal instead

### 6. Common ITR Error Codes

| Error Code | Meaning | Solution |
|---|---|---|
| **Error 900** | Duplicate filing attempt | Check if ITR was already filed for the same AY |
| **Error 150** | PAN not registered | Register PAN on the e-Filing portal first |
| **Error 600** | Digital signature error | Re-register your DSC on the portal |
| **Error 800** | Schema validation error | Download the latest utility and regenerate JSON |
| **ITR-V not generated** | Filing incomplete | Check if e-verification or submission completed |

## Step-by-Step: How to File ITR Online Without Errors

1. **Log in** to [incometax.gov.in](https://www.incometax.gov.in/iec/foportal/) using PAN and password
2. Go to **e-File** → **Income Tax Returns** → **File Income Tax Return**
3. Select **Assessment Year** (e.g., AY 2026-27 for income earned in FY 2025-26)
4. Choose filing mode: **Online** (recommended) or **Offline** (upload JSON)
5. Select the correct **ITR form** based on your income type
6. Fill in income details — the portal pre-fills data from Form 26AS and AIS
7. Verify all pre-filled data and correct any mismatches
8. Enter deductions and tax payments
9. Click **Validate** to check for errors
10. **Preview** your return and submit
11. **e-Verify** your return immediately using [Aadhaar OTP](/guide/itr-verification-pending-fix) or net banking

## Processing Time

- ITR processing by CPC: **15 to 45 days** after e-verification
- Refund (if applicable): **30 to 120 days** — see our [ITR refund guide](/guide/itr-refund-not-received-fix)

## Important Tips

1. **Always use the latest utility** — the IT department updates utilities frequently during filing season
2. **File well before the deadline** to avoid portal congestion and server errors
3. **Keep Form 26AS and AIS handy** to avoid income mismatch errors
4. **e-Verify immediately** after filing — unverified returns are treated as not filed
5. **Take a screenshot** of the acknowledgment number after successful filing

## Frequently Asked Questions

### Q1: Why does my ITR JSON file keep getting rejected?
The JSON file may be generated from an outdated utility or wrong ITR form. Download the latest utility from the official portal, select the correct form, and regenerate the JSON.

### Q2: Can I file ITR if the portal shows a server error?
Yes, but you need to wait. Server errors are usually temporary. Try filing during off-peak hours (early morning or late night). You can also use the offline utility to prepare your return and upload when the server is stable.

### Q3: What happens if I select the wrong ITR form?
The portal will show a validation error or reject the filing. You can restart the process and select the correct form. There is no penalty for selecting the wrong form — you simply cannot submit it.

### Q4: How do I check if my ITR was successfully filed?
Log in to the e-Filing portal → **e-File** → **Income Tax Returns** → **View Filed Returns**. You will see the status, acknowledgment number, and verification status.

### Q5: What should I do if the error persists after trying all fixes?
Contact the CPC helpline at **1800-103-0025** (toll-free) or raise a grievance on the [e-Filing portal](https://www.incometax.gov.in/iec/foportal/). You can also visit your nearest Income Tax office for assistance.

### Q6: Is there a penalty for filing ITR late due to portal errors?
If the portal was genuinely down and the government extends the deadline, no penalty applies. Otherwise, late filing attracts a penalty of ₹1,000 to ₹5,000 under Section 234F. Always file before the deadline to avoid this.
