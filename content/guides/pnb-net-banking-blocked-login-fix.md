# PNB Net Banking Blocked or Login Failed? Fix (2026)

PNB internet banking (netpnb.com) blocks after multiple wrong login attempts. The reset is done online in under 5 minutes with your account number and mobile OTP.

---

## Common Causes of PNB Net Banking Block

| Cause | Fix |
|-------|-----|
| Wrong password 3 times | Reset via "Forgot Password" |
| Wrong transaction password | Reset separately |
| User ID forgotten | Retrieve via account number |
| Inactive account | Call 1800-180-2222 |
| KYC pending | Update KYC first |

---

## Method 1: Reset PNB Net Banking Password

1. Go to **[netpnb.com](https://www.netpnb.com)**
2. Click **"Login"** → **"Forgot Password"** or **"Unlock User"**
3. Enter **User ID** (or account number if you don't have User ID)
4. Enter Account number + Date of birth
5. OTP on registered mobile → Enter OTP
6. Set new login password + confirm
7. **Active immediately**

---

## Method 2: Via PNB ONE App

1. Open **PNB ONE** app
2. **Services → Net Banking → Forgot Password**
3. OTP verification → New password set

---

## Method 3: Unlock PNB User ID

If your PNB User ID is locked (not just password):

1. netpnb.com → **"Unlock User"**
2. Enter User ID + account details + mobile OTP
3. User ID unlocked — then reset password

---

## PNB Net Banking OTP Not Received

1. Wait 2 minutes → Resend
2. Verify registered mobile via PNB ONE → Profile
3. If mobile changed: Visit PNB branch to update mobile, then reset

## Frequently Asked Questions

**What is PNB Net Banking User ID?**
PNB assigns a User ID during internet banking registration — usually your CIF number or customer-assigned ID. Found in PNB welcome letter or account opening documents.

**PNB net banking password reset online isn't working — what to do?**
Visit nearest PNB branch with Aadhaar + passbook. Branch can reset net banking credentials on the spot.

**PNB ONE app works but net banking website doesn't — why?**
PNB ONE app and net banking website (netpnb.com) may use different credentials. Reset the website password separately.
