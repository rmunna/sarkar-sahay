## Overview of Voter ID Forms

The Election Commission of India uses a set of standardized forms for all voter registration and electoral roll management. Understanding which form to use saves time and ensures your application is processed correctly.

Here are the four main forms every Indian voter should know:

| Form | Purpose | When to Use |
|------|---------|-------------|
| **Form 6** | New voter registration | Applying for a Voter ID for the first time or registering at a new constituency |
| **Form 7** | Deletion of name | Removing a duplicate, deceased, or shifted person's entry |
| **Form 8** | Correction of entries | Fixing name, photo, address, DOB, or other details |
| **Form 8A** | Transposition within constituency | Moving your entry to a different part/booth within the same constituency |

All forms can be filed online at [voters.eci.gov.in](https://voters.eci.gov.in) or submitted offline to the ERO/BLO.

## Form 6 — New Voter Registration

### What is Form 6?
Form 6 is the application for **inclusion of name in the electoral roll**. It is used when:
- You are turning 18 and applying for a Voter ID for the first time
- You have moved to a **new constituency** and want to register there
- Your name was deleted and you need to re-register

### Who Should File Form 6?
- Indian citizens who are 18 years or older (as of January 1 of the current year)
- Persons not currently registered in any electoral roll
- Persons who moved to a new assembly constituency

### Documents Required
- Proof of age (birth certificate, Class 10 marksheet, [Aadhaar](/guide/aadhaar-card-apply-online), passport)
- Proof of address at current residence (Aadhaar, utility bill, bank passbook, rent agreement)
- Recent passport-size photograph (JPEG, 10–200 KB for online)

### How to File
**Online:** Visit [voters.eci.gov.in](https://voters.eci.gov.in) → Login → Select "New Registration (Form 6)" → Fill details → Upload documents → Submit

**Offline:** Download Form 6 → Fill → Attach documents → Submit to BLO or ERO office

### Processing Time
15–45 days (includes BLO verification visit)

> **Detailed guide:** See our [complete Voter ID application guide](/guide/voter-id-card-apply-online).

## Form 7 — Deletion of Name

### What is Form 7?
Form 7 is the application for **objection to inclusion of a name or deletion of an entry** from the electoral roll. It is used when:
- A person has **duplicate entries** in the electoral roll
- A person has **died** and their name needs to be removed
- A person has **permanently shifted** to another constituency but their old entry remains

### Who Can File Form 7?
- **Any registered voter** in the same constituency can file Form 7
- You don't have to be the person whose name is being deleted
- Family members typically file for deceased persons

### Documents Required
- EPIC number of the entry to be deleted
- Part number and serial number from the electoral roll
- Proof supporting the reason (death certificate, new voter ID from different constituency, etc.)

### How to File
**Online:** Visit [voters.eci.gov.in](https://voters.eci.gov.in) → Login → Select "Deletion of Name (Form 7)" → Enter duplicate/deceased entry details → Select reason → Upload proof → Submit

**Offline:** Download Form 7 → Fill → Submit to BLO or ERO with supporting documents

### Processing Time
15–45 days (BLO verification + 7-day notice period for objections)

> **Detailed guide:** See our [duplicate Voter ID deletion guide](/guide/voter-id-delete-duplicate).

## Form 8 — Correction of Entries

### What is Form 8?
Form 8 is the application for **correction of particulars entered in the electoral roll**. It is the most commonly used form for updating Voter ID details:
- **Name** correction or change (including [after marriage](/guide/voter-id-name-change-marriage))
- **Photo** update or [replacement](/guide/voter-id-photo-change-online)
- **Date of birth** correction
- **Address** correction (within the same constituency)
- **Gender** correction
- **Relation name/type** change (e.g., father to husband after marriage)

### Who Should File Form 8?
The voter whose details need correction. The applicant must be an existing registered voter with a valid EPIC number.

### Documents Required
- Existing Voter ID (EPIC number)
- Supporting document for the correction:
  - Name change: Marriage certificate, Gazette notification, court order
  - Photo: New passport-size photograph
  - DOB: Birth certificate, Class 10 marksheet
  - Address: Aadhaar, utility bill, rent agreement
- Recent passport-size photograph

### How to File
**Online:** Visit [voters.eci.gov.in](https://voters.eci.gov.in) → Login → Select "Correction of Entries (Form 8)" → Enter EPIC number → Select fields to correct → Upload documents → Submit

**Offline:** Download Form 8 → Fill correction details → Attach documents → Submit to BLO or ERO

### Processing Time
15–30 days (may require BLO verification for certain corrections)

> **Detailed guide:** See our [Voter ID correction guide](/guide/voter-id-correction-online).

## Form 8A — Transposition of Entry

### What is Form 8A?
Form 8A is the application for **transposition of entry in the electoral roll**. It is used when:
- You have moved to a **new address within the same assembly constituency**
- Your polling booth has changed but you remain in the same constituency
- You want your name to appear under a **different part number** (different booth area) within the same constituency

### How is Form 8A Different from Form 8?
| Feature | Form 8 | Form 8A |
|---------|--------|---------|
| **Purpose** | Correct existing details | Move entry to a different part/booth |
| **Address change** | Minor corrections within same booth area | New address in a different booth area (same constituency) |
| **Constituency** | Same constituency | Same constituency only |
| **Electoral roll part** | Same part number | Different part number |

> **Key difference:** If your new address falls under a **different polling booth** but the **same constituency**, use Form 8A. If it's just a house number or street name correction within the same booth area, use Form 8.

### Who Should File Form 8A?
Registered voters who have shifted within the same assembly constituency to an area served by a different polling booth.

### Documents Required
- Existing Voter ID (EPIC number)
- Proof of new address (Aadhaar, utility bill, rent agreement, bank passbook)
- Recent passport-size photograph

### How to File
**Online:** Visit [voters.eci.gov.in](https://voters.eci.gov.in) → Login → Select "Transposition of Entry (Form 8A)" → Enter EPIC number → Enter new address details → Upload proof → Submit

**Offline:** Download Form 8A → Fill → Attach address proof → Submit to BLO or ERO

### Processing Time
15–30 days (includes BLO verification at the new address)

## Quick Decision Guide: Which Form Do I Need?

| Situation | Form to Use |
|-----------|-------------|
| First time applying for Voter ID | **Form 6** |
| Moved to a new constituency | **Form 6** (new) + **Form 7** (delete old) |
| Name, photo, DOB correction | **Form 8** |
| Name change after marriage | **Form 8** |
| Moved within same constituency (different booth) | **Form 8A** |
| Minor address correction (same booth) | **Form 8** |
| Delete duplicate entry | **Form 7** |
| Remove deceased person's entry | **Form 7** |
| Re-register after name was deleted | **Form 6** |

## Fees

**All forms are free.** There are no charges for filing Form 6, 7, 8, or 8A — whether online or offline.

## Important Tips

1. **Always file online when possible** — Online applications are tracked with reference IDs and processed faster.
2. **One form per purpose** — Don't use Form 8 when you need Form 8A, or vice versa. Using the wrong form delays processing.
3. **Moving to a new constituency? File both forms** — Submit Form 6 at the new location and Form 7 to delete from the old one.
4. **Keep reference IDs safe** — Track application status on [voters.eci.gov.in](https://voters.eci.gov.in) using your reference number.
5. **Contact your [BLO](/guide/voter-id-blo-details-check) for help** — The Booth Level Officer can guide you on which form to use and assist with filing.

## Frequently Asked Questions

### What is the difference between Form 6, 7, 8, and 8A?
Form 6 is for new registration, Form 7 for deletion, Form 8 for corrections, and Form 8A for moving your entry within the same constituency to a different booth.

### Which form do I use to change my name on Voter ID?
Use **Form 8** for name corrections or changes, including name change after marriage.

### Can I file these forms online?
Yes. All four forms can be filed online at [voters.eci.gov.in](https://voters.eci.gov.in) after logging in with your mobile number.

### Is there a fee for any of these forms?
No. All voter registration forms are completely free — both online and offline.

### I moved to a new city. Which form should I use?
If the new city is in a **different assembly constituency**, file Form 6 for new registration and Form 7 to delete your old entry. If it's within the **same constituency** but a different booth area, file Form 8A.

### How do I track my form submission status?
Visit [voters.eci.gov.in](https://voters.eci.gov.in) → "Track Application Status" → Enter your Reference ID.

### Can I submit multiple forms at the same time?
Yes. For example, when moving constituencies, you can submit Form 6 (new registration) and Form 7 (deletion of old entry) simultaneously.
