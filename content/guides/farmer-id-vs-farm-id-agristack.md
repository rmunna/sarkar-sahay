# Farmer ID vs Farm ID vs Kisan ID

**Quick answer:** Farmer ID identifies the farmer as a person in the Farmer Registry ecosystem. Farm ID identifies a land parcel/farm record. PM-KISAN ID is a scheme beneficiary record. Aadhaar is the citizen identity used for authentication, but it is not the same as Farmer ID.

The confusion is normal because different schemes and states use different names. This page keeps the terms separate.

## Difference Table

| Term | Meaning | Used For |
|---|---|---|
| Farmer ID | Person-level identity of a farmer | Farmer Registry, scheme targeting, digital agriculture services |
| Farm ID | Land parcel / farm-level identity | Linking land records, crops and ownership/operation details |
| Temporary Farmer ID / Bucket ID | Internal grouping ID mentioned in registry clarification | Software/data matching, not usually needed by farmer |
| PM-KISAN ID | PM-KISAN scheme beneficiary record | PM-KISAN payments and status |
| Aadhaar | General identity/authentication number | eKYC and identity checks |
| KCC account | Bank loan account | Agriculture credit |

## Official Farmer Registry Clarification

The official Farmer Registry FAQ says:

- Farmer ID is for a person.
- Farm ID is for land parcel owned by the farmer within the survey number or sub-survey number.
- Temporary Farmer ID and Bucket ID are internal IDs used by software and are not required by the farmer.

This means a farmer may have one person identity, while land/farm records may be linked separately.

## Why This Matters

Wrong ID confusion can cause real problems:

- A scheme form may ask for Farmer ID, but the applicant enters Aadhaar.
- A land correction may need Farm ID or land record details, not PM-KISAN ID.
- A bank or CSC operator may ask for KCC/PM-KISAN details, but that does not automatically create Farmer ID.
- A state portal may use a different label while mapping to Agri Stack.

When in doubt, check the exact field label on the official form.

## Example Scenarios

| Situation | Likely ID Needed |
|---|---|
| Checking PM-KISAN payment | PM-KISAN beneficiary/mobile/Aadhaar route |
| Linking land records in Farmer Registry | Farmer ID and land/farm details |
| Agriculture loan | KCC/bank account plus farmer verification |
| Crop survey | Farm/land parcel and crop details |
| State Farmer Registry login | State-specific Farmer ID/mobile/CSC route |

## What Farmers Should Keep Ready

- Aadhaar-linked mobile number
- Land record details
- PM-KISAN or state scheme details, if already enrolled
- Bank account for DBT schemes, where required
- Mobile number used for agriculture department registration

Do not guess IDs. Wrong entries can delay verification.

## If Your Farmer ID and Land Record Do Not Match

Common reasons:

- Land record name differs from Aadhaar name
- Joint ownership or inherited land not updated
- Mobile number differs from old scheme records
- Tenant farmer or cultivator details are not recorded in the same way across systems
- State portal has not synced the latest land record

Start with the state Farmer Registry or revenue/agriculture department correction route. Do not use unofficial "correction agents".

## Frequently Asked Questions

### Is Farmer ID my Aadhaar number?
No. Aadhaar may be used for authentication, but Farmer ID is a farmer registry identity.

### Is Farm ID the same as land survey number?
Not exactly. Farm ID is a registry identity for land parcel/farm records. It may be linked with survey/sub-survey details depending on state implementation.

### Is Farmer ID needed for every farmer scheme?
Not always. Existing schemes such as PM-KISAN have their own official beneficiary processes. Farmer ID importance may increase as states integrate Agri Stack.

### What is Bucket ID?
The Farmer Registry clarification describes Bucket ID as an internal software ID for grouping land records. It is not normally something a farmer needs to enter.

### Can one farmer have more than one Farm ID?
A farmer may have multiple land parcels/farm records. The exact structure depends on state land records and Farmer Registry implementation.
