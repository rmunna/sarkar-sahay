# Farmer ID Agri Stack Guide 2026

**Quick answer:** Farmer ID is the farmer identity layer being built through the Agri Stack / Farmer Registry ecosystem. It is meant to help identify farmers, connect land and crop information where states have onboarded, and improve delivery of farmer schemes, credit, inputs and advisories.

This is an emerging digital agriculture cluster. The exact registration route depends on the state, because Agri Stack is designed with states at the centre of implementation.

## Current Status

| Item | Status on June 8, 2026 |
|---|---|
| Agri Stack | Official digital agriculture infrastructure initiative |
| Farmer Registry | Active in some state portals; rollout varies by state |
| Farmer ID | Person-level identity for a farmer in the registry ecosystem |
| Farm ID | Land-parcel level identity, different from Farmer ID |
| Best action | Check your state Farmer Registry or agriculture department route |

## What Agri Stack Is

The official Agri Stack portal describes Agri Stack as a digital foundation for Indian agriculture. It aims to bring together high-quality data and make it easier for farmers, governments, agri-techs and service providers to use digital services.

Important goals include:

- Better delivery of government farmer schemes
- Easier farmer identification and authentication
- Lower cost and risk for credit, inputs and agriculture services
- Scheme convergence between ministries and state governments
- Innovation by agri-tech startups using approved access and consent systems

## What Farmer ID Is Used For

Farmer ID can become useful when schemes and services need to know who the farmer is and which land/crop records are linked.

Likely use cases include:

- Farmer scheme eligibility checks
- Kisan Credit Card and agriculture credit workflows
- Crop survey and crop advisory systems
- PM-KISAN and other DBT verification support
- Insurance, input subsidy and disaster-relief verification
- AI-based agriculture advisories where official data is available

For AI-linked agriculture services, also read [Bharat-VISTAAR AI for Farmers Guide](/guide/bharat-vistaar-ai-farmers-guide).

## Farmer ID Is Not the Same as Aadhaar

Do not treat Farmer ID as a replacement for Aadhaar, land records, bank account or PM-KISAN ID.

| ID / Record | What It Is |
|---|---|
| Aadhaar | General identity number |
| Farmer ID | Farmer identity in the Agri Stack / Farmer Registry ecosystem |
| Farm ID | Land-parcel identity linked to farm/land details |
| PM-KISAN ID | Scheme-specific beneficiary record |
| KCC account | Bank credit account, not a farmer registry identity |

Detailed comparison: [Farmer ID vs Farm ID vs Kisan ID](/guide/farmer-id-vs-farm-id-agristack).

## How To Check Whether Your State Has Farmer Registry

1. Search your state agriculture department site for "Farmer Registry" or "Agri Stack".
2. Check whether the URL is on an official government or `agristack.gov.in` subdomain.
3. Look for options such as Farmer login, CSC login, status check or enrollment status.
4. Do not enter Aadhaar, OTP or bank details on unofficial websites.
5. If the state portal is not live, wait for official agriculture department instructions.

Use this status guide: [Farmer Registry Status Check](/guide/farmer-registry-status-check).

## Documents Farmers May Need

Requirements can differ by state, but farmers should keep these ready:

- Aadhaar-linked mobile number
- Land record / RoR / khata / survey details
- Bank account details for scheme DBT, if requested by official route
- Existing PM-KISAN or state farmer scheme details
- Mobile number used in agriculture department records

Never share OTPs with agents or callers. Official registration may use OTP, but the OTP should be entered by you on the official portal or at an authorised centre.

## Scam Warning

Avoid:

- Paid "urgent Farmer ID" services on WhatsApp
- Websites that are not official state government or Agri Stack domains
- Calls asking for Aadhaar OTP, bank OTP or UPI PIN
- Forms promising instant subsidy after Farmer ID creation

Farmer ID is a registry identity. It does not automatically guarantee subsidy, loan approval or insurance payment.

## Frequently Asked Questions

### What is Farmer ID?
Farmer ID is a person-level farmer identity in the Farmer Registry / Agri Stack ecosystem. It helps identify a farmer for digital agriculture services where the state has implemented the registry.

### Is Farmer ID available in every state?
Rollout varies by state. Some states have visible Farmer Registry portals, while others may still be onboarding or using department-led processes.

### Is Farmer ID mandatory for PM-KISAN?
Do not assume it is mandatory everywhere. PM-KISAN has its own official process. Farmer ID may become important for future verification in some states, but check your state agriculture department and PM-KISAN portal.

### Can I create Farmer ID myself online?
Some state portals may allow farmer login or CSC-assisted enrollment. The route depends on the state. Use only official portals.

### Is Farm ID the same as Farmer ID?
No. The official Farmer Registry FAQ distinguishes Farmer ID for a person and Farm ID for land parcel details.
