# DigiLocker Aadhaar Verification Failed: How to Fix

DigiLocker is the government's official digital document wallet that requires Aadhaar verification for sign-up and accessing documents. When Aadhaar verification fails, you cannot create a DigiLocker account or fetch your documents. This guide covers all reasons for verification failure and how to fix them.

## Common Error Messages and Symptoms

- **"Aadhaar verification failed — please try again"** — generic verification failure
- **"OTP not received"** — Aadhaar OTP does not arrive during sign-up
- **"Invalid OTP — please enter correct OTP"** — OTP is rejected
- **"Aadhaar number not found"** — entered Aadhaar is not recognized
- **"Your Aadhaar is already linked to another DigiLocker account"** — duplicate account
- **"KYC verification failed"** — Aadhaar-based KYC does not complete
- **"Unable to fetch documents"** — verification succeeds but documents do not load
- Sign-up page gets stuck after entering Aadhaar number
- App crashes during Aadhaar verification
- Biometric verification fails at DigiLocker-linked services

## Why DigiLocker Aadhaar Verification Fails

### 1. Mobile Number Not Linked to Aadhaar

DigiLocker sends OTP to the mobile number registered with UIDAI. If no number is linked, or it is an old number, OTP cannot be received.

### 2. UIDAI Server Issues

DigiLocker connects to UIDAI's authentication servers in real-time. If UIDAI servers are down or overloaded, verification fails.

### 3. Aadhaar Already Used

Each Aadhaar can be linked to only one DigiLocker account. If a previous account exists (possibly created unknowingly), new registration fails.

### 4. Name/Date of Birth Mismatch

If details entered during DigiLocker registration do not exactly match Aadhaar records, verification fails.

### 5. Aadhaar Biometric Lock

If you have locked your Aadhaar biometrics via mAadhaar or UIDAI portal, biometric-based verification methods will fail.

### 6. Outdated DigiLocker App

Older versions of the DigiLocker app may have bugs that cause verification failures.

## Step-by-Step Troubleshooting

### Step 1: Verify Mobile Number Linked to Aadhaar

1. Visit [myaadhaar.uidai.gov.in](https://myaadhaar.uidai.gov.in/)
2. Use **"Verify Mobile & Email"** to check if your current number is linked
3. If not linked, visit an [Aadhaar enrolment centre](/guide/aadhaar-card-apply-online) to update your mobile number (₹50 fee)
4. Mobile update takes 10-90 days to reflect

### Step 2: Check UIDAI Server Status

1. Try generating an OTP at [myaadhaar.uidai.gov.in](https://myaadhaar.uidai.gov.in/) for any service
2. If OTP works on myAadhaar but not DigiLocker, the issue is on DigiLocker's side
3. Wait 30-60 minutes and retry
4. Try during off-peak hours (early morning or late evening)

### Step 3: Fix "Already Linked" Error

If your Aadhaar is already linked to another DigiLocker account:
1. Try logging in with your Aadhaar number at [digilocker.gov.in](https://www.digilocker.gov.in/)
2. Use **"Sign in with Aadhaar"** and complete OTP verification
3. If the old account opens, you can continue using it
4. If you do not have access to the old account, raise a support ticket at [digilocker.gov.in → Contact Us](https://digilocker.gov.in/about-us/contact-us)
5. Request account deletion of the old account, then create a new one

### Step 4: Update DigiLocker App

1. Open Google Play Store or App Store
2. Search for "DigiLocker"
3. Update to the latest version
4. Clear app cache: Settings → Apps → DigiLocker → Storage → Clear Cache
5. Retry verification

### Step 5: Use the Web Portal Instead of App

1. Open [digilocker.gov.in](https://www.digilocker.gov.in/) in Chrome or Firefox
2. Use Incognito/Private mode
3. Disable ad blockers and privacy extensions
4. Try sign-up or verification through the web portal
5. The web portal often works when the app does not

### Step 6: Use TOTP Instead of SMS OTP

1. Install the **mAadhaar app** on your phone
2. Set up TOTP (Time-based OTP) in the app
3. When DigiLocker asks for OTP, use the TOTP generated by mAadhaar
4. This bypasses SMS delivery issues entirely

### Step 7: Contact DigiLocker Support

If all else fails:
1. Email **support@digitallocker.gov.in** with:
   - Your name and Aadhaar number (masked: XXXX-XXXX-1234)
   - Screenshot of the error
   - Mobile number
   - Description of the issue
2. Raise a ticket at [digilocker.gov.in → Contact Us](https://digilocker.gov.in/about-us/contact-us)
3. Response typically takes 3-7 working days

## Alternative Methods and Workarounds

### Sign Up with Mobile Number

DigiLocker also allows registration with just a mobile number:
1. Choose **"Sign up with Mobile"** option
2. Enter your mobile number and verify with OTP
3. Aadhaar linking can be done later inside the app
4. Some features may be limited until Aadhaar is verified

### Access Documents Through UMANG

If DigiLocker is not working, access your digital documents through the [UMANG app](/guide/umang-app-not-working-fix):
1. Download UMANG from your app store
2. Go to **DigiLocker** section within UMANG
3. Authenticate with Aadhaar and access your documents

### Download Documents Directly

Instead of using DigiLocker, download documents from the issuing departments:
- **Aadhaar:** [myaadhaar.uidai.gov.in](https://myaadhaar.uidai.gov.in/)
- **Driving Licence:** [parivahan.gov.in](https://parivahan.gov.in/)
- **Marksheets/Certificates:** Your university's or board's portal (CBSE, state boards)
- **Vehicle RC:** [parivahan.gov.in](https://parivahan.gov.in/)
- **PAN:** [eportal.incometax.gov.in](https://eportal.incometax.gov.in/)

### Use DigiLocker Partner Apps

Several apps integrate with DigiLocker:
- mParivahan (vehicle documents)
- UMANG (multiple government documents)
- Aarogya Setu (health records)

## Prevention Tips

1. **Ensure mobile number is updated in Aadhaar** — this is the most important step for smooth DigiLocker verification
2. **Install mAadhaar** — set up TOTP as a backup for OTP verification
3. **Remember your DigiLocker credentials** — save your security PIN and linked mobile to avoid lockouts
4. **Keep the app updated** — enable auto-updates for DigiLocker
5. **Create only one account** — do not try creating multiple accounts with the same Aadhaar
6. **Fetch important documents early** — do not wait until you urgently need a document to fetch it into DigiLocker

## Frequently Asked Questions

### Why does DigiLocker say my Aadhaar is already linked?

Each Aadhaar number can be linked to only one DigiLocker account. If you previously created an account (even accidentally), your Aadhaar is already used. Try signing in with your Aadhaar number to access the existing account. If you cannot access it, contact DigiLocker support to delink the old account.

### Can I use DigiLocker without Aadhaar?

Partially. You can create a basic DigiLocker account using just your mobile number. However, Aadhaar verification is required to fetch government-issued documents (driving licence, vehicle RC, marksheets) and to use the full features. Without Aadhaar, you can only manually upload documents.

### How long does it take for DigiLocker Aadhaar verification to work after updating mobile in Aadhaar?

After updating your mobile number at an Aadhaar enrolment centre, the change typically reflects in the UIDAI database within 10-90 days. Once the new number is active in Aadhaar, DigiLocker verification will work with OTP sent to the new number.

### Is DigiLocker safe and legally valid?

Yes. DigiLocker is a Government of India platform under the Ministry of Electronics and IT. Documents fetched from DigiLocker are legally valid and equivalent to original documents as per the IT Act 2000. They are accepted by all government departments, banks, and educational institutions.

### What should I do if DigiLocker verification fails repeatedly?

First, ensure your mobile number is linked to Aadhaar and try TOTP via mAadhaar app instead of SMS OTP. Try the web portal in an incognito browser. If issues persist, email support@digitallocker.gov.in with a masked Aadhaar number and error screenshots. Also check if UIDAI servers are functioning by testing OTP on myaadhaar.uidai.gov.in.
