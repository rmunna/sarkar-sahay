# Union Bank Mobile Banking (Vyom) Not Working? (2026 Fix)

**Vyom** is Union Bank of India's official mobile banking app — launched after the merger of Andhra Bank and Corporation Bank into Union Bank. If Vyom app is not opening, login is failing, or OTP not coming — this guide walks you through the fixes.

> **Quick check:** Call **1800-222-244** (toll-free) or check @UnionBankTweets on Twitter/X to see if there's a known outage.

---

## Common Vyom App Issues

| Issue | Likely Cause |
|-------|-------------|
| Login failed | Wrong MPIN; account locked |
| OTP not received | Network issue; registered number inactive |
| Black screen / app not loading | Cache issue; old app version |
| "Service unavailable" error | Server maintenance or outage |
| Transaction declined | Wrong UPI PIN; limit exceeded |
| Biometric not working | OS update; permission revoked |
| App crash | Outdated version; device incompatibility |

## Fixes — Try in Order

### Fix 1: Check Union Bank Server Status

- Call **1800-222-244** — automated line confirms outages
- Search Twitter/X: @UnionBankTweets or "Vyom app down"
- Check [downdetector.in](https://downdetector.in) → "Union Bank of India"
- If outage confirmed, wait 15–30 minutes and retry

### Fix 2: Update Vyom App

1. Open **Google Play Store** or **App Store**
2. Search **"Vyom - Union Bank of India"**
3. Tap **Update** if available
4. Relaunch after updating

> Union Bank periodically rolls out mandatory security updates. Old Vyom versions will block login.

### Fix 3: Clear App Cache (Android)

1. **Settings → Apps → Vyom Union Bank**
2. Tap **Storage → Clear Cache**
3. Do NOT clear app data (you'll lose login credentials)
4. Reopen Vyom

> On iPhone: Uninstall and reinstall Vyom from the App Store.

### Fix 4: OTP Not Received

- Ensure your **registered mobile number** is active with SMS
- Disable **DND mode** temporarily
- Check if SMS inbox is full — delete old messages
- Wait 3–5 minutes for delayed OTP
- If number has changed: visit Union Bank branch to update before attempting login

### Fix 5: Reset MPIN

**Forgot MPIN:**
1. On Vyom login screen → **"Forgot MPIN"**
2. Enter **Debit Card number + ATM PIN** (or card expiry + CVV)
3. Enter OTP sent to registered mobile
4. Set new 6-digit MPIN

**Via Internet Banking:**
1. Login at [unionbankonline.co.in](https://unionbankonline.co.in)
2. **Service Request → Mobile Banking → Reset MPIN**

### Fix 6: Re-register Biometric

1. Open Vyom → **Settings → Security**
2. Disable fingerprint/Face ID login
3. Login with MPIN once
4. Re-enable biometric and scan fingerprint again

### Fix 7: Switch Network

- Turn off Wi-Fi → use **4G mobile data**
- Disable VPN before opening Vyom
- If on office network: switch to personal mobile hotspot

### Fix 8: Reinstall Vyom

1. Uninstall **Vyom** app completely
2. Restart device
3. Reinstall from Play Store / App Store
4. Re-register: Customer ID → OTP → Debit Card → new MPIN

## Frequently Asked Questions

### Why does Vyom app say "Invalid Customer ID"?

Your **Customer ID** (CIF number) is different from your account number. Find it on your passbook, welcome letter, or bank statement — it's typically 7–10 digits. Not the account number.

### Vyom app is stuck on loading screen — how to fix?

1. Force-close the app
2. Clear cache (Settings → Apps → Vyom → Storage → Clear Cache)
3. Switch from Wi-Fi to mobile data
4. Reopen Vyom
5. If still stuck: update/reinstall

### My Union Bank transaction failed — money deducted but not credited?

Wait 30 minutes — most failed UPI/NEFT transactions auto-reverse. If not reversed in 3 working days: call **1800-222-244** with transaction ID, date, and amount.
