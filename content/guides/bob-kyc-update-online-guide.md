# Bank of Baroda KYC Update Online 2026 — Without Branch Visit

Bank of Baroda (BOB) conducts periodic KYC updates as per RBI mandate. Customers can now update KYC online via the BOB World app or Baroda Connect net banking. Here's the complete step-by-step guide.

---

## Why BOB Is Asking for KYC Update

| Reason | BOB Action |
|--------|-----------|
| RBI periodic re-KYC | Debit transactions restricted after deadline |
| Migration from Vijaya/Dena Bank | KYC re-verification post-merger |
| Address/name change | Records must match OVD (Officially Valid Document) |
| Account dormancy | KYC mandatory for reactivation |

---

## Method 1: BOB World App (Recommended)

1. Open **BOB World** app → Login with MPIN
2. Navigate to **"Profile"** → **"KYC Update"** or **"Services"** → **"Update KYC"**
3. Upload documents:
   - Aadhaar (front + back photos)
   - PAN card photo
   - Live selfie (in-app)
4. Accept self-declaration
5. Submit → Reference number generated
6. **Processing: 24–72 hours**

### Aadhaar OTP KYC (Instant):
1. BOB World → KYC → **"Aadhaar-based e-KYC"**
2. Enter Aadhaar number → OTP on registered mobile
3. UIDAI data fetched electronically → KYC updated instantly

---

## Method 2: Baroda Connect Net Banking

1. Login at **[barodaconnect.com](https://www.barodaconnect.com)**
2. **"Services"** → **"KYC Update"**
3. Upload scanned Aadhaar + PAN (self-attested)
4. Submit
5. **Processing: 3–5 working days**

---

## Method 3: BOB Video KYC

1. BOB World app → KYC → **"Video KYC"** (if available)
2. BOB executive joins the call (5-minute session)
3. Show original Aadhaar + PAN
4. KYC verified live → Confirmation within 1 hour

---

## Method 4: BOB Branch

1. Visit any Bank of Baroda branch
2. Carry: Aadhaar (original + copy) + PAN (original + copy) + photo
3. Fill **"KYC Updation Form"**
4. Submit → Same-day processing

**BOB Customer Care:** **1800-5700** (toll-free)

## Frequently Asked Questions

**BOB KYC update — do I need to go to my home branch?**
No — any BOB branch can process KYC update. BOB World app allows online KYC for most accounts. Home branch is faster if there are complications.

**My BOB account was Vijaya/Dena Bank — does KYC process differ?**
No — same BOB KYC process applies. Carry old passbook details + Aadhaar + PAN. Branch can trace your account via merger records.

**BOB World app KYC document rejected — why?**
Common causes: Image blurry, Aadhaar face photo not visible, name mismatch between Aadhaar and BOB records. Retry with fresh clear photos. For name mismatch: Update Aadhaar name or get bank records corrected at branch.

**BOB KYC update pending for 7 days — what to do?**
Call 1800-5700 with reference number. Escalate if not resolved within 10 working days. As last resort: Visit home branch with printout of app reference.

**Enhanced KYC requested by BOB — what documents are needed?**
Enhanced KYC: Latest 6 months bank statement + ITR or salary slip + Aadhaar + PAN. For high-value business accounts: Additional source of funds documentation. This usually requires branch visit.
