# Bank of Baroda UPI Blocked or Not Working? Fix (2026)

Bank of Baroda UPI can be managed via the **BOB World** app and third-party UPI apps. This guide covers all common BOB UPI failures and fixes.

---

## Why Is BOB UPI Failing?

| Issue | Fix |
|-------|-----|
| Wrong UPI PIN 5+ times | Reset UPI PIN |
| Account has debit freeze | Fix account block first |
| Daily limit exceeded | Wait till midnight |
| UPI not registered | Register via BOB World |
| Bank server down | Wait 30 minutes |

---

## Reset Bank of Baroda UPI PIN

### Via BOB World App
1. Open **BOB World** → **UPI** → **Manage**
2. Select account → **"Change UPI PIN"** or **"Forgot UPI PIN"**
3. Debit card last 6 digits + expiry → OTP → New PIN

### Via PhonePe / GPay
1. App → Bank Accounts → Select BOB account
2. **"Forgot UPI PIN"** → Debit card → OTP → New PIN

---

## Register BOB UPI on BOB World

1. BOB World → **UPI Services** → **Activate UPI**
2. Select savings/current account
3. Verify mobile number (must be bank-registered)
4. Set new UPI PIN
5. UPI active for use on all apps

## Frequently Asked Questions

**BOB World UPI works but PhonePe shows BOB account failed — why?**
Different apps register UPI separately. Remove BOB account from PhonePe → Re-add → Reset PIN in PhonePe.

**Bank of Baroda UPI daily limit?**
₹1,00,000 per day. Resets at midnight. For amounts above ₹1 lakh: use NEFT/IMPS via BOB World net banking.

**My BOB account is active but UPI says "payment declined by bank" — what to do?**
Call 1800-5700. A bank-specific UPI block may be in place. They can check and remove it.
