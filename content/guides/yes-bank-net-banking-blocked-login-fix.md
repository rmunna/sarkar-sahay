# Yes Bank Net Banking Blocked / Login Failed — Fix Guide 2026

Yes Bank's internet banking is accessed at **yesbank.in** (YES Online). The YES MOBILE app also provides all net banking features. Here's how to fix all Yes Bank net banking login issues.

---

## Common Yes Bank Net Banking Issues

| Problem | Cause |
|---------|-------|
| "Login failed — incorrect credentials" | Wrong User ID / password |
| "Account locked" | 3+ wrong password attempts |
| "OTP not received" | Mobile number mismatch |
| "Your session has expired" | Inactivity timeout |
| "Service unavailable" | Scheduled maintenance |

---

## Fix 1: Reset Yes Bank Net Banking Password

1. Go to **[yesbank.in](https://www.yesbank.in)** → **"YES Online"**
2. Click **"Forgot Password"**
3. Enter Customer ID / User ID
4. Mobile OTP verification on registered mobile
5. Enter debit card details (card number + expiry)
6. Set new password
7. **Login with new password**

---

## Fix 2: Unlock Yes Bank User ID

After 3+ wrong attempts:
1. YES Online → **"Unlock User"**
2. Enter User ID + registered mobile OTP
3. User ID unlocked → Reset password

---

## Fix 3: Recover Forgotten User ID

Customer ID / User ID is available:
- In account opening letter from Yes Bank
- First page of Yes Bank cheque book
- YES MOBILE app (after login via OTP)
- Customer care: **1800-1200** → Identity verification → User ID provided

---

## Fix 4: YES MOBILE App as Alternative

If YES Online website is having issues, use **YES MOBILE** app:

1. Open YES MOBILE app → Login with Customer ID + MPIN
2. Same functions: Balance, transfers, NEFT, bill pay
3. If MPIN forgotten: **"Forgot MPIN"** → OTP verification → Set new MPIN

---

## Fix 5: Mobile Number Update (If OTPs Not Coming)

If OTP not coming on current number:
1. Visit Yes Bank branch with Aadhaar (new mobile number)
2. Mobile number update form submitted
3. After 48 hours: New number active for OTPs
4. Reset net banking password with new number

**Yes Bank Customer Care:** **1800-1200** (toll-free, 24×7)

## Frequently Asked Questions

**Yes Bank — what is Customer ID vs User ID for net banking?**
Customer ID: 10-digit number assigned by Yes Bank (in account opening documents). User ID: Can be same as Customer ID or a user-set alphanumeric ID. If unsure which to use: Try both, or call 1800-1200.

**Yes Bank net banking showing "Your session will expire soon" repeatedly?**
This happens if browser has cookies disabled. Enable cookies for yesbank.in. Also ensure you're using Chrome or Firefox latest version. If on mobile: Use YES MOBILE app instead.

**Yes Bank net banking vs YES MOBILE — which is better?**
YES MOBILE app is more stable and feature-rich. Use the app for daily banking. YES Online (web) is useful for larger transactions (RTGS) on desktop.

**Can I transfer ₹10 lakh via Yes Bank net banking?**
Yes — NEFT/RTGS via net banking. RTGS: Minimum ₹2 lakh, available 24×7. For new beneficiaries: 24-hour cooling period (security measure). Pre-registered beneficiaries: Full limit immediate.

**Yes Bank account frozen — net banking shows login but no transactions?**
If account is frozen (by RBI compliance order or Yes Bank's own risk process): Contact Yes Bank branch directly with Aadhaar + PAN. Net banking may work for view-only but transactions blocked.
