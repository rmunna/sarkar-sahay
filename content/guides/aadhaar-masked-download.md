# Masked Aadhaar Download: How to Get & Why You Should Use It

A **masked Aadhaar** is a version of your [Aadhaar card](/guide/aadhaar-card-apply-online) where only the **last 4 digits** of your Aadhaar number are visible. The first 8 digits are replaced with "XXXX-XXXX". This protects your Aadhaar number from misuse while still serving as a valid identity proof.

## What is Masked Aadhaar?

| Feature | Regular Aadhaar | Masked Aadhaar |
|---|---|---|
| Aadhaar number display | Full 12 digits visible | Only last 4 digits shown (XXXX-XXXX-1234) |
| QR code | Contains full data | Contains full data (digitally signed) |
| Photo, name, address | Shown | Shown |
| Valid as ID proof | Yes | Yes |
| Digital signature | Yes | Yes |

The masked Aadhaar contains the same digitally signed QR code as the regular e-Aadhaar. The only difference is the visual display of the number on the document.

## Why Use Masked Aadhaar?

1. **Privacy protection** — Your full Aadhaar number is not visible, reducing the risk of unauthorized use
2. **Prevents identity theft** — Even if the document is seen by someone, they cannot note down your full Aadhaar number
3. **Equally valid** — UIDAI has confirmed that masked Aadhaar is a valid proof of identity
4. **QR code still works** — Verifiers can scan the QR code to get authenticated details
5. **Recommended by UIDAI** — UIDAI itself encourages the use of masked Aadhaar for day-to-day identity verification

## How to Download Masked Aadhaar

### Method 1: From myAadhaar Portal

1. Visit [https://myaadhaar.uidai.gov.in/](https://myaadhaar.uidai.gov.in/)
2. Click on **"Download Aadhaar"**
3. Enter your **12-digit Aadhaar number** or **16-digit [Virtual ID (VID)](/guide/aadhaar-virtual-id-generate)** or **Enrolment ID**
4. Enter the security code (captcha)
5. Click **"Send OTP"** — OTP will be sent to your registered mobile number
6. Enter the OTP
7. **Check the box** that says **"Do you want a Masked Aadhaar?"**
8. Click **"Download Aadhaar"**
9. The masked e-Aadhaar PDF will be downloaded to your device

### Method 2: From eaadhaar.uidai.gov.in

1. Visit [https://eaadhaar.uidai.gov.in/](https://eaadhaar.uidai.gov.in/)
2. Select the **"Aadhaar"** tab
3. Enter your Aadhaar number or VID
4. Enter captcha and request OTP
5. Enter OTP
6. **Tick the "Masked Aadhaar" checkbox**
7. Download the PDF

### Method 3: Using mAadhaar App

1. Download the **mAadhaar** app from [Google Play Store](https://play.google.com/store/apps/details?id=in.gov.uidai.mAadhaarPlus) or Apple App Store
2. Log in with your Aadhaar number and OTP
3. Your Aadhaar profile will load
4. Tap on **"View Aadhaar"**
5. Select **"Masked Aadhaar"** option
6. Download or share the masked version

## Password for Masked Aadhaar PDF

The downloaded masked Aadhaar PDF is password-protected. The password is the **first 4 letters of your name in UPPERCASE** + **year of birth**.

**Example:** If your name is Rajesh Kumar and birth year is 1990, the password is: **RAJE1990**

## Where is Masked Aadhaar Accepted?

Masked Aadhaar is accepted everywhere that regular Aadhaar is accepted:

- **Bank account opening** — for KYC verification
- **SIM card purchase** — telecom companies accept it
- **Government schemes** — for identity verification
- **Hotel check-in** — as address and identity proof
- **Exam hall tickets** — where Aadhaar is required as ID
- **Address proof** — for various applications
- **[PAN card application](/guide/pan-card-apply-online)** — as supporting identity document

**Note:** In rare cases, some private entities may insist on the full Aadhaar number. You can politely inform them that masked Aadhaar is valid as per UIDAI guidelines. If they still refuse, use the [Offline KYC XML](/guide/aadhaar-offline-kyc-xml) method instead.

## When to Use Masked Aadhaar vs Regular Aadhaar

| Situation | Recommended Version |
|---|---|
| Sharing Aadhaar copy with a landlord or employer | **Masked Aadhaar** |
| Uploading Aadhaar on websites or apps | **Masked Aadhaar** |
| Submitting for government scheme applications | Either (masked preferred) |
| KYC at banks with QR verification capability | **Masked Aadhaar** |
| Situations requiring full number (rare) | Regular Aadhaar |

## Important Tips

1. **Always prefer masked Aadhaar** when sharing copies — there is no downside to using it
2. **The QR code on masked Aadhaar contains full details** — so it can be [verified](/guide/aadhaar-verification-check-online) just like a regular Aadhaar
3. **You can download both versions** — keep a masked copy for sharing and a regular copy for your personal records
4. **Use VID to download** — for extra privacy, use your [Virtual ID](/guide/aadhaar-virtual-id-generate) instead of Aadhaar number even during download
5. **Watermark "COPY"** on shared documents — add a visible watermark before sharing physical copies

## FAQs

### Is masked Aadhaar legally valid as ID proof?

Yes. UIDAI has confirmed that masked Aadhaar (e-Aadhaar with only last 4 digits visible) is equally valid as a regular Aadhaar card for identity verification purposes.

### Can someone misuse my Aadhaar if they have the masked version?

The risk is significantly lower with masked Aadhaar since the full number is not visible. However, the QR code still contains data, so always share documents only with trusted entities.

### Can I get a physical masked Aadhaar card?

The PVC Aadhaar card ordered from UIDAI shows the full number. Masked Aadhaar is available only in the e-Aadhaar (PDF) format downloaded from the portal.

### How many times can I download masked Aadhaar?

There is no limit. You can download masked Aadhaar as many times as you need from myaadhaar.uidai.gov.in.

### What if I accidentally downloaded regular Aadhaar instead of masked?

Simply go back to myaadhaar.uidai.gov.in and download again, this time ensuring you tick the "Masked Aadhaar" checkbox before clicking download.

### Is the masked Aadhaar different from the Virtual ID?

Yes. Masked Aadhaar is a document format where the display of the number is hidden. The [Virtual ID (VID)](/guide/aadhaar-virtual-id-generate) is a separate 16-digit temporary number that maps to your Aadhaar but can be shared instead of the actual number.
