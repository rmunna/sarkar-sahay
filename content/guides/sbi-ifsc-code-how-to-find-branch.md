# SBI IFSC Code — How to Find Your Branch IFSC Code

**State Bank of India (SBI)** has over **22,000 branches** across India — each with a **unique IFSC code**. You cannot use one universal SBI IFSC code for all branches. This guide shows you exactly how to find the IFSC code for YOUR specific SBI branch.

> **Why we don't list specific codes:** SBI IFSC codes are branch-specific and change when branches merge, relocate, or close. Listing individual codes here risks spreading outdated information. Always verify from SBI's official sources.

---

## SBI IFSC Code Format

All SBI IFSC codes follow this pattern:

```
S B I N 0 X X X X X X
│ │ │ │ │ └────────── Branch code (6 alphanumeric)
│ │ │ │ └──────────── Always 0 (reserved character)
└─┴─┴─┴────────────── SBIN (SBI's bank code)
```

- **Always starts with: `SBIN`**
- **5th character: Always `0`**
- **Last 6 characters: Branch-specific code**

**Example format:** `SBIN0001234` (not a real code — for illustration only)

## 5 Official Ways to Find SBI Branch IFSC Code

### Method 1: Your SBI Cheque Book (Fastest)

Your IFSC code is printed on **every cheque leaf** at the top:
- Look near the bank's logo or branch address on the cheque
- It appears as 11 characters starting with **SBIN**
- This is 100% accurate — cheques are printed for your specific branch

### Method 2: SBI YONO App

1. Open **YONO SBI** app → Login
2. Tap **Account Details** (on home screen)
3. Scroll to find **IFSC Code** — displayed for your account's branch
4. Copy and use directly

### Method 3: SBI Net Banking (onlinesbi.sbi)

1. Login at [onlinesbi.sbi](https://www.onlinesbi.sbi)
2. Go to **My Accounts** → Select your account
3. Click **Account Details** or **Account Statement header**
4. IFSC code displayed alongside branch name and account number

### Method 4: SBI Branch Locator (Official Website)

1. Go to [sbi.co.in](https://sbi.co.in)
2. Click **Locate Us** → **Branch / ATM Locator**
3. Select State → District → Branch
4. Branch details page shows: **IFSC Code + MICR Code + Branch Address**

### Method 5: RBI's Official IFSC Directory

The RBI maintains the authoritative IFSC code database:
1. Visit [rbi.org.in](https://www.rbi.org.in)
2. Navigate to **Payment Systems → NEFT → IFSC**
3. Download the IFSC directory or use the search tool
4. Search for SBI + your state + district + branch name

## SBI IFSC Code on Passbook / Bank Documents

Your SBI passbook's **first page** shows:
- Account number
- Branch name and address
- **IFSC Code**
- MICR Code

The branch allotment letter or welcome kit from SBI also includes your branch's IFSC code.

## SBI Balance Enquiry / Mini Statement — IFSC Not Needed

For SBI balance check and mini-statement, you don't need IFSC:
- **Missed call:** 09223766666 (balance) | 09223866666 (mini-statement)
- **SMS:** `BAL` to 09223766666
- **YONO:** Home screen shows balance instantly

## After Bank Mergers — Important Note

SBI absorbed all **5 associate banks** (State Bank of Patiala, State Bank of Mysore, State Bank of Bikaner & Jaipur, State Bank of Travancore, State Bank of Hyderabad) in **April 2017**.

- Old SBBJ, SBH, SBM, SBP, SBT IFSC codes have been **changed to SBI codes**
- If you have an old passbook from these banks, the IFSC may be outdated
- Verify your current IFSC via YONO app or SBI net banking

## SBI IFSC for NEFT / RTGS Transfer — Step by Step

To add SBI as a beneficiary for NEFT/RTGS from another bank:

1. Get the recipient's SBI IFSC code (using methods above)
2. In your bank's net banking/app → **Fund Transfer → Add Beneficiary**
3. Enter:
   - Account Number (SBI account number)
   - IFSC Code (starts with SBIN)
   - Account holder name
4. Wait for beneficiary activation (30 min – 24 hours)
5. Initiate NEFT/RTGS transfer

## Frequently Asked Questions

**What is the IFSC code of SBI main branch?**
SBI has thousands of branches — there is no single "main branch" IFSC. Each branch has a unique code starting with SBIN. Find yours via YONO app, cheque book, or SBI website's branch locator.

**My SBI cheque shows SBIN0000001 — is this a real IFSC?**
No — this is a placeholder example. Your actual IFSC will be an 11-character code starting with SBIN, followed by 0, followed by 6 alphanumeric characters specific to your branch.

**Can I use another SBI branch's IFSC code for my NEFT transfer?**
No — you must use the IFSC code of the specific branch where the recipient's account is held. Using a different SBI branch IFSC can cause the transfer to fail or go to the wrong branch.

**SBI IFSC code for international transfers?**
IFSC is for domestic transfers only. For international transfers to an SBI account, you need SBI's **SWIFT code: SBININBB** (plus the account details). See our [SWIFT code guide](/guide/swift-code-indian-banks-guide).

**How many SBI branches have the same IFSC code?**
Zero — every SBI branch has a unique IFSC code. However, after branch mergers (when SBI merges two nearby branches), one branch's IFSC becomes invalid and all accounts are moved to the surviving branch's IFSC.
