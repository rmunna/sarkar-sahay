# SBI UPI Not Working / Blocked — Fix Guide 2026

SBI (State Bank of India) UPI issues are common given the bank's massive customer base and high transaction volumes. Whether you use YONO SBI, BHIM SBI Pay, or any third-party UPI app with SBI account, this guide covers every fix.

---

## SBI UPI Apps — Which One Are You Using?

| App | SBI UPI App? | Managed by |
|-----|-------------|-----------|
| **YONO SBI** | Yes — official SBI app with UPI | SBI |
| **BHIM SBI Pay** | Yes — dedicated SBI UPI app | SBI/NPCI |
| **PhonePe / GPay / Paytm** | Third-party, linked to SBI account | NPCI |
| **BHIM** | Generic NPCI app, SBI account linkable | NPCI |

Most SBI UPI issues can be fixed regardless of which app you use.

---

## Most Common SBI UPI Problems

| Problem | Likely Cause |
|---------|-------------|
| "UPI transaction declined" | Daily limit reached or bank server issue |
| "Your UPI PIN is blocked" | 3+ wrong PIN attempts |
| "Bank account not linked" | SBI account deregistered from UPI |
| "YONO UPI payment failed" | App glitch or SBI server timeout |
| "UPI ID not found" | SBI UPI ID (@oksbi) deleted or changed |

## Fix 1: Reset SBI UPI PIN (BHIM SBI Pay / YONO)

**If UPI PIN is blocked after wrong attempts:**

### In YONO SBI App:
1. YONO SBI → UPI → **"Forgot UPI PIN"** / **"Change UPI PIN"**
2. Select your SBI account
3. Enter **SBI debit card last 6 digits + expiry date**
4. OTP received on registered mobile
5. Set new 6-digit UPI PIN
6. **PIN reset — transactions resume immediately**

### In BHIM SBI Pay:
1. BHIM SBI Pay → UPI → **"Reset UPI PIN"**
2. Enter debit card details (last 6 digits + expiry)
3. OTP verification
4. Set new PIN → Done

---

## Fix 2: Re-link SBI Account to UPI (If Account Deregistered)

If your SBI UPI app shows "no bank account linked":

1. YONO SBI → **"UPI"** → **"Add / Manage Bank Accounts"**
2. Tap **"+"** → Select **State Bank of India**
3. App fetches accounts linked to your mobile number
4. Select the correct savings account
5. Set UPI PIN using debit card OTP
6. **Account re-linked — UPI active**

For third-party apps (PhonePe/GPay):
- Open the app → Payment Methods → Add/link bank account → SBI → Verify OTP

---

## Fix 3: SBI UPI Daily Limit Reset

**SBI UPI limits (NPCI standard):**
- ₹1 lakh per day per UPI-registered account
- ₹10,000 per transaction for some merchant payments (varies)
- SBI may set lower limits for new accounts

If limit exceeded: Wait until midnight (12:00 AM) — limits reset daily.
If you need higher limits: Use NEFT/RTGS via SBI net banking (up to ₹10 lakh per day).

---

## Fix 4: SBI Server / "Bank Account Temporarily Unavailable"

During peak hours (especially month-end salary dates), SBI servers become slow:

1. Wait 15–30 minutes → Retry
2. Check failed transaction: Go to YONO → **"UPI History"** → Check if deducted
3. If amount deducted but recipient not credited: **Auto-reversal in 24–48 hours**
4. Dispute failed transaction: YONO → UPI History → Select transaction → **"Raise Dispute"**

---

## Fix 5: SBI UPI ID (@oksbi) Not Working

SBI UPI IDs end in **@oksbi** or **@sbi**. If someone says your UPI ID is invalid:

1. Open YONO SBI → UPI → **"My UPI ID"** — note your exact ID
2. Share the correct ID
3. If UPI ID is deleted: Re-register UPI in YONO → New ID assigned

---

## Fix 6: UPI Failed on PhonePe/GPay with SBI Account

For third-party app failures with SBI account:

1. Check if SBI account is primary in the UPI app
2. UPI PIN reset: Go to PhonePe/GPay → Payment Methods → SBI → **"Forgot UPI PIN"** → Enter SBI debit card details
3. If SBI account removed from app: Re-add and re-verify

---

## Raise UPI Dispute for Failed SBI Transaction

If money deducted but payment not received:

1. YONO SBI → UPI → **"Transaction History"** → Find transaction → **"Raise Dispute"**
2. OR: **[pgrs.npci.org.in](https://pgrs.npci.org.in)** → Raise complaint → Enter UPI transaction ID
3. **Auto-resolution: 24–48 hours** for most failed transactions
4. Call SBI customer care: **1800-11-2211**

## Frequently Asked Questions

**SBI UPI shows "Exceeded daily limit" — when does it reset?**
SBI UPI limits reset at midnight (12:00 AM IST) every day. For urgent transfers above ₹1 lakh: Use YONO SBI → NEFT/RTGS (available 24×7 in SBI net banking).

**BHIM SBI Pay not working since phone change?**
BHIM SBI Pay is device-bound. After a phone change: Reinstall → Re-register your mobile number → Re-link SBI account → Reset UPI PIN.

**SBI UPI blocked but debit card works fine — why?**
UPI and debit card are separate systems. UPI blocks occur due to PIN failures, app issues, or mobile number problems. Debit card works independently via the ATM/POS network.

**How do I know if SBI UPI is blocked vs SBI servers down?**
If UPI fails on ALL payment apps linked to SBI, it's likely an SBI server issue. If only one app fails, it's an app-specific issue. Check SBI Twitter/social media for server outage announcements.

**SBI UPI transaction pending for 3 days — what to do?**
Call 1800-11-2211 with UPI transaction reference number (UPI Ref No. from YONO → UPI History). NPCI mandate: Failed transactions auto-reversed within 5 working days. Escalate to pgrs.npci.org.in if not resolved.
