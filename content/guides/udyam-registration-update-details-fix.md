# Udyam Registration Update Details? Fix Modification Errors

Need to update your business address, bank details, NIC code, or turnover on the [Udyam portal](https://udyamregistration.gov.in/)? The update process is straightforward but frequently throws errors. This guide covers how to update details correctly and fix common modification problems.

## How to Update Udyam Registration (Correct Process)

1. Visit [udyamregistration.gov.in](https://udyamregistration.gov.in/)
2. Click **"Update Udyam Registration"**
3. Enter your **Udyam Registration Number** (format: UDYAM-XX-00-0000000)
4. Enter the **OTP** sent to your Aadhaar-linked mobile number
5. Your existing registration details will load
6. Edit the fields you want to update
7. Click **"Submit & Get Final OTP"**
8. Verify with final OTP and submit
9. Updated certificate will be available within **24–48 hours**

## What You Can Update

| Detail | Can Update? | Notes |
|--------|-------------|-------|
| Business Address | ✅ Yes | Enter new address with correct PIN code |
| Bank Account Details | ✅ Yes | New bank account number and IFSC |
| Business Activity/NIC Code | ✅ Yes | Select correct NIC code from dropdown |
| Investment in Plant & Machinery | ✅ Yes | Update as per current financials |
| Annual Turnover | ✅ Yes | Must match ITR filed |
| Mobile Number | ✅ Yes | Will be used for future OTP verification |
| Email Address | ✅ Yes | Update for communications |
| Enterprise Name | ⚠️ Limited | Minor corrections only; major changes need DIC support |
| Owner's Name | ❌ No | Cannot be changed through portal |
| Aadhaar Number | ❌ No | Linked permanently to registration |

## Error 1: Unable to Login for Update

### Fixes

1. **OTP not received** — See our [Aadhaar OTP fix guide](/guide/udyam-registration-aadhaar-otp-fix) for detailed troubleshooting
2. **"Invalid Udyam Number"** — Check format: UDYAM-XX-00-0000000. Retrieve via "Forgot Udyam Number" option
3. **Portal not loading** — See our [Udyam portal fix guide](/guide/udyam-registration-not-working-fix) for server and browser fixes

## Error 2: NIC Code Update Issues

The National Industrial Classification (NIC) code defines your business activity. Incorrect NIC code can affect your MSME benefits eligibility.

### Common Problems

- **Can't find correct NIC code** — The portal uses NIC 2008 codes. Search by keyword in the dropdown
- **Multiple activities** — You can add up to 10 NIC codes for different business activities
- **Wrong code selected earlier** — Simply update to the correct code during modification
- **Code not saving** — Ensure you select from the dropdown (don't type manually) and click "Add"

### How to Find Your Correct NIC Code

1. Visit [mospi.gov.in](http://mospi.gov.in/) and search for NIC 2008 classification
2. Or search within the Udyam portal dropdown using business keywords
3. Example: Restaurant = NIC Code 5610, Software Development = NIC Code 6201

## Error 3: Turnover Mismatch

The Udyam portal auto-verifies turnover data with GSTN and Income Tax records.

### Common Issues & Fixes

1. **Turnover doesn't match ITR** — Enter the exact turnover as declared in your latest ITR. The system cross-verifies with CBDT
2. **"Turnover exceeds MSME limit"** — If annual turnover exceeds ₹250 crore, you no longer qualify as an MSME
3. **GST turnover vs ITR turnover mismatch** — Ensure your GST returns and ITR are consistent
4. **First year business with no ITR** — Enter projected/estimated turnover. Update next year with actual figures
5. **Export turnover exclusion** — Export turnover is excluded from the MSME limit calculation. Ensure you enter domestic turnover only where applicable

### MSME Classification Limits (Current)

| Category | Investment (Manufacturing & Services) | Turnover |
|----------|---------------------------------------|----------|
| Micro | Up to ₹1 crore | Up to ₹5 crore |
| Small | Up to ₹10 crore | Up to ₹50 crore |
| Medium | Up to ₹50 crore | Up to ₹250 crore |

## Error 4: Address Change Not Reflecting

### Fixes

1. **Wait 24–48 hours** — Address changes take time to reflect on the certificate
2. **PIN code validation error** — Enter the correct 6-digit PIN code matching your area
3. **State/District auto-fill incorrect** — PIN code determines state and district. Verify PIN code accuracy
4. **Moved to different state** — Update address normally. Your Udyam number won't change but the state code in the certificate reflects original registration
5. **After update, download new certificate** — Visit Print Certificate to get the updated version

## Error 5: Bank Details Update Rejected

### Common Causes

1. **Invalid IFSC code** — Verify IFSC on [rbi.org.in](https://www.rbi.org.in/Scripts/IFSCMICRDetails.aspx)
2. **Account number format** — Enter only digits, no spaces or special characters
3. **Account not in owner's name** — Bank account should ideally be in the business owner's name or the firm's name
4. **Frozen/inactive account** — Ensure the bank account is active

## Error 6: Re-verification Loop

Sometimes after submitting an update, the portal asks for re-verification repeatedly.

### Fixes

1. **Clear browser data** completely and start fresh
2. **Use incognito/private mode** to avoid cached session issues
3. **Don't use back button** — Navigate only through portal links
4. **Complete in one session** — Don't leave the update form idle
5. **If stuck**, raise a grievance on [champions.gov.in](https://champions.gov.in/)

## Important Tips

1. Update your Udyam details annually, especially turnover and investment figures
2. Keep your ITR, GST returns, and Udyam data consistent — mismatches can trigger verification issues
3. After updating, always download and save the new certificate
4. Major changes (like enterprise name change) may require visiting DIC office with supporting documents
5. All updates are free — never pay anyone to update your Udyam registration

## Frequently Asked Questions

### How often should I update my Udyam registration?
You should update investment and turnover details at least once a year, ideally after filing your annual ITR. Other details (address, bank) should be updated whenever they change.

### Can I change my Udyam registration from proprietorship to Pvt Ltd?
No. Change in constitution (ownership type) requires a new Udyam registration. Cancel the old one and apply fresh with the new entity's details.

### Will my Udyam number change after updating details?
No. Your Udyam Registration Number remains the same for lifetime regardless of updates.

### Can I update Udyam registration from my mobile phone?
Yes, the update process works on mobile browsers. However, for better experience, use a desktop/laptop with Chrome or Firefox.

### I updated my details but the old certificate still shows. What do I do?
Wait 48 hours for the system to refresh. Then download the certificate again from the Print Certificate section. If the issue persists, contact [champions.gov.in](https://champions.gov.in/).

### Can a CA or consultant update my Udyam registration?
Technically, anyone with access to your Aadhaar OTP can update it. However, never share your OTP with third parties. Do it yourself or visit the DIC office for free assistance.
