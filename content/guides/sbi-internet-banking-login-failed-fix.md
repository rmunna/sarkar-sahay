# SBI Net Banking Login Failed — How to Fix OTP & Password Errors

SBI Internet Banking (OnlineSBI) is used by millions for fund transfers, bill payments, and account management. Login failures are among the most common complaints. This guide covers every login error and how to resolve it.

## Common Login Problems and Fixes

### 1. Wrong Password Error

**Possible causes:** Typo, Caps Lock on, password expired, copy-paste issue with virtual keyboard.

**Fix:**
1. SBI's login page uses a **virtual keyboard** — you must click each character, not type physically
2. Ensure Caps Lock is off and you're clicking the correct characters
3. If you've genuinely forgotten your password:
   - Go to [onlinesbi.sbi](https://retail.onlinesbi.sbi/retail/login.htm)
   - Click **Forgot Login Password**
   - Enter your username → Verify with OTP on registered mobile
   - Set a new password following SBI's password policy
4. Password rules: 8-20 characters, must include uppercase, lowercase, number, and special character

> **Warning:** After **3 consecutive wrong attempts**, your profile gets temporarily locked.

### 2. Profile Locked — "Your Profile Has Been Locked"

**Possible causes:** 3 wrong password attempts, suspicious activity detected.

**Fix:**
1. **Wait 24 hours** — the profile auto-unlocks after 24 hours in most cases
2. If you can't wait, visit your **home branch** with:
   - Aadhaar card or PAN card
   - Passbook or account statement
   - Request the branch to unlock your Internet Banking profile
3. You can also call SBI helpline: **1800-425-3800** and request profile unlock after identity verification
4. After unlocking, reset your password using **Forgot Login Password**

### 3. OTP Not Received

**Possible causes:** DND active, network issue, wrong mobile number linked, SBI server delay.

**Fix:**
1. Ensure your **registered mobile number** has active network
2. Wait 2-3 minutes — OTPs may be delayed during peak hours
3. Check if DND is blocking bank SMS:
   - Call your telecom provider and ask to allow transactional SMS
   - Or SMS **START DND** to 1909
4. If your mobile number has changed, update it at your SBI branch first
5. Try using **High Security OTP** option if available on the transaction page
6. As a workaround, try logging in via the [YONO app](/guide/sbi-yono-app-not-working-fix) which may offer alternative verification

### 4. Virtual Keyboard Not Showing

**Possible causes:** JavaScript disabled, browser extension blocking, outdated browser.

**Fix:**
1. SBI requires JavaScript to display the virtual keyboard — ensure it's enabled
2. Disable **ad blockers** and privacy extensions temporarily
3. Try in **Incognito/Private mode** (Ctrl+Shift+N in Chrome)
4. Clear browser cache and cookies for onlinesbi.sbi
5. SBI works best with:
   - Google Chrome (latest version)
   - Mozilla Firefox (latest version)
   - Microsoft Edge
6. Avoid using Safari on Mac for SBI — it has known compatibility issues

### 5. Browser Compatibility Issues

**Possible causes:** Unsupported browser, outdated version, security settings.

**Fix:**
1. Use **Google Chrome** or **Mozilla Firefox** (latest versions) for best results
2. Enable cookies and JavaScript for onlinesbi.sbi
3. If you see a blank page or "Page Cannot Be Displayed":
   - Clear all browser data for SBI domains
   - Disable all browser extensions
   - Try a different browser
4. If using a company/office network, check if the firewall is blocking SBI's portal
5. On mobile, use the **YONO app** instead of browser-based Internet Banking

### 6. "Invalid Username" Error

**Fix:**
1. Your username is **not** your account number — it's the username you set during registration
2. If you've forgotten your username:
   - Go to [onlinesbi.sbi](https://retail.onlinesbi.sbi/retail/login.htm) → **Forgot Username**
   - Enter your account number, CIF number, registered mobile, and date of birth
   - Your username will be sent via SMS
3. CIF number is printed on the first page of your SBI passbook

## How to Reset SBI Internet Banking Password

### Online Method:
1. Visit [retail.onlinesbi.sbi](https://retail.onlinesbi.sbi/retail/login.htm)
2. Click **Forgot Login Password**
3. Select **Reset via OTP** or **Reset via ATM**
4. For OTP method: Enter username → Verify with registered mobile OTP → Create new password
5. For ATM method: Visit any SBI ATM → Select **PIN Generation** → Follow on-screen steps

### Branch Method:
1. Visit your home branch with Aadhaar and passbook
2. Fill the Internet Banking reset form
3. New temporary password will be sent to your registered mobile
4. Log in and change the password immediately

## How to Register for SBI Internet Banking

If you don't have Internet Banking yet:

1. Visit [onlinesbi.sbi](https://www.onlinesbi.sbi/) → **New User Registration**
2. Select **New User** and enter:
   - Account number
   - CIF number
   - Branch code
   - Country and registered mobile number
3. Verify via OTP
4. Set your username and login password
5. Log in and set your transaction password separately

Alternatively, visit your SBI branch and request Internet Banking activation with your KYC documents.

## Important Tips

1. **Never type passwords physically** on SBI's login page — always use the on-screen virtual keyboard
2. **Bookmark** the correct URL: [https://retail.onlinesbi.sbi](https://retail.onlinesbi.sbi) — beware of phishing sites
3. **Log out properly** after every session — don't just close the browser
4. **Change your password** every 90 days for security
5. SBI will **never call or email** asking for your password, OTP, or card details

## Frequently Asked Questions

### How many wrong attempts lock my SBI Net Banking?
Three consecutive wrong password attempts will lock your profile for 24 hours.

### Can I unlock my SBI Internet Banking profile online?
No. You must either wait 24 hours for auto-unlock or visit your home branch to get it unlocked immediately.

### Why does SBI use a virtual keyboard?
The virtual keyboard protects against keylogger malware that can record your physical keystrokes. Always use the on-screen keyboard for password entry.

### Can I use SBI Net Banking on my mobile browser?
Yes, but the experience is limited. SBI recommends using the [YONO app](/guide/sbi-yono-app-not-working-fix) for mobile banking instead.

### My transaction password is different from my login password?
Yes. SBI Internet Banking has two passwords — a **login password** to access your account and a **transaction password** to authorize fund transfers and payments.

### I changed my mobile number. Can I still log in?
You can log in with your username and password, but you won't receive OTPs for transactions. Visit your branch to update your mobile number first.

### Is SBI Internet Banking available 24/7?
Mostly yes, except during scheduled maintenance (typically 11:30 PM to 12:30 AM IST) and occasional unscheduled downtime.
