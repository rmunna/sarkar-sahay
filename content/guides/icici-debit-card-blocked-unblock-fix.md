# ICICI Bank Debit Card Blocked / Not Working — Fix Guide 2026

ICICI Bank debit card issues can be fixed quickly via the iMobile Pay app. Most problems — PIN block, temporary block, international/online transaction disable — resolve within minutes.

---

## Types of ICICI Debit Card Issues

| Issue | Fix |
|-------|-----|
| PIN blocked (3 wrong attempts) | Generate new PIN via iMobile |
| Temporarily blocked (self) | Unblock via iMobile |
| Hot-listed (permanent) | Request new card |
| International disabled | Enable in iMobile Card Controls |
| Online payments failing | Enable CNP in iMobile |
| Card expired | New card via iMobile |

---

## Fix 1: Reset ICICI ATM PIN

**Blocked after wrong PIN attempts:**

1. Open **iMobile Pay** app → Login
2. **"Cards"** → Select your debit card
3. Tap **"Generate PIN"** / **"Forgot ATM PIN"**
4. Enter last 6 digits of debit card + expiry date (MM/YY)
5. OTP on ICICI-registered mobile
6. Set new 4-digit ATM PIN
7. **Works at any ATM immediately**

**Via ICICI Net Banking:**
1. icicibank.com → Login → **"Cards"** → **"Debit Card"** → **"PIN Change"**
2. Same OTP process

**At ATM:**
1. Insert card → Select **"PIN Change"**
2. OTP on registered mobile → Set new PIN

---

## Fix 2: Unblock Temporarily Blocked ICICI Card

1. iMobile Pay → **"Cards"** → Select blocked card
2. **"Unblock Card"** → Confirm
3. Immediately active

---

## Fix 3: Enable ICICI International Transactions

1. iMobile Pay → **"Cards"** → **"Card Controls"** / **"Manage Card"**
2. **"International Transactions"** → Toggle ON
3. Active within 2 minutes

---

## Fix 4: Enable ICICI Online Transactions

For online payment failures (Amazon, Swiggy, Netflix):

1. iMobile Pay → **"Cards"** → **"Card Controls"**
2. **"Online Transactions"** → Toggle ON
3. Works immediately

---

## Fix 5: Request New ICICI Debit Card

1. iMobile Pay → **"Cards"** → **"Request New Debit Card"**
2. Select: Visa Signature / Platinum / Coral (based on eligibility)
3. Confirm delivery address
4. **New card delivered in 5–7 working days**

**ICICI Customer Care:** **1800-1080** (24×7 toll-free)

## Frequently Asked Questions

**ICICI debit card declined at POS even with correct PIN — why?**
Check: (1) Daily POS spending limit in iMobile → Card Controls, (2) Card set to online-only (contactless disabled), (3) Merchant's terminal issue — try another store, (4) Card on hold due to account KYC issue.

**ICICI debit card international — does RuPay work abroad?**
ICICI RuPay cards have limited international acceptance. For international travel: Use ICICI Visa/Mastercard debit card. If you only have RuPay: Apply for an ICICI Visa card at branch or via iMobile.

**My ICICI debit card was used fraudulently — what to do?**
Immediately: Hotlist card via iMobile Pay → **"Block Card"**. Call 1800-1080 to report fraud. File dispute for unauthorized transactions within 3 working days = zero liability (RBI mandate).

**ICICI debit card auto-renewal — will bank send new card before expiry?**
Yes — ICICI auto-dispatches new cards 30–45 days before expiry to registered address. If not received: Request via iMobile → Request Debit Card.

**ICICI Coral vs Platinum vs Signature debit card — which is better?**
Higher tier = more benefits (lounge access, cashback). Coral (basic), Platinum (mid), Signature/Sapphiro (premium — offer lounge access + higher cashback). Card tier depends on account type — upgrade by maintaining higher AMB.
