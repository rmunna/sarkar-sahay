# PNB UPI Blocked or Not Working? Fix (2026)

PNB (Punjab National Bank) UPI works via the **PNB ONE** app and all major UPI apps. Here's how to fix all common PNB UPI issues.

---

## Common PNB UPI Issues

| Issue | Fix |
|-------|-----|
| Wrong UPI PIN 5 times | Reset PIN |
| Account debit freeze | Fix account block |
| Daily limit (₹1 lakh) hit | Wait till midnight |
| UPI not registered | Register via PNB ONE |
| Bank server down | Try after 30 minutes |

---

## Reset PNB Bank UPI PIN

### Via PNB ONE App
1. Open **PNB ONE** → **UPI Services** → **Manage UPI PIN**
2. **"Change UPI PIN"** or **"Forgot UPI PIN"**
3. PNB debit card last 6 digits + expiry → OTP → New 6-digit PIN

### Via PhonePe / GPay
1. App → Bank Accounts → Punjab National Bank
2. **"Forgot UPI PIN"** → PNB debit card details → OTP → New PIN

---

## Register PNB UPI on PNB ONE

1. PNB ONE → **UPI** → **Register/Activate**
2. Select PNB savings account → verify mobile → set UPI PIN
3. Or: Any UPI app → Add Bank → Punjab National Bank → OTP → Set PIN

## Frequently Asked Questions

**PNB UPI daily limit?**
₹1,00,000 per day per account.

**PNB UPI PIN reset via PNB ONE — debit card details not accepted?**
Ensure you're using: Last 6 digits of the 16-digit card number (NOT the card number from the beginning) + expiry month/year as printed on card.

**PNB UPI works on BHIM but fails on GPay — why?**
Remove PNB from GPay → Re-add → Reset PIN within GPay. Each app registers UPI independently.
