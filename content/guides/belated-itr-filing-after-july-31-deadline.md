# Belated ITR Filing After July 31 — What to Do, Late Fee, and Limitations

The standard ITR filing deadline for individuals is **July 31** of each Assessment Year. If you missed it, you can still file under **Section 139(4) — Belated Return** until **December 31** of the same Assessment Year, but with a late filing fee.

> **Bottom line**: File as soon as possible even after the deadline — a belated return is better than no return. Late fee is capped at ₹5,000, which is far less than the consequences of not filing.

## Key Deadlines at a Glance

| Deadline | Action | Section |
|----------|--------|---------|
| **July 31** | Original ITR filing deadline (non-audit) | 139(1) |
| **October 31** | Extended deadline for tax audit cases | 139(1) |
| **December 31** | Last chance for Belated Return | 139(4) |
| After December 31 | Can only file with CBDT condonation | — |

*Assessment Year 2026-27 (FY 2025-26): Original deadline July 31, 2026; belated return by December 31, 2026.*

## Late Filing Fee (Section 234F)

| Total Income | Late Filing Fee |
|-------------|----------------|
| Up to ₹5,00,000 | **₹1,000** |
| Above ₹5,00,000 | **₹5,000** |
| Income below basic exemption limit | **₹0** (no fee) |

The late fee is **flat** — you pay ₹1,000 or ₹5,000 regardless of how many days late you file. Even if you file on December 30 vs August 1, the fee is the same.

**Additional interest**: If you had tax payable (not fully covered by TDS/advance tax), you also pay:
- **Section 234A interest**: 1% per month from July 31 until actual filing date on tax payable
- This is separate from the 234F late fee

## How to File Belated Return

1. Login to **[incometax.gov.in](https://incometax.gov.in/)**
2. File ITR → Select Assessment Year → Select your ITR form (ITR-1, ITR-2, ITR-3, etc.)
3. The portal automatically identifies this as a **Belated Return** if the original deadline has passed
4. Fill in all income, deductions, TDS credits as normal
5. The system calculates and adds the ₹1,000 or ₹5,000 late filing fee automatically
6. Pay any balance tax + late fee + 234A interest
7. E-verify the return within 30 days of submission

## Limitations of Belated Return

Filing after July 31 has these specific disadvantages:

| Limitation | Details |
|-----------|---------|
| **Cannot carry forward capital losses** | Loss from equity/property/other assets cannot be carried to next year if return is belated (Section 80 restriction) |
| **Cannot carry forward business losses** | Business/profession losses cannot be carried forward |
| **Exception**: Unabsorbed depreciation | Can still be carried forward even in belated return |
| **No revision possible** | A belated return can be revised, but only until December 31 (same deadline) — so no extra time |

**Biggest impact**: If you had capital losses from stocks, mutual funds, or property sale in the current year, filing belated means you **lose the ability to carry forward those losses** to set off against future gains. This is a significant financial cost beyond just the late fee.

## What If You Can't File Even by December 31?

If you miss the December 31 belated return deadline, you can only file with a **Condonation of Delay (Section 119(2)(b))**:
1. Write an application to the Principal Commissioner of Income Tax (PCIT) in your jurisdiction
2. Explain the genuine reason for delay (medical emergency, abroad, natural disaster, bereavement)
3. If approved: PCIT issues condonation order → you file the return

The condonation is at PCIT's discretion and is typically granted only for genuine hardship, not casual negligence.

## Do I Need to File If No Tax Is Due?

Even if your total tax after TDS is zero (or you're getting a refund), you should file ITR because:
1. **Refunds**: You cannot claim a TDS refund without filing an ITR
2. **Income proof**: ITR is needed for loans, visas, credit cards
3. **Penalty avoidance**: CBDT may issue notice for non-filing even if income is low
4. **Compulsory filing**: If your gross total income exceeds the basic exemption limit (₹2.5L for non-seniors), filing is mandatory regardless of tax

## Check if You Actually Need to File Late

Some people assume they must file late when they actually don't need to file at all:

| Situation | ITR Required? |
|-----------|-------------|
| Salary with full TDS (employer deducted all tax) and income below ₹2.5L | ❌ No |
| Senior citizen (75+) with only pension + FD interest at same bank | ❌ No (Section 194P) |
| Super senior citizen, all income within exemption limit | ❌ No |
| Income > ₹2.5L but all tax deducted at source (TDS = tax liability) | ✅ Still should file (mandatory above ₹2.5L) |

## E-Verification of Belated Return

After filing, you must e-verify within **30 days** of submission (same as for regular ITR). Without verification, the return is treated as not filed.

E-verify via:
- Aadhaar OTP (fastest)
- Net banking
- Bank EVC
- Physical ITR-V sent to CPC Bengaluru (30-day deadline still applies)

## Frequently Asked Questions

### I forgot to file ITR for FY 2024-25. Can I file now?

FY 2024-25 = AY 2025-26. The original deadline was July 31, 2025; belated return deadline was December 31, 2025. If it's now 2026, you need condonation from PCIT. File a condonation application as soon as possible.

### I need to file for both this year (FY 2025-26) and last year (FY 2024-25). Can I file both now?

For FY 2025-26: Can file belated return till December 31, 2026.
For FY 2024-25: Belated deadline was December 31, 2025 — you need PCIT condonation now.
File each year separately on the IT portal.

### The late fee is deducted from my refund. Will I get less refund?

Yes — if you're getting a ₹5,000 refund but owe a ₹1,000 late fee, you'll receive ₹4,000. The fee is settled before the refund is credited.

### Can I avoid the 234F late fee by filing a belated return on August 1?

No — 234F kicks in the moment you file after July 31. Whether you file August 1 or December 31, the fee is the same (₹1,000 or ₹5,000). File early only to reduce 234A interest on unpaid tax.
