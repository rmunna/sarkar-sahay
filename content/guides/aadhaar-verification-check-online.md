# Aadhaar Verification Check Online: Verify by QR Code & Number

When someone shares their [Aadhaar card](/guide/aadhaar-card-apply-online) with you — as an employer, landlord, or service provider — you need to verify that it is genuine. UIDAI provides multiple official methods to check Aadhaar authenticity online, including number verification, QR code scanning, and offline XML validation. This guide covers all methods step by step.

## Why Verify Aadhaar?

- Prevent fraud from fake or tampered Aadhaar cards
- Confirm identity before onboarding employees or tenants
- Meet KYC compliance requirements
- Validate Aadhaar details without accessing biometric data

## Method 1: Verify Aadhaar Number Online

This is the simplest method to check if an Aadhaar number is valid and issued by UIDAI.

### Steps to Verify Aadhaar Number

1. Visit the official portal at [https://myaadhaar.uidai.gov.in/](https://myaadhaar.uidai.gov.in/)
2. Click on **"Verify Aadhaar Number"** under Aadhaar Services
3. Enter the 12-digit Aadhaar number
4. Enter the security code (captcha)
5. Click **"Verify"**
6. The system will confirm if the Aadhaar number exists in the UIDAI database

**What it shows:** Only confirms whether the number is valid or not. It does NOT reveal the holder's name, address, or photo for privacy reasons.

## Method 2: Verify Aadhaar Using QR Code

Every Aadhaar card (physical, e-Aadhaar, or mAadhaar) has a QR code that contains digitally signed data. Scanning this QR code is the most reliable way to verify Aadhaar.

### Steps for QR Code Verification

1. Download the **Aadhaar QR Code Scanner** app from:
   - [Google Play Store](https://play.google.com/store/apps/details?id=in.gov.uidai.qrcodescannerapp) (Android)
   - Also available on UIDAI website
2. Open the app and point your camera at the QR code on the Aadhaar card
3. The app reads the digitally signed data embedded in the QR code
4. It displays the holder's **photo, name, date of birth, gender, and masked address**
5. A **green tick** confirms the QR code is authentic and issued by UIDAI

**Why this is the best method:** The QR code contains a digital signature from UIDAI. If anyone tampers with the card, the signature verification will fail, and the app will show an error.

### Types of QR Codes on Aadhaar

| QR Code Type | Found On | Data Contained |
|---|---|---|
| Secure QR Code | e-Aadhaar, Aadhaar letter (post-2018) | Photo + demographics + digital signature |
| Old QR Code | Older Aadhaar cards (pre-2018) | Demographics only (no photo) |

## Method 3: Offline XML Verification

Aadhaar Offline XML (also called Paperless Offline KYC) is a digitally signed XML file that can be shared for verification without exposing the Aadhaar number.

### Steps to Verify Offline XML

1. Ask the Aadhaar holder to [download their Offline KYC XML](/guide/aadhaar-offline-kyc-xml) from myaadhaar.uidai.gov.in
2. The holder will share the XML zip file along with a **share code** (4-digit password)
3. Use UIDAI's **Offline e-KYC Verification** tool or any authorized software to open the XML
4. Enter the share code to decrypt
5. Verify the digital signature to confirm authenticity
6. The XML contains: name, date of birth, gender, address, photo, and a reference ID (not Aadhaar number)

**Advantages of XML verification:**
- No Aadhaar number exposure — uses a reference ID instead
- Digitally signed by UIDAI — tamper-proof
- No internet needed after downloading
- Valid for verification by banks, telecom, and other agencies

## Method 4: Bulk Aadhaar Verification (For Organizations)

Organizations that need to verify multiple Aadhaar numbers can use UIDAI's bulk verification service.

### How Bulk Verification Works

1. Visit [https://resident.uidai.gov.in/verify](https://resident.uidai.gov.in/verify)
2. Organizations can verify Aadhaar numbers in bulk through UIDAI's authentication services
3. Requires a formal agreement with UIDAI as an **Authentication User Agency (AUA)**
4. Contact UIDAI at [help@uidai.gov.in](mailto:help@uidai.gov.in) for onboarding

**Note:** Bulk authentication is available only to licensed entities. Individual users should use the single verification method.

## Important Tips

1. **Always use official UIDAI tools** — do not use third-party QR scanners, as they may not validate digital signatures
2. **QR code verification is the gold standard** — it is the only method that shows the photo and verifies the digital signature
3. **Number verification only confirms existence** — it does not confirm the card belongs to the person presenting it
4. **For KYC compliance, use Offline XML** — it provides complete details without exposing the Aadhaar number
5. **Never collect Aadhaar numbers unnecessarily** — as per the Aadhaar Act, unauthorized storage or use of Aadhaar data attracts penalties

## FAQs

### Can I verify someone's Aadhaar without their consent?

No. Aadhaar verification must be done with the consent of the Aadhaar holder. Under the Aadhaar Act 2016, using someone's Aadhaar data without consent is a punishable offence.

### Does Aadhaar number verification show the person's name or photo?

No. The online number verification on myaadhaar.uidai.gov.in only confirms whether the number is valid. It does not reveal any personal details.

### What if the QR code scanner shows an error?

If the QR code scanner shows a verification failure, the Aadhaar card may have been tampered with or the QR code is damaged. Ask the holder to download a fresh [e-Aadhaar](/guide/aadhaar-card-download-online) which will have an updated secure QR code.

### Is Offline XML verification legally valid?

Yes. UIDAI's Offline KYC XML is digitally signed and accepted by banks, telecom companies, mutual funds, and other regulated entities for KYC purposes.

### Can I verify Aadhaar using the Virtual ID (VID)?

Yes. You can verify Aadhaar using the [Virtual ID (VID)](/guide/aadhaar-virtual-id-generate) instead of the actual Aadhaar number. The VID maps to the Aadhaar number in UIDAI's system but keeps the actual number hidden.

### How do I know if an e-Aadhaar PDF is genuine?

Every e-Aadhaar PDF is digitally signed by UIDAI. Open the PDF in Adobe Reader and check the signature panel — it should show a valid signature from "UIDAI" with no modifications since signing.
