# SBI Net Banking Blocked or Login Failed? Unblock & Reset Guide (2026)

SBI internet banking (onlinesbi.sbi.co.in) locks after **3 consecutive wrong login attempts**. If you've forgotten your username or password, it's easily reset online using your mobile number and ATM card — no branch visit needed in most cases.

---

## Common Causes of SBI Net Banking Lock

| Cause | Fix |
|-------|-----|
| Wrong password 3 times | Reset via "Forgot Login Password" |
| Wrong profile/transaction password | Reset profile password separately |
| Username forgotten | "Forgot Username" option |
| OTP not received (mobile changed) | Branch visit for mobile update |
| Account-level restriction | Fix account block first |

---

## Method 1: Reset SBI Net Banking Login Password (Online)

1. Go to **[onlinesbi.sbi.co.in](https://onlinesbi.sbi.co.in)**
2. Click **"Login"** → **"Forgot Login Password"**
3. Enter your **SBI Username** (usually 8-character alphanumeric)
4. Enter your **Account Number**
5. Enter **Date of Birth** + **Country**
6. OTP sent to registered mobile → Enter OTP
7. Set **new login password** → Confirm
8. Try logging in with new password

**Timeline:** 3–5 minutes

---

## Method 2: Forgot SBI Net Banking Username

If you've also forgotten your username:

1. **onlinesbi.sbi.co.in** → Login → **"Forgot Username"**
2. Enter: Account number + Registered mobile number
3. OTP sent → Enter OTP
4. **Username displayed on screen** + emailed to registered email

---

## Method 3: Reset SBI Profile/Transaction Password

SBI has two passwords:
- **Login Password:** To log into internet banking
- **Profile Password:** For making changes (adding beneficiary, etc.)

Reset Profile Password:
1. Login to SBI net banking → **"My Account" → "Profile"**
2. **"Change Profile Password"**
3. Old password → New password → Confirm
4. If forgotten: **"Forgot Profile Password"** → OTP verification

---

## Method 4: Via SBI YONO App

1. Open **YONO** app
2. If YONO credentials work (separate from net banking sometimes)
3. YONO → **More → Internet Banking → Reset Password**
4. Or: YONO login → Account → Services → Net Banking Reset

---

## What Is SBI Net Banking Username?

Your SBI net banking username was created during registration:
- **8-character alphanumeric** (e.g., "JOHNA123")
- **Not your account number** (which is 14+ digits)

| Where to Find Username |
|-----------------------|
| Your registration confirmation email |
| SBI welcome letter |
| Via "Forgot Username" on onlinesbi.sbi.co.in |

## SBI Net Banking OTP Not Received

1. Wait 2 minutes → click **"Resend OTP"**
2. Check if mobile number is registered correctly
3. Verify: Call 1800-11-2211 → ask "What mobile number is registered for account XXXX?"
4. If mobile changed: Visit branch with Aadhaar to update → then reset password

---

## SBI Net Banking Blocked (Not Password Issue)

If SBI has placed a security block (not just wrong password):

1. Call **1800-11-2211** (24/7)
2. "My SBI net banking is blocked. I need it unblocked."
3. Verify: Account number + registered mobile OTP + ATM PIN (for identity)
4. Agent processes unblock — takes 15–30 minutes

---

## SBI Net Banking First-Time Activation

If you have an SBI account but never activated net banking:

1. **onlinesbi.sbi.co.in** → **"New User Registration"**
2. Enter: Account number + CIF number (on passbook first page) + Branch code + mobile number
3. OTP on registered mobile → Set username and password
4. Alternatively: YONO app → Register with account details → Activate net banking

---

## SBI Two-Factor Authentication

SBI sends **second-factor OTP** for:
- Login from new device
- Any financial transaction
- Beneficiary addition (OTP + 30-minute wait before transfer allowed)

If OTP stops coming:
- Mobile must be active and registered with SBI
- Check spam/block filters for SMS

## Frequently Asked Questions

**How do I activate SBI YONO if net banking is blocked?**
YONO uses a separate mPIN after initial activation. If YONO was previously activated, try the app with your YONO MPIN — it may work even if net banking is blocked. Reset MPIN via YONO → Forgot MPIN → OTP on mobile.

**Can I reset SBI net banking password without ATM card?**
Yes — the "Forgot Password" flow uses account number + mobile OTP (no ATM card needed). ATM card is needed only for initial net banking activation if you have no registered mobile OTP.

**SBI says "Your account is locked for security" when I login — what to do?**
This is the system blocking after multiple wrong attempts. Use "Forgot Password" to reset — this automatically unlocks the account and sets a new password. Or call 1800-11-2211.

**My SBI net banking works but beneficiary addition keeps failing — why?**
After adding a new beneficiary, SBI mandates a **30-minute waiting period** before you can transfer. Also, OTP confirmation is required. This is a security feature — not a bug.

**Can I do NEFT/RTGS on SBI net banking without OTP?**
No — all financial transactions (NEFT, RTGS, IMPS, NEFT to new beneficiary) require OTP confirmation on your registered mobile. If your mobile number isn't active, you cannot do net banking transfers.
