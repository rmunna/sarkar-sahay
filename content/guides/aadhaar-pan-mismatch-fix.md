# Aadhaar PAN Name Mismatch? Fix Linking Error (2026)

Linking Aadhaar with PAN is mandatory for filing Income Tax Returns (ITR) and to keep your PAN active. But many Indians face a "Name/DOB mismatch" error when trying to link. This guide explains how to fix it.

> **Disclaimer:** CitizenNest is an independent platform and is not affiliated with UIDAI or Income Tax Department.

## Why Aadhaar-PAN Linking Fails

The Income Tax system matches your **name, date of birth, and gender** across both databases. Common mismatches include:

| Mismatch Type | Example |
|--------------|---------|
| Name spelling | "Rajesh Kumar" (PAN) vs "Rajesh Kumaar" (Aadhaar) |
| Name format | "R. Kumar" (PAN) vs "Rajesh Kumar" (Aadhaar) |
| Middle name | PAN has middle name, Aadhaar doesn't |
| Father's name in name field | Different ordering |
| Date of birth | 15/03/1990 (PAN) vs 15/04/1990 (Aadhaar) |
| Gender | Male (PAN) vs Female (Aadhaar) — data entry error |

## Step 1: Check What's Different

Before fixing, identify the exact mismatch:

1. **Check PAN details:** Visit [incometax.gov.in](https://www.incometax.gov.in) → Login → Profile → Check name and DOB
2. **Check Aadhaar details:** Visit [myaadhaar.uidai.gov.in](https://myaadhaar.uidai.gov.in) → Login with OTP → Check name and DOB
3. **Compare both** — note exactly which field doesn't match

## Step 2: Decide Which to Correct

| Situation | What to Fix |
|-----------|------------|
| PAN has wrong/short name | Correct PAN |
| Aadhaar has wrong name | Correct Aadhaar |
| Both have errors | Fix both |
| Minor spelling difference | Fix either one |
| DOB wrong on PAN | Correct PAN |
| DOB wrong on Aadhaar | Correct Aadhaar |

**Tip:** It's generally easier and faster to correct PAN details than Aadhaar.

## Option A: Correct Your PAN Details

### Online PAN Correction (via NSDL/Protean):
1. Visit [onlineservices.nsdl.com](https://www.onlineservices.nsdl.com/paam/endUserRegisterContact.html)
2. Select **"Changes or Correction in existing PAN Data"**
3. Fill the form with correct details
4. Upload supporting documents (Aadhaar, passport, etc.)
5. Pay the fee: **₹107** (for Indian address) or **₹1,017** (foreign address)
6. Submit and note the acknowledgment number
7. Processing time: **15-20 working days**

### Documents Required for PAN Correction:
- Aadhaar card (for name/DOB proof)
- Passport (alternative proof)
- Voter ID (alternative proof)
- Birth certificate (for DOB correction)

## Option B: Correct Your Aadhaar Details

### Online Aadhaar Update:
1. Visit [myaadhaar.uidai.gov.in](https://myaadhaar.uidai.gov.in)
2. Login with Aadhaar number + OTP
3. Click **"Update Aadhaar"**
4. Select the field to update (Name/DOB/Gender)
5. Upload supporting document
6. Pay **₹50** processing fee
7. Processing time: **7-15 working days**

**Note:** DOB can only be updated **once** on Aadhaar, and only at an Aadhaar Enrollment Center (not online).

### At Aadhaar Enrollment Center:
1. Find your nearest center at [appointments.uidai.gov.in](https://appointments.uidai.gov.in)
2. Carry original documents + photocopies
3. Fill the Aadhaar update form
4. Submit biometrics
5. Pay ₹50
6. Get acknowledgment slip with URN (Update Request Number)

See our [Aadhaar enrollment center guide](/guide/aadhaar-enrollment-center-near-me) for detailed steps.

## Step 3: Try Linking Again After Correction

After your PAN or Aadhaar is updated:

### Link via Income Tax Portal:
1. Visit [incometax.gov.in](https://www.incometax.gov.in)
2. Click **"Link Aadhaar"** on the homepage
3. Enter PAN number and Aadhaar number
4. Verify name and DOB match
5. Enter OTP sent to Aadhaar-registered mobile
6. Pay linking fee: **₹1,000** (if linking after the deadline)
7. Submit

### Link via SMS:
Send SMS: `UIDPAN <12-digit Aadhaar> <10-digit PAN>` to **567678** or **56161**

## What If Minor Name Difference?

For small differences (like "Raj Kumar" vs "Raj Kumar Singh"), the system sometimes accepts the link if:
- First name and surname match
- DOB and gender match exactly

Try linking first — it may go through despite a minor difference.

## Penalty for Not Linking Aadhaar-PAN

| Consequence | Details |
|------------|---------|
| PAN becomes inoperative | Can't file ITR, open bank accounts, or do high-value transactions |
| Higher TDS | 20% TDS instead of normal rate on income |
| Can't process refunds | Pending IT refunds won't be processed |
| Linking fee | ₹1,000 penalty for late linking |

## Check Aadhaar-PAN Link Status

1. Visit [incometax.gov.in](https://www.incometax.gov.in)
2. Click **"Link Aadhaar Status"**
3. Enter PAN and Aadhaar numbers
4. Click **"View Link Aadhaar Status"**
5. It will show if they're linked or the error

## Frequently Asked Questions

### How to fix Aadhaar PAN name mismatch?
Compare your name on both documents, identify the incorrect one, and apply for correction. You can correct PAN online via NSDL (₹107) or update Aadhaar at myaadhaar.uidai.gov.in (₹50).

### What is the fee for Aadhaar-PAN linking?
Linking after the government deadline costs ₹1,000. This fee must be paid via challan on the Income Tax portal before linking.

### Can I link Aadhaar and PAN with different names?
No, the names must match. Minor variations may be accepted, but significant differences will cause linking failure. Correct either document first.

### How long does PAN correction take?
PAN correction via NSDL takes 15-20 working days. You'll receive an updated PAN card by post. The digital PAN is updated faster.

### What if my DOB is different on Aadhaar and PAN?
You must correct the DOB on whichever document has the error. For PAN, apply online via NSDL. For Aadhaar, visit an enrollment center (DOB changes can't be done online).

### Is Aadhaar-PAN linking mandatory?
Yes, it's mandatory for all PAN holders. Failure to link makes your PAN inoperative, resulting in higher TDS, inability to file ITR, and restrictions on financial transactions.

### Can I file ITR without Aadhaar-PAN linking?
No. You cannot file ITR if your PAN and Aadhaar are not linked. Link them first, then file your return. The Income Tax portal won't accept ITR without linking.

### What if Aadhaar has father's name but PAN doesn't?
This shouldn't cause a mismatch as the system primarily checks your name (first + last), DOB, and gender. If linking still fails, update PAN to include the name exactly as on Aadhaar.
