# Debit Card Blocked / Not Working — All Banks Fix Guide 2026

A blocked debit card stops all ATM withdrawals, POS transactions, and online payments. This guide covers every reason a debit card gets blocked and how to unblock it — for all major Indian banks.

---

## Types of Debit Card Blocks

| Block Type | Cause | How to Fix |
|-----------|-------|-----------|
| **ATM PIN block** | 3 wrong PIN attempts | PIN reset at ATM / bank app |
| **Temporary block** | You blocked it via app | Unblock via same app |
| **Permanent block** | Lost/stolen card blocked | New card request |
| **International block** | International transactions disabled by default | Enable via app |
| **Online transaction block** | e-Commerce disabled by RBI mandate | Enable via app |
| **Account-level block** | Account frozen/KYC pending | Fix underlying account issue |
| **Expiry** | Card expired | Request renewal card |

---

## Fix 1: Reset ATM PIN (PIN Blocked)

After 3 wrong PIN attempts, the PIN is blocked (not the card). Fix:

**At any ATM:**
1. Insert your card → Don't enter PIN → Select **"PIN Change"** / **"Green PIN"** (SBI) / **"PIN Generation"**
2. Enter OTP received on registered mobile
3. Set new 4-digit PIN
4. **Card works immediately**

**Via Mobile App (most banks):**
- **SBI**: YONO → Cards → **"Generate Green PIN"**
- **HDFC**: HDFC App → Cards → **"Generate PIN"**
- **ICICI**: iMobile Pay → Cards → **"Set PIN"**
- **Axis**: Axis Mobile → Cards → **"Reset PIN"**
- **Kotak**: Kotak Mobile → Cards → **"Generate PIN"**

---

## Fix 2: Unblock Temporarily Blocked Card

If you temporarily blocked your card via app (common for lost card alert):

**All apps allow instant unblock:**
- YONO SBI → Cards → Select card → **"Unblock"**
- HDFC App → Cards → **"Hot Listing"** → **"Remove Block"**
- iMobile Pay → Cards → **"Block/Unblock Card"** → Unblock
- Axis Mobile → Cards → Toggle off "Block"
- Kotak Mobile → Cards → **"Block/Unblock"**

**If permanently blocked** (hot-listed after loss): Cannot unblock. Must request new card.

---

## Fix 3: Enable International Transactions

RBI mandates that international card transactions are disabled by default for most cards. Enable before international travel or foreign website purchase:

**All banks — enable via app:**
- **SBI**: YONO → Cards → **"International Use"** → Enable
- **HDFC**: HDFC App → Cards → **"International Transactions"** → Toggle on
- **ICICI**: iMobile → Cards → **"Manage Card"** → International → Enable
- **Axis**: Axis Mobile → Cards → **"International Transactions"** → On
- **Kotak**: Kotak Mobile → Cards → **"Card Control"** → International → On

Set limit: Most banks let you set per-day international spend limit.

---

## Fix 4: Enable Online / e-Commerce Transactions

Similar to international, online transactions may be disabled by default:

**Enable in-app:**
- All banking apps have "Card Controls" or "Manage Card" section
- Toggle on: **"Online/e-Commerce Transactions"**
- Set daily online limit if needed

**Why this matters:** RBI's card tokenization and safety rules led many banks to disable CNP (Card Not Present) transactions by default for less-active customers.

---

## Fix 5: New/Replacement Card Request

For expired or permanently blocked cards:

| Bank | How to Request New Card |
|------|------------------------|
| **SBI** | YONO → Cards → **"Request New Debit Card"** |
| **HDFC** | HDFC App → Cards → **"Request New Card"** |
| **ICICI** | iMobile → Cards → **"Request Replacement"** |
| **Axis** | Axis Mobile → Cards → **"Order New Card"** |
| **Kotak** | Kotak App → Cards → **"Replace Card"** |
| **PNB** | PNB ONE → Cards → **"New Debit Card"** |

**Delivery time:** 5–10 working days. Most banks allow same-day card activation once received.

## Special: RBI Zero Liability for Unauthorized Card Use

If your debit card is used fraudulently:

1. Report to bank **immediately** (hotlist/block card first via app)
2. Report to bank within **3 working days** → **Zero liability** (you get full refund)
3. Report 4–7 working days late → Limited liability (max ₹10,000 depending on account type)
4. Report > 7 working days → Bank decides case-by-case

**Always hotlist the card first** (takes 10 seconds via app), then call customer care to report fraud.

## Frequently Asked Questions

**ATM shows "Card Blocked" — is PIN block different from card block?**
Yes. PIN block: Only the PIN is locked, card itself is fine. Reset PIN at ATM or via app. Card block: Full card suspended — cannot transact even with correct PIN. Must unblock via app or get new card.

**Debit card declined at POS but ATM works — why?**
If ATM works but POS fails: (1) POS machine issue — try another merchant, (2) NFC/contactless disabled in app — enable it, (3) Daily spending limit reached — check in app, (4) Merchant's bank terminal issue — retry later.

**Debit card not working on Amazon/Flipkart — why?**
Most likely: Online transactions (e-Commerce) are disabled on your card. Fix: Enable via your bank app → Card Controls → e-Commerce toggle. Takes effect within minutes.

**My SBI ATM card expired — can I use it for online transactions until new card arrives?**
No — expired card cannot be used for any transaction once the expiry date passes. Request new card well before expiry (30 days before).

**Kotak 811 — I have a virtual debit card. How do I unblock it?**
Kotak 811 virtual card: Kotak Mobile → Cards → Select virtual card → View controls. If blocked: Same unblock process as physical card. If KYC expired: Complete Video KYC first (KYC expiry blocks all card functions).
