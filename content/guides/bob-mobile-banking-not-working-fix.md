# Bank of Baroda Mobile Banking Not Working? How to Fix It

Bank of Baroda's **bob World** app is the primary mobile banking platform for BoB customers. But users frequently face login failures, MPIN errors, device binding problems, and app crashes. This guide covers every common issue and its fix.

## Common bob World App Problems & Fixes

### 1. bob World App Login Failed

**Possible Causes & Solutions:**

| Cause | Fix |
|-------|-----|
| Wrong MPIN entered | Use "Forgot MPIN" to reset |
| App version outdated | Update from Play Store / App Store |
| Account not linked | Re-register in the app |
| Device changed | Complete device binding on new phone |
| Server maintenance | Try after 30 minutes |

**Steps to Fix Login:**
1. Ensure you're entering the correct **registered mobile number**
2. Check that your **MPIN** is correct (4 or 6 digits depending on setup)
3. If locked out after 3 wrong attempts, wait **24 hours** or reset MPIN
4. Update the bob World app to the latest version
5. Clear cache: Settings → Apps → bob World → Clear Cache

---

### 2. bob World MPIN Reset

**Forgot MPIN:**
1. Open **bob World** app
2. Tap **"Forgot MPIN"** on the login screen
3. Enter your **registered mobile number** and **account number**
4. Verify with **OTP** and **debit card** last 6 digits + expiry date
5. Set a new MPIN

**MPIN Locked (3 Wrong Attempts):**
- Wait **24 hours** for auto-unlock, OR
- Use "Forgot MPIN" to reset immediately
- If debit card verification also fails, visit your BoB branch

**MPIN Rules:**
- Must be 4 or 6 digits (as configured)
- Avoid simple patterns like 1234 or 0000
- Don't use your birth year or ATM PIN

---

### 3. bob World Device Binding Error

bob World links to **one device** at a time. If you change phones:

**How to Bind New Device:**
1. Install bob World on new phone
2. Open app → Select **"Existing Customer"**
3. Enter registered **mobile number**
4. Verify via **OTP**
5. Authenticate with **debit card details** (last 6 digits + expiry)
6. Set new MPIN
7. Device binding completes automatically

**Binding Failed? Try These:**
- Ensure old device doesn't have the app open simultaneously
- Check that registered mobile number is active and in the new phone
- Clear app data and try again
- If repeated failure, visit branch to **de-register mobile banking** and re-register

---

### 4. bob World App Crashing or Not Opening

**Quick Fixes:**
1. **Update the app** — Go to Play Store/App Store and update bob World
2. **Clear cache and data** — Settings → Apps → bob World → Clear Cache → Clear Data (you'll need to re-login)
3. **Free up storage** — Ensure at least 300MB free space
4. **Restart phone** — Simple reboot fixes many issues
5. **Reinstall** — Uninstall and reinstall from official store
6. **Check OS compatibility** — bob World requires Android 6.0+ or iOS 13+

**App Stuck on Loading Screen:**
- Check internet connection (switch between Wi-Fi and mobile data)
- Disable VPN if active
- Try after 15-30 minutes (could be server-side)

---

### 5. bob World Server Down / Maintenance

Bank of Baroda performs scheduled maintenance that can cause temporary outages:

- **Usual maintenance window:** 11:00 PM – 1:00 AM
- **Extended maintenance:** Announced via SMS or app notification

**How to Check if Server is Down:**
1. Check [Bank of Baroda's official website](https://www.bankofbaroda.in/)
2. Look for maintenance banners on the app login screen
3. Check BoB's social media handles for outage announcements
4. If the issue persists beyond 2 hours outside maintenance, call customer care

---

### 6. bob World OTP Not Received

1. Ensure your **registered mobile** has network signal
2. Wait **2-3 minutes** before requesting resend
3. Check if bank SMS sender (BoBaroda/BOBSMS) is blocked
4. Disable DND for transactional SMS — send **START** to **1909**
5. If you recently ported your number, visit branch to update records
6. Try in an area with better network coverage

---

### 7. bob World Transaction Failed

| Issue | Solution |
|-------|----------|
| "Transaction limit exceeded" | Check daily limit in app settings; visit branch to increase |
| "Beneficiary not verified" | Wait for cooling period (usually 30 min to 24 hours for new beneficiaries) |
| "Insufficient balance" | Check account balance including minimum balance requirement |
| "Server timeout" | Try again; check if amount was debited in transaction history |
| "MPIN incorrect" | Enter correct MPIN; reset if forgotten |

**If money is debited but not credited to beneficiary:**
- Wait **48 hours** for auto-reversal
- If not reversed, file complaint in bob World → **"Raise Complaint"**
- Or call **1800-258-4455** with transaction reference number

## Frequently Asked Questions

### Q1. How do I register for bob World mobile banking?
Download bob World from Play Store or App Store. Open the app, select "New Customer" or "Existing Customer," enter your account number and registered mobile number, verify via OTP and debit card, and set your MPIN.

### Q2. Why does bob World show "Login Failed" every time?
This usually means wrong MPIN, outdated app, or device binding issue. Reset your MPIN using "Forgot MPIN," update the app, and ensure you're using the device linked to your account.

### Q3. How do I change my registered mobile number for bob World?
Visit your nearest Bank of Baroda branch with your passbook and ID proof. Mobile number change cannot be done online for security reasons. After branch update, re-register on bob World.

### Q4. Can I use bob World on two devices?
No, bob World is linked to one device at a time. To switch devices, install on the new phone and register as an existing customer. The old device will be automatically de-linked.

### Q5. bob World shows "Service Temporarily Unavailable." What to do?
This indicates server maintenance or a temporary outage. Wait 30 minutes and try again. If it persists, check BoB's website or call 1800-258-4455.

### Q6. How do I increase my bob World transaction limit?
Default UPI limit is ₹1 lakh per transaction. For NEFT/IMPS limits, visit your branch or call customer care. Some limits can be changed in bob World → Settings → Transaction Limits.

### Q7. Is bob World safe to use?
Yes, bob World uses 256-bit encryption, MPIN authentication, and device binding for security. Enable biometric login and transaction alerts for additional protection. Never install the app from unofficial sources.
