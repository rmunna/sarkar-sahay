# Indian Bank Mobile Banking Not Working? How to Fix App Errors

Indian Bank's **IndOASIS** app provides mobile banking services including fund transfers, bill payments, and account management. Users often face app crashes, login failures, MPIN issues, and transaction errors. This guide covers all common IndOASIS problems and solutions.

## Common IndOASIS App Problems & Fixes

### 1. IndOASIS App Crashing or Not Opening

**Quick Fixes:**
1. **Update the app** — Download latest version from [Google Play Store](https://play.google.com/store/apps/details?id=com.IndianBank.IndOASIS) or App Store
2. **Clear cache** — Settings → Apps → IndOASIS → Clear Cache
3. **Clear data** (will require re-login) — Settings → Apps → IndOASIS → Clear Data
4. **Free storage** — Ensure at least 250MB free space on phone
5. **Restart phone** — Fixes temporary memory issues
6. **Reinstall** — Uninstall completely and reinstall from official store

**Compatibility Requirements:**
- Android 7.0 or above
- iOS 13 or above
- Rooted/jailbroken devices are blocked by the app

**App Stuck on Splash Screen:**
- Switch between Wi-Fi and mobile data
- Disable VPN or proxy connections
- Check if Indian Bank servers are under maintenance

### 2. IndOASIS Login Failed

**Common Login Errors & Fixes:**

| Error | Cause | Fix |
|-------|-------|-----|
| "Invalid MPIN" | Wrong MPIN entered | Reset via Forgot MPIN |
| "User Not Registered" | App not linked to account | Register as new/existing user |
| "Device Not Registered" | Using different phone | Complete device re-binding |
| "Account Blocked" | Multiple wrong attempts | Wait 24 hours or call customer care |
| "Session Expired" | Idle timeout | Restart the app and log in again |

**Steps to Fix Login:**
1. Ensure you're using the **registered mobile number's SIM** in the phone
2. Check your **MPIN** — it's different from your ATM PIN
3. Update the app to the latest version
4. If locked out, wait 24 hours for auto-unlock

### 3. Indian Bank MPIN Reset

**Forgot MPIN:**
1. Open IndOASIS app
2. Tap **"Forgot MPIN"** on login screen
3. Enter **registered mobile number** and **account number**
4. Verify with **OTP** sent to registered mobile
5. Enter **debit card** last 6 digits and expiry date
6. Set new MPIN (4 or 6 digits)

**MPIN Locked After Wrong Attempts:**
- Wait **24 hours** for automatic unlock
- Or use "Forgot MPIN" to reset immediately
- If debit card verification fails, visit your Indian Bank branch

**Tips for MPIN:**
- Don't use birth year, 1234, or 0000
- Don't reuse your ATM PIN as MPIN
- Change MPIN periodically from app Settings

### 4. IndOASIS Device Registration Error

IndOASIS works on **one device** per account.

**Register New Device:**
1. Install IndOASIS on the new phone (must have registered SIM)
2. Open app → Select **"Existing User"**
3. Enter **registered mobile number**
4. Verify with **OTP**
5. Authenticate with **debit card details**
6. Set new MPIN
7. Device binding completes

**Device Binding Failed?**
- Ensure the **registered SIM card** is in the new phone (not just the number via call forwarding)
- The old device must not have an active IndOASIS session
- Clear app data and try again
- If still failing, visit branch to **de-register** mobile banking and re-register

**Changed Mobile Number?**
- Visit Indian Bank branch with passbook + ID proof
- Submit mobile number change request
- After update (1-2 working days), register on IndOASIS with new number

### 5. IndOASIS Transactions Failing

**Transaction Error Fixes:**

| Problem | Solution |
|---------|----------|
| "Transaction Limit Exceeded" | Check limits in Settings; visit branch to increase |
| "Beneficiary Not Active" | New beneficiaries have a cooling period (up to 24 hours) |
| "Insufficient Balance" | Check balance including minimum balance requirement |
| "Server Error / Timeout" | Try after 15-30 minutes; avoid peak hours (1st/last day of month) |
| "MPIN Incorrect" | Enter correct MPIN; reset if forgotten |
| "Transaction Declined" | Check if account is active; may need KYC update |

**Money Debited But Not Credited:**
1. Wait **48 hours** — auto-reversal happens in most cases
2. Check transaction status in IndOASIS → **"Transaction History"**
3. If not reversed, file complaint via IndOASIS → **"Service Request"**
4. Or call **1800-425-00-000** with transaction reference number

**UPI Transactions Failing:**
- Ensure UPI ID is correctly set up in IndOASIS
- Check if the recipient's UPI ID/VPA is valid
- For UPI lite, ensure sufficient UPI lite balance
- Try re-linking your bank account in UPI settings

## Frequently Asked Questions

### Q1. How do I register for Indian Bank mobile banking?
Download IndOASIS from Play Store or App Store. Open the app, select your account type, enter account number and registered mobile number, verify via OTP and debit card, and set your MPIN.

### Q2. Why is IndOASIS showing "Login Failed"?
This can mean wrong MPIN, unregistered device, or locked account. Reset MPIN via "Forgot MPIN," ensure you're using the registered device, and wait 24 hours if your account is locked.

### Q3. IndOASIS OTP is not coming. What should I do?
Check mobile network signal, wait 3-5 minutes, and try resending. Ensure DND is disabled for transactional SMS (send START to 1909). If the issue persists, call 1800-425-00-000.

### Q4. Can I use IndOASIS on two phones?
No, IndOASIS is linked to one device at a time. To switch, install on the new phone (with registered SIM) and register as an existing user. The old device is automatically de-linked.

### Q5. How do I increase my IndOASIS transaction limit?
Default limits vary by transaction type. Visit your Indian Bank branch with a written request and ID proof to increase NEFT/IMPS/UPI limits. Some limits can be adjusted in app Settings.

### Q6. My Indian Bank account is dormant. Can I still use IndOASIS?
No, dormant accounts cannot use mobile banking. First reactivate your account by visiting the branch with KYC documents. See our [dormant account reactivation guide](/guide/bank-account-dormant-inactive-reactivate) for help.

### Q7. IndOASIS was working but suddenly stopped. What happened?
This could be due to an app update requirement, server maintenance, or expired credentials. Update the app, check your internet connection, and try after 30 minutes. If the issue persists, clear data and re-register.
