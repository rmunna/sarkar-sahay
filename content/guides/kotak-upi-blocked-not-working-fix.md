# Kotak Mahindra Bank UPI Blocked or Not Working? Fix (2026)

Kotak Mahindra Bank UPI works via the **Kotak Mobile Banking** app and all major UPI apps including PhonePe, Google Pay. This guide covers all common Kotak UPI issues.

---

## Common Kotak UPI Issues

| Issue | Fix |
|-------|-----|
| Wrong UPI PIN 5 times | Reset PIN |
| Account debit freeze | Fix account block |
| Daily limit (₹1 lakh) hit | Wait till midnight |
| UPI not registered | Register via Kotak app |
| Bank server down | Try after 30 minutes |

---

## Reset Kotak Bank UPI PIN

### Via Kotak Mobile Banking App
1. Open **Kotak Mobile Banking** → **UPI**
2. Select your account → **"Change/Forgot UPI PIN"**
3. Debit card last 6 digits + expiry → OTP → New 6-digit PIN

### Via PhonePe / GPay
1. App → Bank Accounts → Kotak Mahindra Bank
2. **"Forgot UPI PIN"** → Kotak debit card details → OTP → New PIN

---

## Kotak 811 Account UPI — Register & Fix

Kotak 811 (zero-balance digital account) UPI:

1. Kotak app → **811 Account** → **UPI**
2. **"Set/Reset UPI PIN"**
3. 811 account holders: Use your Kotak 811 debit card (virtual card in app is accepted)

---

## Register Kotak Bank UPI

1. Kotak Mobile Banking → **UPI** → **Activate/Register**
2. Select savings account → verify registered mobile
3. Set new UPI PIN
4. Or: Any UPI app → Add Bank → Kotak Mahindra Bank

## Frequently Asked Questions

**Kotak UPI daily limit?**
₹1,00,000 per day per account (NPCI limit).

**My Kotak UPI works for small amounts but fails for large amounts — why?**
Could be hitting per-transaction limit (₹1 lakh) or daily aggregate limit. Check your remaining daily UPI balance in the Kotak app.

**Kotak 811 virtual card — can I use it for UPI PIN setup?**
Yes — Kotak 811 virtual debit card details (16-digit number, expiry, CVV) are available in the Kotak app. Use these for UPI PIN setup.
