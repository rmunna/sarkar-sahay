# ICICI Bank UPI Not Working / Blocked — Fix Guide 2026

ICICI Bank is India's second-largest private bank and a major UPI participant. iMobile Pay is the primary UPI app for ICICI customers, though third-party apps like PhonePe and GPay also support ICICI accounts. Here's how to fix all ICICI UPI issues.

---

| App | ICICI UPI Support | Notes |
|-----|-----------------|-------|
| **iMobile Pay** | Yes — official ICICI app with UPI | Primary ICICI UPI app |
| **PhonePe** | Yes — link ICICI account | @ybl UPI ID |
| **GPay** | Yes — ICICI linkable | @oksbi or @icici |
| **Paytm** | Yes — ICICI linkable | @paytm UPI ID |

## Most Common ICICI UPI Problems

| Problem | Likely Cause |
|---------|-------------|
| "UPI PIN incorrect" / "PIN blocked" | Too many wrong PIN attempts |
| "Transaction declined by bank" | Daily limit or account restriction |
| "ICICI account removed from UPI" | Deregistered (phone change etc.) |
| "Insufficient funds" | Actual balance low or pending debit |
| "iMobile Pay UPI not working" | App bug, network issue |

## Fix 1: Reset ICICI UPI PIN

**Most common fix — blocked after wrong PIN attempts:**

### Via iMobile Pay:
1. Open **iMobile Pay** → **"UPI"** section → **"Manage Accounts"**
2. Select ICICI bank account
3. Tap **"Change UPI PIN"** → **"Forgot UPI PIN"**
4. Enter ICICI debit card details:
   - Last 6 digits of card number
   - Expiry date (MM/YY)
5. OTP received on ICICI-registered mobile
6. Enter OTP → Set new 6-digit UPI PIN
7. **UPI restored immediately**

### Via PhonePe (ICICI linked):
1. PhonePe → **"My Money"** → Select ICICI account → **"Forgot UPI PIN"**
2. ICICI debit card details + OTP → New PIN

### Via GPay (ICICI linked):
1. GPay → Profile → **Payment Methods** → ICICI → **"Change UPI PIN"**
2. Card last 6 digits + expiry → OTP → New PIN

## Fix 2: Re-link ICICI Account to UPI

Account deregistered (common after phone change):

1. **iMobile Pay** → Login → **"UPI"** → **"Add Bank Account"**
2. SIM verification detects ICICI account linked to mobile
3. Select account → Set UPI PIN → Linked
4. Your ICICI UPI ID (@icici) is restored

## Fix 3: ICICI UPI Limit Management

| ICICI UPI Limits | Amount |
|----------------|--------|
| Per transaction | ₹1 lakh |
| Per day (all UPI apps combined) | ₹1 lakh |
| Merchant/bill payments | Up to ₹2 lakh for select categories |

**Workaround for higher amounts:** iMobile Pay → **NEFT/RTGS** — ICICI supports 24×7 NEFT.

## Fix 4: iMobile Pay UPI Transaction Failed

For failed transactions in iMobile Pay:

1. Check **iMobile Pay → UPI → Transaction History**
2. Find the failed transaction → Status shows "Failed" or "Pending"
3. If **"Failed"**: Money was not deducted — retry
4. If **"Pending"**: Check after 30 minutes — usually reverses automatically
5. **Dispute**: iMobile Pay → UPI History → Transaction → **"Raise Dispute"**
6. OR call: **1800-1080** (ICICI 24×7)

---

## Fix 5: ICICI UPI After Phone Change

ICICI UPI is SIM/mobile number linked:

1. Insert your ICICI-registered SIM in new phone
2. Install iMobile Pay → Login with Customer ID + password
3. **"UPI"** → **"Register for UPI"** → SIM-based verification
4. Set new UPI PIN via debit card OTP
5. Your ICICI UPI ID retained

For third-party apps: Re-install → Re-add ICICI account → Reset PIN.

---

## Fix 6: ICICI UPI on Multiple Apps

Some users face issues when ICICI is linked to many UPI apps:

- ICICI allows registration on up to 3 UPI-enabled apps simultaneously
- If one app's PIN is different from another: Each app has its own UPI PIN (they are not synced)
- Resetting PIN in one app doesn't affect other apps

## Raise ICICI UPI Dispute

For amount deducted but not credited to recipient:

1. **iMobile Pay** → UPI → History → Tap transaction → **"Raise Dispute"**
2. **NPCI PGRS portal**: [pgrs.npci.org.in](https://pgrs.npci.org.in) → File complaint → UPI → Enter transaction ID
3. **ICICI customer care**: **1800-1080** (24×7 toll-free)
4. **Resolution**: Auto-reversal typically within 24–48 hours; NPCI mandate: max 5 working days

## Frequently Asked Questions

**ICICI UPI PIN reset — I don't have my debit card. What to do?**
Without debit card: Request a replacement ICICI debit card (takes 5–7 days) then reset UPI PIN. Alternatively, visit ICICI branch → Get UPI reset done at branch kiosk using biometric verification.

**iMobile Pay says "UPI registration failed" — why?**
Causes: SIM not inserted (UPI needs SIM for registration), mobile number in iMobile is different from SIM, outgoing SMS disabled on SIM. Ensure SIM is inserted and can send SMS.

**ICICI UPI is blocked but my savings account is fine — are they related?**
They're separate. ICICI savings account works via debit card + net banking. UPI is linked to your mobile number + ICICI account. UPI block doesn't block your account — fix UPI PIN independently.

**My ICICI UPI ID changed after re-registering — how to inform contacts?**
ICICI UPI IDs are mobile-number based (@icici or @ibl). After re-registration, the ID should be the same. If different: Share the new ID. Old UPI ID stops working — any payments to old ID will fail.

**ICICI UPI shows "Your account doesn't support UPI" — what does this mean?**
Some ICICI accounts (NRO accounts, certain business accounts) have UPI restrictions. For savings accounts: Check if account is active (not frozen/blocked). For NRO: UPI is not supported — use NEFT/wire transfer.
