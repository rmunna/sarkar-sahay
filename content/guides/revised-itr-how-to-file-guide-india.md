# Revised ITR India 2026 — Complete Guide to Correcting Your Filed Return

Made a mistake in your ITR? Forgot to include some income? Wrong bank account number? India's Income Tax Act allows you to **revise your return** under Section 139(5) — at no cost and without any penalty.

## Two Options: Revised Return vs Updated Return

### Option 1: Revised Return (Section 139(5))
- **Who**: Anyone who filed an original ITR (on time or belated)
- **Deadline**: December 31 of the Assessment Year (AY)
- **Example**: For FY 2025-26 (AY 2026-27), deadline is December 31, 2026
- **Cost**: Zero — no additional tax or fee just for revising
- **Times**: Can be revised **multiple times** before the deadline
- **Scope**: Can change almost anything — income, deductions, bank account, tax regime choice

### Option 2: Updated Return (Section 139(8A))
- **Who**: Filed any return (original/revised/belated), but missed income that needs to be disclosed
- **Deadline**: 4 years from the end of the relevant AY (Budget 2025 extended from 2 years)
- **Cost**: Additional tax — **25% of incremental tax** (within 1 year of original deadline) or **50% of incremental tax** (Year 2–4)
- **Cannot be used**: To claim additional refund, reduce tax liability, or change regime

**If you need to ADD income you missed**: Use Updated Return (even after December 31, up to 4 years).
**If you need to CORRECT details before December 31**: Use Revised Return.

## Common Reasons to File Revised ITR

- Forgot to include salary from a previous employer (Form 16 arrived late)
- FD/savings interest not included
- Missed claiming a deduction (80C, 80D, HRA, LTA)
- Wrong bank account number (for refund)
- Claim under wrong section
- ITR form was wrong (e.g., filed ITR-1 but should have used ITR-2)
- Name, address, or contact details incorrect
- Tax regime selection changed
- Capital gains or rental income not declared
- Foreign assets/income not declared in Schedule FA

## How to File Revised ITR on Income Tax Portal

### Step 1: Go to incometax.gov.in → Log In

Use your PAN or Aadhaar-linked account.

### Step 2: Go to e-File → Income Tax Returns → File Income Tax Return

Select the same assessment year as the original return you want to revise.

### Step 3: Select "Revised Return" Under Filing Type

On the return filing page:
- Filing type: **Revised (u/s 139(5))**
- Enter the **Acknowledgement Number (Ack No.)** of the original return you're revising
- Enter the **Date of Filing** of the original return

You'll find the Ack No. in the ITR-V (acknowledgement) you received after original filing, or in your IT portal under "View Filed Returns."

### Step 4: Make Your Changes

The portal will pre-fill your original data. Correct whatever needs correcting:
- Income schedule corrections
- Deduction changes
- Bank account update (check the "Refund" section)

### Step 5: Validate, Calculate Tax, and Submit

Re-verify all details. The portal auto-calculates revised tax liability. Pay any additional tax before submitting (Challan 280 via portal). If revised return increases your refund, that's fine — just submit.

### Step 6: E-Verify the Revised Return

Like the original, revised return must be e-verified within **30 days**:
- Aadhaar OTP (easiest)
- Net banking EVC
- Demat EVC
- Send signed ITR-V to CPC Bengaluru (physical, if no e-verify option)

## What Happens to the Original Return?

When you file a revised return, the **original return is superseded**. The IT Department treats the revised return as your final return. All earlier assessments reference the latest return.

**You cannot "un-revise"** — once a revised return is filed, it replaces the original. Make sure your revised return is complete and correct.

## Deadline — Don't Miss It

| Filing Type | Deadline |
|-------------|----------|
| Original return (salaried, non-audit) | July 31 of AY |
| Belated return | December 31 of AY |
| Revised return | December 31 of AY |
| Updated return | 4 years from end of AY (Budget 2025 change) |

For FY 2025-26 (AY 2026-27):
- Revised return deadline: **December 31, 2026**
- Updated return available until: March 31, 2031

## Can You Change Tax Regime in a Revised Return?

**Yes, but with conditions:**

For **salaried individuals**:
- Can switch between old and new regime in revised return filed before December 31
- ITR-1 or ITR-2 — regime change allowed in revised return
- However, you must file the return and cannot just change regime without other corrections

For **business/profession income individuals** (ITR-3/4):
- **Cannot change regime once selected in original return** for that AY (regime is fixed for business owners who exercised the option)

## How Many Times Can You Revise?

**No limit** on the number of revisions before December 31 of the AY. You can revise once, discover another mistake, and revise again. Each revision supersedes the previous one.

Practically speaking, filing 2–3 revisions is unusual — but if needed, the portal allows it.

## What You CANNOT Change in Revised Return

- **ITR form type (in some cases)**: If you originally filed ITR-1 (Sahaj) and need to report capital gains, you should revise using ITR-2. The system allows this. But you cannot file a revised return if the assessment is already completed.
- **After assessment is completed**: If the IT Department has issued a final assessment order under Section 143(3), you cannot file a revised return for that year. For errors post-assessment, you need to approach the CIT(A) or ITAT.
- **Reduce income in a way that triggers a refund via Updated Return**: Section 139(8A) only allows you to add/correct income, not claim additional refunds.

## Revised Return and Interest on Tax Due

If your revised return shows higher tax liability (you added income you missed):
- Pay the difference immediately via Challan 280 (Self Assessment Tax)
- **Section 234A**: If original return was filed by July 31 and tax was fully paid, no interest on the revision
- **Section 234B**: If you hadn't paid advance tax and the revision shows you needed to, interest applies from the advance tax dates

To avoid interest: Pay tax before filing the revised return.

## Frequently Asked Questions

### I filed my ITR-1 on time. Now I realize I had LTCG from selling mutual funds. What do I do?

File a Revised Return using ITR-2 (which has the Schedule CG for capital gains). ITR-1 cannot accommodate capital gains. Select "Revised (u/s 139(5))" and choose ITR-2 — the portal allows this. Enter your original Ack No. and proceed. Don't wait — do this before December 31 of the AY.

### I missed Section 80C deduction of ₹1.5L in my original return. Can I revise?

Yes — file a revised return, go to the deductions section, and add your 80C investments (PPF, ELSS, LIC premium, school fees, etc.) with correct amounts. This will reduce your tax liability and may increase your refund. Do this before December 31.

### I filed the revised return but the refund got credited to my old bank account. Can I revise again?

Yes — file another revised return just to update the bank account number in the "Refund" section. The system allows multiple revisions. Make sure the new bank account is pre-validated on the portal under Profile → Bank Accounts.

### My original return showed ₹5L income. Revised return now shows ₹7L. Will the IT Department send a notice?

The IT Department's system compares returns and AIS data. If the revised return correctly captures income that was missed, filing it proactively is the right move — it reduces notice risk. If you wait and they notice the mismatch, you face penalties. Voluntary correction is always better than assessed correction.
