# Axis Bank UPI Blocked or Not Working? Fix (2026)

Axis Bank UPI works via **Axis Mobile** app and all third-party UPI apps. Here's how to fix every common Axis Bank UPI issue.

---

## Common Axis Bank UPI Issues

| Issue | Fix |
|-------|-----|
| Wrong UPI PIN | Reset PIN |
| Account debit freeze | Fix account block |
| Daily limit (₹1 lakh) hit | Wait till midnight |
| UPI not registered | Register in Axis Mobile |
| Bank server down | Try after 30 minutes |

---

## Reset Axis Bank UPI PIN

### Via Axis Mobile App
1. Open **Axis Mobile** → **UPI** → **Manage UPI PIN**
2. **"Change/Forgot UPI PIN"**
3. Axis debit card last 6 digits + expiry → OTP → New 6-digit PIN

### Via PhonePe / GPay
1. App → Bank Accounts → Axis Bank
2. **"Forgot UPI PIN"** → Axis debit card → OTP → New PIN

---

## Register Axis Bank UPI

1. Axis Mobile → **UPI Services** → **Register/Activate**
2. Select savings/current account → verify mobile → set PIN
3. Or: Any UPI app → Add Bank → Axis Bank → OTP → Set PIN

## Frequently Asked Questions

**Axis Bank UPI daily limit?**
₹1,00,000 per day per account (standard NPCI limit). Axis may have higher limits for specific merchant categories (hospitals, education).

**Axis UPI works on PhonePe but fails on GPay — why?**
Both apps register Axis UPI separately. Remove Axis Bank from GPay → Re-add → Reset UPI PIN on GPay. The PIN registered on PhonePe and GPay can be the same or different.

**Axis Bank UPI "payment pending" for 2 days — what to do?**
Open Axis Mobile → UPI → Transaction History → Find the pending transaction → "Raise Dispute". Also check with Axis customer care: 1860-419-5555 with the UPI reference number (UTR).
