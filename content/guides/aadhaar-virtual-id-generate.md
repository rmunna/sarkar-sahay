# Aadhaar Virtual ID (VID): How to Generate, Use & Regenerate

The **Aadhaar Virtual ID (VID)** is a temporary, revocable **16-digit number** that maps to your [Aadhaar number](/guide/aadhaar-card-apply-online) without revealing it. Introduced by UIDAI in 2018 to enhance privacy, VID can be used instead of your actual Aadhaar number for authentication and KYC purposes.

## What is Aadhaar Virtual ID?

| Feature | Details |
|---|---|
| Format | 16-digit temporary number |
| Maps to | Your 12-digit Aadhaar number (in UIDAI's system) |
| Validity | Until you revoke or regenerate it |
| Can be revoked? | Yes, anytime |
| Can be regenerated? | Yes, unlimited times |
| Reveals Aadhaar number? | No — only UIDAI can map VID to Aadhaar |

**How it works:** When you give your VID to a service provider, they send it to UIDAI for authentication. UIDAI maps it internally to your Aadhaar and returns the authentication result — but never reveals your actual Aadhaar number to the service provider.

## How to Generate Aadhaar Virtual ID

### Method 1: myAadhaar Portal

1. Visit [https://myaadhaar.uidai.gov.in/](https://myaadhaar.uidai.gov.in/)
2. Click on **"Virtual ID (VID) Generator"**
3. Enter your **12-digit Aadhaar number**
4. Enter the captcha code
5. Click **"Send OTP"** — OTP is sent to your registered mobile
6. Enter the OTP
7. Select **"Generate VID"**
8. Your 16-digit VID will be displayed and also sent via SMS to your registered mobile

### Method 2: mAadhaar App

1. Download and open the **mAadhaar** app
2. Add your Aadhaar profile (if not already added)
3. Go to **"VID Generator"** from the main menu
4. Authenticate with OTP
5. Tap **"Generate VID"**
6. Your VID will be displayed in the app and sent via SMS

### Method 3: UIDAI Resident Portal

1. Visit [https://resident.uidai.gov.in/vid-generation](https://resident.uidai.gov.in/vid-generation)
2. Enter Aadhaar number and captcha
3. Request OTP and enter it
4. Generate or retrieve your VID

## How to Retrieve Existing VID

If you have already generated a VID but forgot it:

1. Go to [https://myaadhaar.uidai.gov.in/](https://myaadhaar.uidai.gov.in/)
2. Click on **"Virtual ID (VID) Generator"**
3. Enter your Aadhaar number and verify via OTP
4. Select **"Retrieve VID"** instead of Generate
5. Your existing VID will be sent to your registered mobile number via SMS

## How to Revoke & Regenerate VID

You can revoke your current VID and generate a new one at any time. This is useful if you suspect your VID has been compromised.

1. Visit [https://myaadhaar.uidai.gov.in/](https://myaadhaar.uidai.gov.in/)
2. Go to **"VID Generator"**
3. Authenticate with Aadhaar number and OTP
4. Select **"Regenerate VID"**
5. The old VID is automatically revoked, and a new 16-digit VID is generated
6. The new VID is sent via SMS

**Note:** When you regenerate a VID, the old one becomes permanently invalid. Any service provider using the old VID for authentication will get an error.

## Where to Use Aadhaar VID

VID can be used anywhere Aadhaar number is accepted for authentication:

- **[e-Aadhaar download](/guide/aadhaar-card-download)** — enter VID instead of Aadhaar number to download
- **[Masked Aadhaar download](/guide/aadhaar-masked-download)** — use VID for downloading
- **[Offline KYC XML download](/guide/aadhaar-offline-kyc-xml)** — enter VID for extra privacy
- **Bank KYC** — share VID for Aadhaar-based e-KYC
- **Telecom KYC** — provide VID for SIM activation
- **Government services** — DigiLocker, UMANG, and other services accept VID
- **Mutual fund KYC** — via CAMS and KFintech
- **[PAN-Aadhaar linking](/guide/pan-aadhaar-link)** — VID can be used on the income tax portal

## VID vs Aadhaar Number vs Masked Aadhaar

| Feature | Aadhaar Number | Virtual ID (VID) | [Masked Aadhaar](/guide/aadhaar-masked-download) |
|---|---|---|---|
| Digits | 12 | 16 | 12 (8 hidden) |
| Permanent | Yes | No (revocable) | N/A (document format) |
| Reveals Aadhaar number | Yes | No | Partially (last 4) |
| Can be regenerated | No | Yes | N/A |
| Use for authentication | Yes | Yes | No (document only) |
| Best for | Personal records | Sharing with third parties | Document submission |

## Important Tips

1. **Use VID whenever possible** instead of your Aadhaar number — it provides the same functionality without exposing your permanent ID
2. **Regenerate VID periodically** — especially after sharing it with multiple service providers
3. **Keep your mobile number updated** — VID is sent via SMS to your registered mobile, so ensure it is current
4. **VID works everywhere** — any system that accepts Aadhaar number for authentication must also accept VID (it is mandatory as per UIDAI)
5. **Do not share VID publicly** — while safer than Aadhaar, treat it with the same caution as any identity credential

## FAQs

### What is the difference between Aadhaar number and Virtual ID?

Your Aadhaar number is a permanent 12-digit identity number. The Virtual ID is a temporary 16-digit number that maps to your Aadhaar internally but can be revoked and regenerated. VID prevents your actual Aadhaar number from being stored by service providers.

### Can I have multiple VIDs at the same time?

No. You can have only one active VID at a time. Generating a new VID automatically revokes the previous one.

### Do all service providers accept VID?

As per UIDAI mandate, all Authentication User Agencies (AUAs) must accept VID in place of Aadhaar number. If a service provider refuses VID, they are violating UIDAI guidelines.

### Will my old VID stop working if I generate a new one?

Yes. When you regenerate a VID, the old one becomes permanently invalid. Only the latest VID will work for authentication.

### Can someone find my Aadhaar number using my VID?

No. The mapping between VID and Aadhaar number exists only within UIDAI's secure servers. No external entity — including the Authentication User Agency — can derive your Aadhaar number from the VID.

### Is there a validity period for VID?

No fixed expiry. Your VID remains valid until you revoke or regenerate it. However, UIDAI recommends regenerating it periodically for security.
