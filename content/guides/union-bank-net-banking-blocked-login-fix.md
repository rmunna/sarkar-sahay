# Union Bank Net Banking Blocked / Login Failed — Fix Guide 2026

Union Bank of India's internet banking portal is **unionbankonline.co.in**. If your Union Bank net banking is blocked, locked, or login is failing, here's how to fix it in minutes.

---

## Common Union Bank Net Banking Issues

| Problem | Cause |
|---------|-------|
| "User ID locked" | 3+ wrong password attempts |
| "Invalid user ID/password" | Forgot credentials or account changed |
| "Session expired" | Inactivity timeout — re-login |
| "OTP not received" | Mobile number not updated in bank |
| "Account blocked" | Underlying account issue (freeze/KYC) |

---

## Fix 1: Reset Union Bank Net Banking Password

**Locked after wrong attempts:**

1. Go to **[unionbankonline.co.in](https://www.unionbankonline.co.in)**
2. Click **"Forgot Password"** / **"Reset Password"**
3. Enter your **User ID** (customer ID provided by Union Bank)
4. Enter registered mobile number → OTP
5. Enter your **Debit Card number + PIN** (for additional verification)
6. Set new password
7. **Login restored**

---

## Fix 2: Unlock User ID (After Multiple Wrong Attempts)

1. Union Bank portal → **"Unlock User ID"** option
2. Enter User ID + registered mobile OTP
3. ID unlocked → Enter new password

---

## Fix 3: Recover Forgotten User ID

1. **Vyom App** → Login with account number + OTP → View User ID
2. **Union Bank branch**: Submit request with Aadhaar + account passbook → User ID provided within 1 day
3. **Customer care**: 1800-22-2244 → Request User ID (after identity verification)

---

## Fix 4: Update Mobile Number for Net Banking OTP

If your registered mobile number changed:

1. Visit Union Bank branch
2. Submit mobile number change request with Aadhaar (updated number)
3. After 24 hours: New mobile number gets OTPs
4. Reset net banking credentials with new number

The **Union Bank Vyom app** offers most net banking features:

If net banking is temporarily down: Use Vyom app.

**Customer Care:** **1800-22-2244** (24×7, toll-free)

## Frequently Asked Questions

**Union Bank net banking — what is the User ID format?**
Union Bank User ID is typically a customer reference number (8–10 digits). It's mentioned in: Account opening letter, bank passbook header, welcome email from Union Bank.

**Net banking profile password vs transaction password — what's the difference?**
Profile password: Login to view accounts, statements. Transaction password: Needed for NEFT/fund transfers (additional authentication layer). Reset both separately if both are forgotten.

**My Union Bank net banking shows "account temporarily suspended" — what to do?**
This usually means there's a compliance/KYC hold on the account. Visit branch with Aadhaar + PAN. Once account status is resolved, net banking access is restored.

**Union Bank net banking — is it available 24×7?**
Yes — net banking login is 24×7. NEFT/RTGS: Available 24×7 (RBI enables 24×7 NEFT). IMPS: Always available. Some fund transfer features may have brief maintenance windows (usually 2–4 AM).

**Forgot both User ID and password — what to do?**
Visit nearest Union Bank branch with Aadhaar + account passbook. Branch officer retrieves User ID from system. You set new password using OTP on updated mobile. Takes 30 minutes at branch.
