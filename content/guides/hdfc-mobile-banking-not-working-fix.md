# HDFC Mobile Banking Not Working? Fix App Login Errors

The HDFC Bank Mobile Banking app is used by millions of customers daily. If your app is crashing, MPIN is not working, device binding has failed, or you can't log in, this guide covers all common issues with step-by-step fixes.

| Issue | Likely Cause | Quick Fix |

| MPIN not working | Wrong MPIN or expired | Reset MPIN via app |

## Fix 1: HDFC Bank App Crashing or Not Opening

**Step-by-step:**

### On Android
1. Go to **Settings** → **Apps** → **HDFC Bank**
2. Tap **"Force Stop"**
3. Tap **"Storage"** → **"Clear Cache"** (do NOT clear data)
4. Open the Play Store and update to the latest version
5. Restart your phone and try again
6. If still not working, uninstall and reinstall the app

### On iPhone
1. Swipe up to close the HDFC Bank app completely
2. Go to **Settings** → **General** → **iPhone Storage** → **HDFC Bank**
3. Delete and reinstall the app from App Store
4. Ensure iOS is updated to at least the minimum supported version
5. Restart your phone and try again

**Also check:**
- Minimum 500 MB free storage on your phone
- Stable internet connection (Wi-Fi or 4G/5G)
- App is not restricted by any battery saver or cleaner app

## Fix 2: MPIN Not Working — How to Reset

If your MPIN (Mobile PIN) is not being accepted:

### Reset MPIN via App
1. Open HDFC Bank Mobile Banking app
2. On the login screen, tap **"Forgot MPIN"**
3. Enter your Customer ID and registered mobile number
4. Verify with OTP sent to your registered mobile
5. Set a new 4/6-digit MPIN
6. Login with the new MPIN

### Reset MPIN via NetBanking
1. Login to [HDFC NetBanking](https://netbanking.hdfcbank.com/)
2. Go to **Mobile Banking** → **Reset MPIN**
3. Follow the on-screen steps
4. New MPIN will be set immediately

### If Customer ID is forgotten
- Check any old HDFC Bank email or account statement — it's printed there
- Call 1800-202-6161 and verify your identity to retrieve it
- Visit the nearest branch with ID proof

## Fix 3: Device Binding Failed (New Phone/SIM)

When you change your phone or SIM card, you need to re-register for mobile banking:

1. Install the HDFC Bank app on your new phone
2. Open the app and select **"Register/First Time User"**
3. Enter your **Customer ID** and **registered mobile number**
4. Verify with OTP (sent to registered number)
5. If you've changed your SIM but kept the same number, OTP will work normally
6. If you've changed your mobile number, you must first update it at an HDFC Bank branch
7. Complete device binding by setting a new MPIN
8. Enable biometric login if needed

**Important:** HDFC Mobile Banking can only be active on **one device at a time**. Registering on a new device automatically deactivates the old one.

## Fix 4: Biometric Login (Fingerprint/Face ID) Not Working

**Common causes and fixes:**

1. **OS updated recently:** Biometric permissions may reset after OS updates
   - Go to HDFC App → Settings → Login Preferences → Re-enable Biometric Login
2. **New fingerprint added:** Adding a new fingerprint to your phone disables biometric login in banking apps for security
   - Re-enable biometric login in the HDFC app
3. **App permissions denied:**
   - Android: Settings → Apps → HDFC Bank → Permissions → Enable Biometrics
   - iPhone: Settings → HDFC Bank → Enable Face ID
4. **MPIN expired:** Some biometric issues require re-authentication with MPIN first
   - Login with MPIN once, then re-enable biometric

## Fix 5: "Update Required" Error

If the app says an update is required but no update is available:

1. Go to Play Store (Android) or App Store (iPhone)
2. Search for "HDFC Bank" and check if an update is available
3. If no update shows:
   - Clear Play Store/App Store cache
   - Check if your phone OS meets minimum requirements (Android 8+ / iOS 14+)
   - Your phone may be too old and no longer supported
4. If your phone is incompatible, use [HDFC NetBanking](https://netbanking.hdfcbank.com/) as an alternative

## Fix 6: "Transaction Failed" or "Server Error"

1. Check your internet connection — switch between Wi-Fi and mobile data
2. Check if HDFC Bank has announced any scheduled maintenance (usually late night)
3. Wait 5–10 minutes and retry — server issues are usually temporary
4. Avoid using VPN while accessing the HDFC app
5. If the amount was debited but transaction failed, it will be auto-reversed within 3–5 working days
6. If not reversed, file a complaint via the app or call 1800-202-6161

## Important Tips

1. **Keep the app updated** — HDFC frequently releases patches for bugs and security; always use the latest version
2. **Use only official app** — Download only from Google Play Store or Apple App Store; never use APK files from third-party sites
3. **One device only** — HDFC Mobile Banking works on only one device at a time; don't try to use on two phones simultaneously
4. **Register with primary number** — Ensure your primary mobile number is registered with the bank for OTP and alerts
5. **Don't share MPIN** — HDFC Bank will never call and ask for your MPIN, OTP, or Customer ID

## Frequently Asked Questions

### Q1. Why is HDFC Mobile Banking app not working today?
It could be a server-side issue, scheduled maintenance (usually late night), or an app update required. Check HDFC Bank's social media handles for outage announcements, or try again after some time.

### Q2. How to reset HDFC Mobile Banking MPIN?
Open the app → Tap "Forgot MPIN" → Enter Customer ID → Verify with OTP → Set new MPIN. Alternatively, reset via NetBanking under Mobile Banking settings.

### Q3. Can I use HDFC Mobile Banking on two phones?
No, HDFC Mobile Banking can only be active on one device at a time. Registering on a new device automatically deactivates the previous one.

### Q4. How to register for HDFC Mobile Banking?
Download the HDFC Bank app → Select "Register" → Enter Customer ID and registered mobile number → Verify with OTP → Set MPIN → Done. You need an active HDFC savings/current account.

### Q5. What to do if HDFC app shows "Device Binding Failed"?
Ensure you're using the registered mobile number's SIM in the phone. If you've changed your number, update it at an HDFC branch first. Then retry registration with OTP verification.

### Q6. Is HDFC Mobile Banking safe?
Yes, HDFC uses 256-bit encryption, device binding, MPIN, and biometric authentication. However, never share your MPIN or OTP with anyone, and use only the official app.

### Q7. How to change registered mobile number for HDFC Mobile Banking?
Visit the nearest HDFC Bank branch with your [Aadhaar card](/guide/aadhaar-card-apply-online) and PAN card. Mobile number change cannot be done online for security reasons.
