# Canara Bank UPI Blocked or Not Working? Fix (2026)

Canara Bank UPI works via the **Canara ai1** app and third-party apps (PhonePe, Google Pay). This guide fixes all common Canara Bank UPI issues.

---

## Common Canara Bank UPI Issues

| Issue | Fix |
|-------|-----|
| Wrong UPI PIN | Reset PIN |
| Account debit freeze | Fix account first |
| Daily limit (₹1 lakh) | Wait till midnight |
| UPI not registered | Register via Canara ai1 |
| Server down | Try after 30 minutes |

---

## Reset Canara Bank UPI PIN

### Via Canara ai1 App
1. Open **Canara ai1** → **UPI** → **Manage UPI ID**
2. **"Change UPI PIN"** or **"Forgot UPI PIN"**
3. Debit card last 6 digits + expiry → OTP → New PIN

### Via PhonePe / GPay
1. App → Bank Accounts → Select Canara Bank
2. **"Forgot UPI PIN"** → Card details → OTP → New PIN

---

## Register Canara Bank UPI

1. Canara ai1 → **UPI Services** → **Register UPI**
2. Select account → mobile verification → set PIN
3. Or use any UPI app → Add Bank → Canara Bank → Register

## Frequently Asked Questions

**Canara Bank UPI works on BHIM but fails on PhonePe — why?**
PhonePe and BHIM have separate registrations. Remove and re-add Canara Bank on PhonePe, reset UPI PIN. They're independent.

**Canara Bank UPI limit for 2026?**
Standard ₹1,00,000 per day per account (NPCI mandate). Canara Bank follows NPCI guidelines.

**Canara Bank sent OTP to wrong number during UPI setup — what to do?**
Your UPI-registered mobile must match the bank's registered mobile. Visit Canara branch to update mobile number if they differ.
