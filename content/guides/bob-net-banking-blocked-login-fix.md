# Bank of Baroda Net Banking Blocked / Login Failed — Fix Guide 2026

Bank of Baroda's internet banking is **Baroda Connect** (barodaconnect.com). If login is failing or your BOB net banking is blocked, here's how to fix it quickly.

---

## Common BOB Net Banking Issues

| Problem | Cause |
|---------|-------|
| "User ID locked/blocked" | Wrong password 3+ times |
| "Invalid credentials" | Forgotten User ID or password |
| "Transaction password expired" | Must be changed periodically |
| "OTP not received" | Mobile number mismatch |
| "Page not loading" | Browser cache issue |

---

## Fix 1: Reset Baroda Connect Password

1. Go to **[barodaconnect.com](https://www.barodaconnect.com)**
2. Click **"Forgot Password"** / **"Reset Login Password"**
3. Enter User ID
4. Choose verification: Mobile OTP + Debit card details
5. Enter OTP on registered mobile
6. Enter debit card number + expiry
7. Set new password
8. **Login works again**

---

## Fix 2: Unlock BOB User ID

If user ID locked after multiple wrong attempts:

1. Baroda Connect → **"Unlock User ID"**
2. Enter User ID + OTP verification
3. Reset password → Login

---

## Fix 3: Reset Transaction Password (for Fund Transfers)

BOB Net Banking has two passwords: Login password + Transaction password (for fund transfer authorization).

1. Baroda Connect → **"Forgot Transaction Password"**
2. OTP verification on mobile
3. Set new transaction password → Fund transfers work again

---

## Fix 4: BOB World App Alternative

**BOB World mobile banking** offers the same features as net banking:
- Account balance + statements
- NEFT/IMPS fund transfers
- UPI payments

If Baroda Connect is down or locked: Use BOB World app as alternative while fixing net banking.

---

## Fix 5: Recover Forgotten User ID

1. **BOB World app**: Profile → User ID visible after login
2. **Branch**: Show Aadhaar + account passbook → User ID provided same day
3. **Customer care**: **1800-5700** → Request User ID after identity verification

---

## Fix 6: Browser Issues with Baroda Connect

If barodaconnect.com isn't loading or behaving oddly:
1. Clear browser cache and cookies (Ctrl+Shift+Delete)
2. Use Chrome or Firefox (latest version)
3. Disable ad blockers for barodaconnect.com
4. Try in Incognito mode

## Frequently Asked Questions

**What is Baroda Connect User ID for BOB?**
Baroda Connect User ID is a reference number — find it in: Account opening letter, first SMS from BOB, or by calling 1800-5700.

**BOB net banking — how often must I change transaction password?**
BOB may prompt to change transaction password every 90–180 days. Set it proactively before it expires to avoid lockout.

**My BOB net banking was working before Vijaya/Dena Bank merger — now it's not?**
If your account was migrated from Vijaya Bank or Dena Bank: You need to register fresh on Baroda Connect. Visit BOB branch with Aadhaar + account number → Get new net banking credentials.

**Can I register for BOB net banking online without branch visit?**
New registration: Can be done online via Baroda Connect → New User Registration → Debit card verification. No branch visit needed for initial setup.

**BOB Baroda Connect shows balance but won't let me transfer — why?**
Transfer failure (despite correct transaction password): Could be: Daily transfer limit reached, beneficiary not yet activated (24-hour cooling period for new beneficiaries), account restriction. Check each possibility in Baroda Connect → Transaction Limits.
