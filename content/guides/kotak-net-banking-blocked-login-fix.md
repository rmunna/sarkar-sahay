# Kotak Mahindra Net Banking Blocked or Login Failed? Fix (2026)

Kotak Mahindra net banking (netbanking.kotak.com) locks after **3–5 wrong password attempts**. Reset is quick using Aadhaar OTP or debit card details.

---

## Why Is Kotak Net Banking Blocked?

| Cause | Fix |
|-------|-----|
| Wrong password 3 times | Reset via "Forgot Password" |
| Wrong transaction password | Reset separately |
| Customer ID forgotten | Retrieve via mobile + account |
| Security lock | Call 1860-266-2666 |
| KYC pending | Update KYC first |

---

## Method 1: Reset Kotak Net Banking Password

1. Go to **[netbanking.kotak.com](https://netbanking.kotak.com)**
2. Click **"Forgot Password"**
3. Enter **Customer ID** (8-digit, on passbook/welcome kit)
4. Enter Date of birth + registered mobile number
5. OTP on mobile → Set new password
6. **Active instantly**

---

## Method 2: Via Kotak Mobile App

1. Open **Kotak Mobile Banking**
2. **Profile → Settings → Internet Banking**
3. **"Reset Password"** → OTP → New password

---

## Method 3: Forgot Kotak Customer ID

1. netbanking.kotak.com → **"Forgot Customer ID"**
2. Enter: Mobile number + Account number
3. OTP → Customer ID displayed

---

## Kotak 811 Account — Net Banking Fix

Kotak 811 (digital savings account) uses same net banking portal:

1. netbanking.kotak.com → Forgot Password
2. 811 Customer ID + mobile number + OTP
3. Same reset process as regular Kotak account

## Frequently Asked Questions

**Kotak Mobile Banking app login PIN is different from net banking password — right?**
Yes — Kotak app uses a separate MPIN (4–6 digit PIN). Net banking uses a different password. Reset one doesn't affect the other.

**My Kotak net banking was fine yesterday, now shows "invalid customer ID" — why?**
Could be a caching/cookie issue. Try incognito browser, clear cache, try on mobile browser. If still failing: use "Forgot Password" flow even if you know the password — it verifies your Customer ID.

**Can I use Kotak net banking on mobile without the app?**
Yes — netbanking.kotak.com works on mobile browser. Use incognito mode for better performance.
