# Aadhaar Update Online 2026 — Complete Guide

Aadhaar is India's most important identity document — used for KYC, banking, income tax, government schemes, and more. Keeping it updated is critical. Here's how to update your Aadhaar details online and offline in 2026.

---

## What Can Be Updated in Aadhaar?

| Field | Online Update | Offline Update | Documents Required |
|-------|--------------|---------------|-------------------|
| **Address** | ✅ Yes (free online) | ✅ Yes | Address proof |
| **Name** | ❌ Not online | ✅ Aadhaar Kendra | Identity proof with correct name |
| **Mobile number** | ❌ Not online | ✅ Aadhaar Kendra (OTP needed) | None (biometric verification) |
| **Date of Birth** | ❌ Not online | ✅ Aadhaar Kendra | DOB proof (birth certificate, school certificate) |
| **Gender** | ❌ Not online | ✅ Aadhaar Kendra | Affidavit or legal document |
| **Photo** | ❌ Not online | ✅ Aadhaar Kendra | In-person biometric |
| **Email** | ✅ Yes (myAadhaar) | ✅ Yes | None |

---

## Update 1: Aadhaar Address Update Online (Free)

### Via myAadhaar Portal:

1. Go to **[myaadhaar.uidai.gov.in](https://myaadhaar.uidai.gov.in)**
2. Login: Aadhaar number + OTP on registered mobile
3. **"Update Address Online"** → "Proceed"
4. Select: **"Self-Upload of Supporting Document"**
5. Enter new address details (fill each field carefully)
6. Upload scanned/photo of **one Address Proof document**:
   - Utility bill (electricity/water/gas) — less than 3 months old
   - Bank statement/passbook (less than 3 months)
   - Passport (valid)
   - Voter ID
   - Driving Licence
   - House registration document
   - Rent/lease agreement (with owner's Aadhaar details)
7. Submit → Pay ₹50 via UPI/debit card
8. **SRN (Service Request Number)** generated
9. Processing: **15 working days** (sometimes faster)
10. Download updated e-Aadhaar after processing

---

## Update 2: Aadhaar Address via Address Validation Letter (Offline)

If you live at an address that belongs to someone else (family member's house):

1. myAadhaar → **"Request Address Validation Letter"**
2. Enter "Verifier's" Aadhaar (owner/parent's Aadhaar)
3. Verifier gets OTP → They approve
4. Your address gets linked to their verified address
5. **Useful for**: Children, students, tenants, joint family

---

## Update 3: Mobile Number Update (At Aadhaar Kendra)

Mobile number CANNOT be updated online — requires in-person biometric verification:

1. Find nearest **Aadhaar Kendra / Aadhaar Seva Kendra**:
   - UIDAI website → "Locate Enrolment Centre"
   - OR: [appointments.uidai.gov.in](https://appointments.uidai.gov.in) → Book appointment
2. Visit with: Aadhaar card (original) + new mobile SIM
3. Biometric verification (fingerprint + iris) at the kendra
4. New mobile number OTP verified on new SIM
5. **Processing: 7–10 working days**
6. SMS on new mobile when updated

---

## Update 4: Name Correction (At Aadhaar Kendra)

Name corrections require physical visit:

**Documents for name correction:**
- PAN card (with correct name)
- Passport (with correct name)
- Bank passbook (with correct name, issued by bank)
- SSLC/Matriculation certificate

**Process:**
1. Book appointment at [appointments.uidai.gov.in](https://appointments.uidai.gov.in)
2. Visit Aadhaar Seva Kendra
3. Fill Aadhaar Correction Form
4. Submit document
5. Biometric update
6. **Processing: 30 working days** (name changes take longer — verification required)

---

## Update 5: Date of Birth Correction

DOB can only be corrected **once in a lifetime** on Aadhaar:

**Documents:**
- Birth certificate (most preferred)
- School leaving certificate / SSLC with DOB
- Passport (with DOB)
- PAN card

**Process:** Same as name correction — Aadhaar Seva Kendra visit required.

|-------------|-----|
| Online address update | ₹50 |
| Offline update at Aadhaar Kendra | ₹100 (demographic update) |
| Biometric update (mobile, photo) | ₹100 |
| Enrolment (new Aadhaar) | Free |

## Check Aadhaar Update Status

1. myaadhaar.uidai.gov.in → **"Check Aadhaar Update Status"**
2. Enter SRN (Service Request Number) received after submission
3. Status shown: Under Review / Approved / Rejected

---

## Download Updated e-Aadhaar

After update is approved:
1. myaadhaar.uidai.gov.in → **"Download Aadhaar"**
2. Enter Aadhaar number + OTP
3. e-Aadhaar PDF downloaded (password: first 4 letters of name in CAPS + birth year)

## Frequently Asked Questions

**Aadhaar address update rejected — why?**
Common reasons: Document is older than 3 months (utilities), address on document doesn't exactly match what you entered, document is blurry/incomplete, PIN code mismatch. Resubmit with a clearer, recent document.

**I don't have electricity bill — what address proof for Aadhaar update?**
Any of these work: Bank statement (last 3 months, with address), Voter ID, Passport, Driving Licence, Rent agreement, Property registration document. Bank statement/passbook is easy if you have a bank account.

**Can I update mobile number on Aadhaar via phone call?**
No — mobile number update cannot be done remotely (no online option, no phone call). In-person biometric at Aadhaar Kendra is mandatory. This is a security measure.

**How many times can I update Aadhaar address?**
No limit on address updates. As many times as you move. Each update costs ₹50 online or ₹100 at kendra.

**Aadhaar not linked to new mobile — how do I get OTP for online services?**
Services requiring Aadhaar OTP will fail if your mobile isn't linked. Fix: Visit Aadhaar Kendra → Update mobile number (₹100, biometric). Until then: Use Aadhaar face authentication (some apps) or virtual ID as alternative.
