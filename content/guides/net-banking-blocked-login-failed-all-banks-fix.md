# Net Banking Blocked or Login Failed? Fix for All Banks (2026)

Net banking gets blocked typically after **3–5 failed login attempts** (security lockout), or when the bank detects suspicious login patterns. It's frustrating but fixable — usually in under 10 minutes.

This guide covers how to unblock net banking for every major Indian bank.

---

## Why Is Net Banking Blocked?

| Reason | Fix |
|--------|-----|
| **Wrong password 3–5 times** | Automatic lockout — reset password |
| **Wrong transaction password** | Reset transaction/profile password |
| **Bank security flag** | Call customer care |
| **New device / unfamiliar location** | Email OTP verification required |
| **Account level block** | Fix account block first |
| **Browser/cookie issue** | Try incognito or different browser |
| **Session timeout** | Just re-login |

## SBI Net Banking Blocked — Unlock

### Option 1: Instant Online Unlock (If Just Password Forgotten)
1. Go to **[onlinesbi.sbi.co.in](https://onlinesbi.sbi.co.in)**
2. Click **"Login"** → **"Forgot Login Password"**
3. Enter: Username + Account number + Registered mobile number
4. OTP sent to registered mobile → Enter OTP
5. Set new login password
6. **Timeline:** Instant

### Option 2: SBI YONO App
1. YONO → More → Net Banking → Reset Internet Banking Password
2. OTP verification → New password set

### If User ID Also Forgotten
1. onlinesbi.sbi.co.in → **"Forgot Username"**
2. Enter account number + mobile number → OTP → Username displayed

### If Account-Level Block (Not Just Password)
- Call **1800-11-2211** → Customer care can unlock after verification

**SBI Net Banking Tech Support:** 1800-11-2211

## HDFC Net Banking Blocked — Unlock

### Reset Login Password
1. Go to **[netbanking.hdfcbank.com](https://netbanking.hdfcbank.com)**
2. Click **"Forgotten Password"**
3. Enter Customer ID (printed on first page of passbook)
4. Choose: OTP to mobile / security questions
5. OTP received → Set new password
6. **Timeline:** Instant

### Reset Transaction/IPIN Password
1. Same link → **"Forgotten IPIN"**
2. OTP verification → Set new IPIN

### If HDFC Net Banking Is Blocked After Security Alert
- Call **1800-202-6161** → Select "Internet Banking" → Agent unlocks after identity verification

## If You've Changed Mobile Number and Are Locked Out

This is the tricky case — you can't receive OTP for password reset because your old number is no longer active.

**Solution:**
1. Visit your home branch
2. Carry: Aadhaar, PAN, passbook
3. Request: **"Mobile number update + net banking reset"**
4. Branch updates mobile, then you can reset password digitally
5. Processing time: **1 working day** (mobile update) → then instant reset

## Tips to Avoid Net Banking Lockout

1. **Use a password manager** — prevents wrong password attempts
2. **Save your Customer ID** — note it somewhere safe
3. **Keep mobile number updated** — OTP delivery is critical
4. **Don't save password in shared computers** — use incognito when on public devices
5. **Set up TOTP/authenticator** — some banks offer authenticator app as backup

## Frequently Asked Questions

**How many wrong attempts before net banking is locked?**
Most banks lock after 3 consecutive wrong login attempts (SBI: 3; HDFC: 5; ICICI: 3; Axis: 3). Transaction password locks after 3 wrong entries.

**My net banking is locked but I need to do an urgent transfer — what can I do?**
Use your bank's **mobile app** — login credentials are separate. Or: visit branch for over-the-counter transfer. NEFT/RTGS via branch is immediate.

**Will unlocking net banking automatically restore my UPI?**
No — net banking and UPI are separate. UPI uses the bank app and a separate UPI PIN. Unlocking net banking does not affect UPI status.

**How do I unlock net banking if I'm in another country?**
Most banks allow password reset with OTP to your registered Indian mobile number. If your Indian number is not active, you'll need to call bank's international helpline or have a trusted person visit the branch on your behalf (with authorization letter).

**Can the branch unlock net banking?**
Yes — branches can reset net banking credentials for customers who visit with valid ID. They'll issue a new login password or reset the account.
