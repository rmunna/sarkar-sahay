# Aadhaar Mobile Number Not Linked? How to Register (2026)

Many Aadhaar holders don't have a mobile number linked to their Aadhaar, or have an old/inactive number. This blocks you from receiving OTPs, using online services, downloading e-Aadhaar, and more. Here's how to fix it.

> **Disclaimer:** CitizenNest is an independent platform and is not affiliated with UIDAI.

## Why You Need a Mobile Number on Aadhaar

Without a linked mobile number, you cannot:
- Download e-Aadhaar or mAadhaar
- Receive OTPs for Aadhaar-based authentication (banking, ITR, etc.)
- Link Aadhaar with PAN online
- Update Aadhaar details online
- Use DigiLocker with Aadhaar
- Lock/unlock Aadhaar biometrics online
- Apply for government schemes requiring Aadhaar eKYC

## Check If Mobile Is Linked to Aadhaar

### Method 1: UIDAI Website
1. Visit [myaadhaar.uidai.gov.in](https://myaadhaar.uidai.gov.in)
2. Enter your Aadhaar number
3. Click "Send OTP" — if you receive OTP, your number is linked
4. If you don't receive OTP, your number is not linked or wrong number is registered

### Method 2: Aadhaar Helpline
1. Call **1947** (UIDAI toll-free helpline)
2. Select language
3. Choose "Verify mobile number linked to Aadhaar"
4. The system will tell you if a mobile number is registered

**Note:** UIDAI does not show the full mobile number for privacy. You'll only see the last 4 digits.

## How to Link Mobile Number to Aadhaar

**Important:** Mobile number can ONLY be added/changed by visiting an Aadhaar Enrollment Center in person. This cannot be done online.

### Step-by-Step Process:

1. **Find nearest Aadhaar Enrollment Center:**
   - Visit [appointments.uidai.gov.in](https://appointments.uidai.gov.in)
   - Or search "Aadhaar enrollment center near me"
   - See our [Aadhaar center finder guide](/guide/aadhaar-enrollment-center-near-me)

2. **Visit the center with:**
   - Original Aadhaar card or Aadhaar number
   - The mobile phone with the SIM you want to link (the number should be active)
   - No documents needed for mobile update alone — biometric verification is used

3. **At the center:**
   - Fill the **Aadhaar Update Form**
   - Select "Mobile Number" as the field to update
   - Write your new mobile number clearly
   - Provide biometric authentication (fingerprint + iris scan)
   - Pay **₹50** update fee (get receipt)

4. **After submission:**
   - You'll receive an **Update Request Number (URN)** on the receipt
   - An OTP will be sent to your **new mobile number** for verification
   - Update takes **7-15 working days** to reflect

5. **Track your update:**
   - Visit [myaadhaar.uidai.gov.in](https://myaadhaar.uidai.gov.in) → Check Update Status
   - Enter your Aadhaar number and URN

## What If You Don't Have Any ID Proof?

Even without documents, you can update your mobile number because:
- Aadhaar mobile updates use **biometric verification** (fingerprints and iris)
- No document proof is required — your biometrics confirm your identity
- You only need to know your Aadhaar number

## What If Biometric Verification Fails?

If your fingerprints or iris scan don't match (common for manual laborers, elderly):

1. Ask the operator to try **iris scan** instead of fingerprints
2. Try a **different finger** — index finger often works better
3. Apply moisturizer if fingers are very dry and try again
4. If biometrics still fail, contact UIDAI helpline at **1947** for resolution
5. In extreme cases, you may need to visit a **regional UIDAI office**

## Tips for a Smooth Mobile Update

1. **Go early** — enrollment centers get crowded after 11 AM
2. **Book an appointment** online at [appointments.uidai.gov.in](https://appointments.uidai.gov.in) to skip the queue
3. **Carry the SIM** in an active phone — some centers verify via OTP on the spot
4. **Keep hands clean and dry** for better fingerprint scan
5. **Remember your Aadhaar number** even if you don't have the card
6. **Carry ₹50 in cash** — many centers don't accept digital payments

## After Mobile Update: What Changes

Once your mobile is updated:
- You can download e-Aadhaar from [myaadhaar.uidai.gov.in](https://myaadhaar.uidai.gov.in)
- OTP-based services (PAN link, bank KYC, DigiLocker) will work
- You can update other Aadhaar details online
- mAadhaar app will work on your phone

## Frequently Asked Questions

### Can I add mobile number to Aadhaar online?
No. Adding or changing mobile number in Aadhaar requires a physical visit to an Aadhaar Enrollment Center. This is for security — biometric verification is mandatory.

### How much does Aadhaar mobile update cost?
Aadhaar mobile number update costs ₹50 per transaction at the enrollment center. This is a UIDAI-mandated fee.

### How long does Aadhaar mobile update take?
Aadhaar mobile number update takes 7-15 working days. You can track the status using your URN (Update Request Number) on the UIDAI website.

### Can I update Aadhaar mobile number without documents?
Yes. Mobile number update only requires biometric verification (fingerprints/iris scan). No documents are needed. You just need to know your Aadhaar number.

### Why am I not getting OTP on Aadhaar registered mobile?
Possible reasons: mobile number is not linked, old/inactive number is registered, network issues, or UIDAI server delay. Wait 5 minutes and retry. If the number is wrong, visit an enrollment center.

### Can I link two Aadhaar cards to one mobile number?
Yes. Multiple Aadhaar cards can be linked to the same mobile number. This is common for family members using one phone number.

### What if Aadhaar enrollment center refuses to update mobile?
This is not allowed. Every Aadhaar enrollment center must process update requests. If refused, note the center details and complain to UIDAI at 1947 or via uidai.gov.in.

### Can NRI update Aadhaar mobile number?
Yes, NRIs can update their Aadhaar mobile number by visiting an enrollment center in India. They can link an Indian mobile number while visiting.
