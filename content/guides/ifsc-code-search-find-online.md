# IFSC Code Search — How to Find Bank IFSC Code Online

Every time you transfer money through NEFT, RTGS, or IMPS, you need one critical piece of information — the **IFSC code** of the beneficiary's bank branch. Without the correct IFSC code, your transaction simply won't go through.

This guide covers everything you need to know about IFSC codes: what they are, how to find them, how to verify them, and common mistakes to avoid.

---

## What Is an IFSC Code?

**IFSC** stands for **Indian Financial System Code**. It is an **11-character alphanumeric code** assigned by the Reserve Bank of India (RBI) to every bank branch that participates in electronic fund transfers.

The IFSC code uniquely identifies a specific bank branch within the national payment systems — NEFT, RTGS, and IMPS.

**Key facts:**

- Issued and maintained by the **Reserve Bank of India (RBI)**
- **11 characters** long — a mix of letters and numbers
- Each branch of a bank has a **unique** IFSC code
- Required for all electronic fund transfers in India
- Also used for UPI registration and linking bank accounts

> **Example:** `SBIN0001234` is an IFSC code for a branch of State Bank of India.

---

## IFSC Code Format Explained

Every IFSC code follows a fixed **11-character structure**:

| Position | Characters | Meaning |
|----------|-----------|---------|
| 1–4 | Letters | Bank code (e.g., SBIN for SBI) |
| 5 | Always `0` | Reserved for future use |
| 6–11 | Alphanumeric | Branch code |

**Breaking down `SBIN0001234`:**

- **SBIN** → State Bank of India
- **0** → Reserved character (always zero)
- **001234** → Specific branch identifier

The **5th character is always zero** — this is an easy way to spot an invalid IFSC code.

## Where to Find Your Bank's IFSC Code (7 Methods)

### 1. Cheque Book

The IFSC code is **printed on every cheque leaf**. Look at the top of the cheque — you'll find it next to the MICR code, usually near the bank's branch address.

### 2. Bank Passbook or Account Statement

Your passbook's **first page** typically displays the branch details including the IFSC code, MICR code, and branch address.

### 3. RBI Website

The RBI maintains an official list of all IFSC codes:

1. Visit [https://www.rbi.org.in](https://www.rbi.org.in)
2. Navigate to **Payment and Settlement Systems → NEFT / RTGS**
3. Search by bank name and branch
4. Download the full IFSC directory if needed

This is the **most authoritative source** for IFSC codes.

### 4. Bank's Official Website

Most banks have an IFSC/branch locator on their website:

- **SBI:** [https://sbi.co.in](https://sbi.co.in) → Branch Locator
- **HDFC Bank:** [https://www.hdfcbank.com](https://www.hdfcbank.com) → Locate Us
- **ICICI Bank:** [https://www.icicibank.com](https://www.icicibank.com) → Branch & ATM Locator
- **PNB:** [https://www.pnbindia.in](https://www.pnbindia.in) → Branch Locator

### 5. Net Banking / Internet Banking

Log in to your bank's internet banking portal. The IFSC code is usually displayed:

- On the **account summary/details** page
- Under **profile or account information**
- In the **fund transfer** section when adding a beneficiary

### 6. Mobile Banking App

Open your bank's mobile app → go to **Account Details** or **My Accounts**. The IFSC code for your branch is displayed alongside your account number and branch name.

### 7. Customer Care / Branch Visit

Call your bank's customer care number or visit the branch directly. Provide your account number and they will share the IFSC code.

## How to Verify an IFSC Code on the RBI Website

Before using an IFSC code for a large transaction, verify it:

1. Go to the RBI's official IFSC search page
2. Select the **bank name** from the dropdown
3. Select the **branch state** and **district**
4. Find your branch from the list
5. Cross-check the IFSC code displayed

**Why verify?**

- Bank branches **merge or close** — IFSC codes change when this happens
- After bank mergers (e.g., associate banks merging into SBI, or OBC/UBI merging into PNB), old IFSC codes may become **invalid**
- Using a wrong IFSC code can cause transaction failures or delays

> **Tip:** The RBI periodically publishes updated IFSC directories. Always use the latest list for bulk transactions.

## When Do You Need an IFSC Code?

You need the IFSC code for:

- **NEFT transfers** — National Electronic Funds Transfer
- **RTGS transfers** — Real Time Gross Settlement (for amounts ≥₹2 lakh)
- **IMPS transfers** — Immediate Payment Service
- **Adding a beneficiary** in net banking or mobile banking
- **UPI registration** — linking your bank account to a UPI app
- **Setting up auto-debit/ECS mandates** — loan EMIs, SIP investments, insurance premiums
- **Income tax refunds** — entering bank details on the IT portal
- **Direct Benefit Transfer (DBT)** — linking your bank account for government subsidies

## Important Tips

1. **Always verify before large transfers** — A wrong IFSC code can bounce your transaction or send money to the wrong branch.

2. **Check for merger updates** — If your bank merged recently (e.g., Syndicate Bank → Canara Bank), your old IFSC code may no longer work. Contact your branch for the new code.

3. **The 5th character is always 0** — If someone gives you an IFSC code where the 5th character isn't zero, it's invalid.

4. **IFSC code ≠ MICR code** — These are different. IFSC is 11 alphanumeric characters; MICR is a 9-digit numeric code used for cheque processing.

5. **IFSC codes can change** — When branches relocate, merge, or close, the IFSC code changes. Don't rely on old records.

6. **Use official sources only** — Avoid relying on third-party websites for IFSC lookup. Stick to RBI, NPCI, or your bank's official site.

7. **Save beneficiary details** — Once you verify an IFSC code, save the beneficiary in your net banking to avoid re-entering it each time.

## Frequently Asked Questions (FAQs)

### Is IFSC code the same for all branches of a bank?

**No.** Each branch has a unique IFSC code. Even two branches of SBI in the same city will have different IFSC codes.

### Can I do a fund transfer without an IFSC code?

For **NEFT and RTGS**, the IFSC code is mandatory. For **UPI** transfers using a UPI ID (e.g., name@upi), you don't need to enter the IFSC code manually — it's resolved automatically. For **IMPS** via mobile number + MMID, IFSC is not required.

### What happens if I enter a wrong IFSC code?

The transaction will either **fail and bounce back** to your account (usually within 24–48 hours) or get routed to the wrong branch. If the account number doesn't match at the destination branch, the amount is typically reversed.

### Do IFSC codes change after bank mergers?

**Yes.** After mergers like Andhra Bank into Union Bank or Syndicate Bank into Canara Bank, old IFSC codes were retired and new ones were issued. Banks usually give a transition period, but you should update your records promptly.

### How can I find the IFSC code if I only know the branch name?

Use the RBI website or your bank's branch locator. Search by state → district → branch name to find the exact IFSC code.

### Is IFSC code required for UPI payments?

Not directly. When you link your bank account to a UPI app, the app fetches the IFSC code automatically based on your account number and linked mobile number. You don't need to enter it manually.

### Are IFSC codes used for international transfers?

**No.** IFSC codes are for domestic transfers within India only. For international wire transfers (remittances), you need the bank's **SWIFT/BIC code** instead.
