# Canara Bank Mobile Banking Not Working? (2026 Fix)

**Canara ai1** is Canara Bank's official mobile banking app (formerly called Canara mPay / Canara Mobile Banking). If the app is not working, crashing, showing login errors, or OTP is not arriving — this guide covers the most effective fixes.

> **Quick check:** Call **1800-425-0018** (toll-free 24×7) or check @Canara_Bank on Twitter/X for server outage updates before troubleshooting your phone.

---

## Common Canara ai1 App Issues

| Issue | Likely Cause |
|-------|-------------|
| Login failed / wrong MPIN | Wrong PIN; account locked |
| OTP not received | Network problem; wrong registered number |
| App not opening / black screen | Old app version; cache issue |
| Biometric not working | OS update changed permissions |
| Transaction failed | Server down; wrong UPI PIN |
| App crash on launch | Storage full; incompatible app version |
| "Service unavailable" error | Canara server maintenance |

## Fixes — Try in Order

### Fix 1: Check Canara Bank Server Status

- Call **1800-425-0018** — will announce if there's a downtime
- Check Twitter/X: @Canara_Bank or search "Canara ai1 down"
- Check [downdetector.in](https://downdetector.in) → "Canara Bank"
- Canara typically maintains servers on Sunday nights — avoid then

### Fix 2: Update Canara ai1 App

1. Open **Google Play Store** or **App Store**
2. Search **"Canara ai1"**
3. Tap **Update** if available
4. Reopen app

> Canara Bank periodically forces upgrades. An outdated app will show "Please update" and block login.

### Fix 3: Clear App Cache (Android)

1. **Settings → Apps → Canara ai1**
2. Tap **Storage → Clear Cache**
3. Relaunch the app
4. Try logging in again

> On iPhone: uninstall Canara ai1 and reinstall from App Store.

### Fix 4: OTP Not Received — Fixes

- Verify your **registered mobile number** is active and has SMS
- Disable **DND (Do Not Disturb)** mode on phone
- Wait 5 minutes — Canara OTP can be delayed during peak hours
- Check if SMS inbox is full (delete old messages)
- If number changed: call **1800-425-0018** to update before logging in

### Fix 5: Reset Transaction / Login MPIN

**If MPIN is forgotten or wrong:**

1. On login screen → tap **"Forgot MPIN"** or **"Reset PIN"**
2. Enter debit card number, ATM PIN, and OTP
3. Set new MPIN

**Via Canara Net Banking:**
1. Login to [canarabank.com](https://canarabank.com) → Internet Banking
2. Go to **Services → Mobile Banking → Reset MPIN**

### Fix 6: Re-enable Biometric

1. Open Canara ai1 → **Settings → Profile**
2. Disable fingerprint/biometric login
3. Log in with MPIN manually
4. Re-enable biometric and re-register fingerprint

### Fix 7: Network Switch

- Switch from Wi-Fi to **mobile data** (or vice versa)
- Disable VPN before opening banking apps
- If on corporate Wi-Fi with firewall, switch to personal network

### Fix 8: Reinstall Canara ai1

1. Uninstall Canara ai1 completely
2. Restart phone
3. Reinstall from Play Store / App Store
4. Re-register with your Customer ID, debit card, and OTP

## Frequently Asked Questions

### Canara ai1 shows "User not registered" — what does that mean?

Your mobile number may not be registered for mobile banking, or you're logging into the wrong app. Ensure you're using **Canara ai1** (not an older deprecated Canara app). Call **1800-425-0018** to verify registration.

### Why does Canara ai1 say "Transaction limit exceeded"?

Canara Bank has daily transaction limits: ₹10 lakh for NEFT/RTGS, ₹1 lakh for IMPS per transaction. If you've hit the daily limit, wait until midnight for limits to reset or visit the branch for higher-value transfers.

### Canara Bank balance check without app?

**Missed call balance:** Call **09015483483** from your registered mobile number — receive SMS with account balance.
