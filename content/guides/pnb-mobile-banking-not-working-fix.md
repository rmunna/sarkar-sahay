# PNB Mobile Banking (PNB One) Not Working? (2026 Fix)

**PNB One** is Punjab National Bank's all-in-one mobile banking app. It replaced the older PNB mBanking and PNB mPassbook apps. If PNB One is not opening, login is failing, or OTP isn't arriving — try these fixes in order.

> **Quick check:** PNB server outages are common during heavy-load periods. Call **1800-180-2222** (toll-free) or check @PNBIndia on Twitter/X before blaming your device.

---

## Common PNB One App Issues

| Issue | Likely Cause |
|-------|-------------|
| Login failed | Wrong password or MPIN; account locked |
| OTP not received | Network issue; SIM not active |
| App not loading / black screen | Outdated version; cache corrupted |
| Biometric login not working | Permission revoked; fingerprint changed |
| Transaction failed / declined | Server issue; wrong UPI PIN |
| "Server not reachable" error | PNB maintenance or outage |
| App keeps crashing | Old Android/iOS; storage issue |

## Fixes — Try in Order

### Fix 1: Check PNB Server Status

- Search "PNB One down" or "PNB bank not working" on Twitter/X
- Visit [downdetector.in](https://downdetector.in) → search "Punjab National Bank"
- Call **1800-180-2222** — automated message announces outages
- PNB often does maintenance late night / early Sunday mornings

### Fix 2: Update PNB One App

1. Open **Google Play Store** or **App Store**
2. Search **"PNB One"**
3. Tap **Update** if pending
4. Relaunch app after update

> PNB One forces updates frequently for security compliance. Keep the app updated to avoid lockouts.

### Fix 3: Clear Cache (Android)

1. **Settings → Apps → PNB One**
2. Tap **Storage → Clear Cache**
3. Do NOT tap **Clear Data** (will remove login details)
4. Reopen PNB One

> On iOS: Uninstall and reinstall PNB One from App Store.

### Fix 4: OTP Not Coming — Fixes

- Ensure your **Aadhaar-linked/registered mobile number** is active
- Check SMS inbox for old OTP (sometimes arrives delayed)
- Disable **DND** or message filtering apps temporarily
- Switch to a **different network** (if on poor signal)
- If number changed: visit PNB branch to update before app login

### Fix 5: Reset Login Password / MPIN

**Forgotten MPIN:**
1. Tap **"Forgot MPIN"** on PNB One login screen
2. Enter your **Debit Card number + Expiry + CVV** (or ATM PIN)
3. Enter OTP sent to registered number
4. Set new 6-digit MPIN

**Via PNB Internet Banking:**
1. Log in at [netpnb.com](https://netpnb.com)
2. Go to **Service Request → Mobile Banking → Reset MPIN**

### Fix 6: Fix Biometric Login

1. Open PNB One → **Settings → Security / Biometric**
2. **Turn off** fingerprint/Face ID
3. Log in with MPIN once
4. **Re-enable biometric** → re-register fingerprint

### Fix 7: Network / VPN Fix

- Turn off Wi-Fi → use **4G/5G mobile data**
- Disable VPN or proxy before opening PNB One
- Switch from private network to personal hotspot

### Fix 8: Reinstall PNB One

If all else fails:
1. **Uninstall** PNB One
2. Restart phone
3. **Reinstall** from Play Store / App Store
4. Re-register: Customer ID + Debit Card + OTP + new MPIN

## Frequently Asked Questions

### PNB One shows "Customer ID not found" — why?

Ensure you're entering the full **11-digit Customer ID** (printed on your passbook or welcome letter) — not your account number. If the error persists, call **1800-180-2222**.

### My PNB One transaction failed but money was deducted — what to do?

**Do not retry immediately.** Check your account statement:
- If deducted but not credited to recipient → wait 30 minutes for auto-reversal
- If not reversed in 3 days → call **1800-180-2222** with transaction date and amount

### Can I use PNB One without internet?

Basic features like **SMS banking** (balance check, mini statement) work without internet via SMS. Send "BAL" to 5607040 from your registered number.
