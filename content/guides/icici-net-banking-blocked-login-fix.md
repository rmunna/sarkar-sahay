# ICICI Bank Net Banking Blocked or Login Failed? Fix (2026)

ICICI Bank internet banking (icicibank.com) locks after **3 consecutive wrong login or transaction password attempts**. Reset is quick — usually done in under 5 minutes via OTP verification.

---

## Common Causes of ICICI Net Banking Block

| Cause | Fix |
|-------|-----|
| Wrong password 3 times | Reset via "Forgot Password" |
| Wrong transaction password (6-digit) | Reset separately |
| User ID not remembered | Retrieve via account number + mobile |
| New device login | Email OTP confirmation needed |
| Security flag by bank | Call 1800-1080 |

---

## Method 1: Reset ICICI Net Banking Password Online

1. Go to **[icicibank.com](https://www.icicibank.com)**
2. Click **"Login"** (top right) → **"Forgot Password"**
3. Enter your **User ID** (Customer ID — found on passbook/account statement)
4. Enter: Date of birth + Country
5. Choose: OTP on registered mobile
6. Enter OTP → Set new login password
7. **Timeline:** 2–5 minutes, instantly active

---

## Method 2: Via iMobile Pay App

1. Open **iMobile Pay**
2. If you're logged into iMobile: **Profile → Manage → Internet Banking**
3. Select **"Reset Net Banking Password"**
4. OTP on registered mobile → New password set

---

## Method 3: Forgot ICICI User ID

1. **icicibank.com** → Login → **"Forgot User ID"**
2. Enter: Account number + Date of birth
3. OTP on registered mobile → User ID displayed + emailed

---

## Method 4: Reset ICICI Transaction Password

ICICI has 2 passwords:
- **Login password:** To access net banking
- **Transaction password (6-digit):** For all financial transactions

Reset transaction password:
1. Login to ICICI net banking
2. **"My Profile" → "Security Settings" → "Change Transaction Password"**
3. If forgotten: **"Forgot Transaction Password"** → OTP → Set new

---

## ICICI Net Banking OTP Not Received

1. Wait 2 minutes → **"Resend OTP"**
2. Check registered mobile is active
3. Verify your registered mobile: Call 1800-1080 → ask for registered number
4. If mobile number changed: Visit branch with Aadhaar to update mobile

---

## ICICI Net Banking Locked (Security Block)

If ICICI's security system has blocked your account:
1. Call **1800-1080** (24/7)
2. Say: "My ICICI net banking is locked. I need it unlocked."
3. Identity verified via registered mobile OTP + account details
4. Unlocked in 15–30 minutes

## Frequently Asked Questions

**What is ICICI Bank User ID?**
ICICI's User ID is a self-chosen ID you created during net banking registration. If forgotten, retrieve via "Forgot User ID" on the login page.

**ICICI iMobile works but net banking login fails — why?**
iMobile app login uses a separate app PIN/biometric. Net banking uses a different password. Reset net banking password separately — it won't affect iMobile login.

**Can I reset ICICI net banking without OTP?**
Not fully online. You need OTP to your registered mobile. If mobile is changed: Visit branch with Aadhaar to update mobile, then reset password.
