# IRCTC Forgot User ID or Password? Reset & Recover Account

Forgetting your IRCTC User ID or password is a common problem, especially if you don't book trains frequently. IRCTC provides multiple recovery methods using your registered email, mobile number, and security questions. This guide covers all recovery methods step by step.

## Part 1: How to Recover Forgotten IRCTC User ID

### Method 1: Recover User ID Using Registered Email

1. Go to [IRCTC login page](https://www.irctc.co.in/)
2. Click on **"Forgot User ID?"** link below the login form
3. Select **"Retrieve through Email"**
4. Enter your **registered email address**
5. Complete the **captcha**
6. Click **Submit**
7. IRCTC will send your User ID to your registered email
8. Check your **inbox, spam, and promotions folder**

### Method 2: Recover User ID Using Registered Mobile

1. Go to IRCTC login page
2. Click on **"Forgot User ID?"**
3. Select **"Retrieve through SMS"** or **"Retrieve through Mobile"**
4. Enter your **registered mobile number**
5. Complete the captcha
6. Click **Submit**
7. IRCTC will send your User ID via SMS to your registered number

### Method 3: Check Your Email Inbox

If you've booked tickets before, search your email for:
- **"IRCTC"** in the search bar
- Look for old booking confirmation emails
- Your User ID is mentioned in every IRCTC booking email

### Method 4: Contact IRCTC Customer Care

If you don't have access to your registered email or mobile:

1. Email **care@irctc.co.in** with subject: **"Request to Retrieve IRCTC User ID"**
2. Include:
   - Your **full name** as registered on IRCTC
   - **Date of birth**
   - **Registered email** (even if you don't have access)
   - **Registered mobile number**
   - **Aadhaar/PAN number** for verification
   - Any **old PNR numbers** from previous bookings
3. IRCTC care will verify your identity and share your User ID

## Part 2: How to Reset Forgotten IRCTC Password

### Method 1: Reset Password via OTP

1. Go to [IRCTC login page](https://www.irctc.co.in/)
2. Click on **"Forgot Password?"** link
3. Enter your **IRCTC User ID**
4. Complete the captcha
5. Choose OTP verification method — **Email** or **Mobile**
6. Click **Submit**
7. Enter the **OTP** received on your email/mobile
8. Create a **new password** following these rules:
   - Minimum 8 characters
   - At least 1 uppercase letter
   - At least 1 lowercase letter
   - At least 1 number
   - At least 1 special character (@, #, $, etc.)
9. Confirm the new password
10. Click **Submit** — your password is now reset

### Method 2: Reset Password via Security Question

1. Go to IRCTC login page
2. Click **"Forgot Password?"**
3. Enter your User ID
4. If the security question option is available, select it
5. Answer your **security question** correctly (set during registration)
6. If the answer matches, you'll be allowed to set a new password

> **Note:** Security question reset may not be available for all accounts. OTP-based reset is the recommended method.

### Method 3: Reset Password via PNR

If you have a recently booked PNR number:

1. Some IRCTC recovery flows may allow verification using a **valid PNR** linked to your account
2. This is not always available but worth trying if OTP methods fail
3. Contact IRCTC care with your PNR details for manual password reset assistance

## What If You Don't Have Access to Registered Email or Mobile?

This is the most difficult scenario. Here's what to do:

1. **Email care@irctc.co.in** with a detailed request:
   - Subject: **"Password Reset — No Access to Registered Email/Mobile"**
   - Include your User ID, full name, date of birth
   - Attach **Aadhaar card and PAN card** copies for identity verification
   - Mention your **old mobile number and email** (even if inaccessible)
   - Provide any **old PNR numbers** for account verification
   - Request them to update your mobile/email and reset password

2. **Call 14646** and explain the situation — the agent may help update your contact details

3. **Visit a Railway Reservation Counter** (major stations) with your Aadhaar card for in-person verification (limited availability)

## How to Avoid Losing IRCTC Credentials Again

1. **Save your User ID** in a password manager (Google Password Manager, Bitwarden, etc.)
2. **Use a memorable but strong password** — combine words with numbers and symbols
3. **Keep your registered mobile and email updated** — this is crucial for recovery
4. **Set an easy-to-remember security question** — but don't use publicly known answers
5. **Enable browser auto-fill** — Let your browser save the IRCTC login credentials securely
6. **Note down your User ID** in a safe place after registration

## Important Tips

1. **IRCTC User ID is case-sensitive** — Try both lowercase and uppercase versions
2. **One account per Aadhaar** — Don't create a new account if you can recover the old one
3. **Password changes are immediate** — You can log in with the new password right away
4. **Keep old PNR numbers** — They serve as proof of account ownership during recovery
5. **Update contact details regularly** — If you change your phone number, update it on IRCTC immediately

## Frequently Asked Questions

### How do I find my IRCTC User ID if I forgot it?

Go to the IRCTC login page and click "Forgot User ID?" You can retrieve it via your registered email or mobile number. IRCTC will send your User ID to the registered contact. You can also search your email inbox for old IRCTC booking confirmations.

### Can I reset my IRCTC password without OTP?

You can try the security question method if available for your account. Otherwise, OTP verification (via email or mobile) is mandatory for password reset. If you don't have access to either, contact care@irctc.co.in for manual reset.

### Is IRCTC User ID the same as the email address?

No. Your IRCTC User ID is a unique username you chose during registration (e.g., "rajesh123"). It is separate from your email address, though your email is linked to the account for recovery purposes.

### I forgot both my User ID and password — what to do?

First recover your User ID using the "Forgot User ID" option with your registered email/mobile. Once you have the User ID, use "Forgot Password" to reset your password. If you've lost access to both email and mobile, contact care@irctc.co.in with identity proof.

### How often can I reset my IRCTC password?

There is no strict limit on password resets, but IRCTC may temporarily block reset attempts if too many are made in a short period. Wait at least 30 minutes between repeated attempts.

### Can I change my IRCTC User ID?

No, IRCTC does not allow changing the User ID. It is permanent and set during registration. If you don't like your current User ID, you would need to create a new account (with a different email and mobile number) — but this means losing your old booking history.
