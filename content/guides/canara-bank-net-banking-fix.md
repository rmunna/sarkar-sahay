# Canara Bank Net Banking Not Working? How to Fix Login Errors

Canara Bank provides internet banking and the CANDI mobile app for digital transactions. Many users face issues with login failures, forgotten credentials, OTP problems, and session timeouts. This guide covers all common Canara Bank net banking errors and how to resolve them.

## Common Canara Bank Net Banking Problems & Fixes

### 1. Canara Bank User ID & Registration Issues

**How to Register for Canara Bank Net Banking:**
1. Visit [Canara Bank Net Banking](https://netbanking.canarabank.in/)
2. Click **"New User? Click Here"**
3. Enter your **Account Number**, **Registered Mobile Number**, and **Customer ID**
4. Verify via **OTP**
5. Set **User ID**, **Login Password**, and **Transaction Password**
6. Log in with your new credentials

**Forgot User ID:**
1. Visit the net banking login page
2. Click **"Forgot User ID"**
3. Enter account number and registered mobile number
4. Your User ID will be sent via SMS

**Customer ID Not Known?**
- Check your **passbook first page** — Customer ID is printed there
- Or visit your branch with ID proof to retrieve it

---

### 2. Canara Bank Password Issues

**Forgot Login Password:**
1. Go to [Canara Bank Net Banking](https://netbanking.canarabank.in/)
2. Click **"Forgot Login Password"**
3. Enter **User ID** and **Account Number**
4. Verify with OTP on registered mobile
5. Create new password following the rules below

**Password Requirements:**
- 8-20 characters
- At least one uppercase, one lowercase, one number, one special character
- Cannot reuse last 3 passwords
- Must be changed every 90 days (system enforced)

**Transaction Password Reset:**
- Log in → Go to **Administration → Change Transaction Password**
- If locked, use "Forgot Transaction Password" from login page
- Verify with OTP + debit card details

---

### 3. Canara Bank OTP Not Received

**Step-by-step troubleshooting:**

1. **Verify registered mobile:** Ensure the mobile number linked to your account is correct
2. **Check network signal:** OTP requires active mobile network (not just Wi-Fi)
3. **Wait 3-5 minutes:** OTP delivery can be delayed during high traffic
4. **Click "Resend OTP"** after waiting at least 60 seconds
5. **Check message filters:** Ensure Canara Bank sender IDs are not blocked
6. **Disable DND:** Send **START** to **1909** from your registered number
7. **SIM/port issue:** If recently ported, visit branch to update mobile number records

**Alternative:** Some operations support **email OTP** — check if this option is available on the verification screen.

---

### 4. Session Timeout Error

Canara Bank net banking sessions expire after **5 minutes of inactivity**.

**How to Avoid Session Timeout:**
- Complete your transaction without long pauses
- Don't open multiple net banking tabs
- Don't use the browser back button — use the portal's navigation
- Ensure stable internet connection throughout

**"Session Expired" After Login:**
- Clear browser cookies and cache
- Try a different browser (Chrome, Firefox recommended)
- Disable browser extensions that may interfere
- Ensure your system clock is set to the correct time and timezone

**Persistent Session Issues:**
- Try **incognito/private browsing** mode
- Disable pop-up blockers for the banking site
- If using corporate network, check if the firewall blocks banking sites

---

### 5. CANDI App (Canara Bank Mobile Banking) Issues

CANDI is Canara Bank's official mobile banking app.

**App Not Working / Crashing:**
1. Update CANDI from [Google Play Store](https://play.google.com/store/apps/details?id=com.canarabank.mobility) or App Store
2. Clear app cache: Settings → Apps → CANDI → Clear Cache
3. Ensure at least 200MB free storage
4. Restart your phone
5. Reinstall if crashes persist

**CANDI Login Failed:**
- Use correct **MPIN** (set during registration)
- If MPIN forgotten: Tap **"Forgot MPIN"** → verify with debit card + OTP → set new MPIN
- After 3 wrong attempts, MPIN is locked for 24 hours

**CANDI Device Registration:**
- App works on one device at a time
- New device: Install → Register as existing user → OTP + debit card verification
- If device binding fails, visit branch to de-register and start fresh

**CANDI Transactions Not Going Through:**
- Check daily transaction limits
- Ensure beneficiary cooling period (24 hours for new beneficiaries) has passed
- Verify sufficient balance including minimum balance
- Try during non-peak hours if server is slow

## Frequently Asked Questions

### Q1. How do I activate Canara Bank net banking?
Visit your branch with your passbook and ID proof to get your Customer ID and initial credentials. Then register online at netbanking.canarabank.in. Alternatively, use the CANDI app to self-register with your debit card details.

### Q2. Why is Canara Bank net banking showing "Invalid Credentials"?
You may be entering the wrong User ID or password. Use "Forgot User ID" or "Forgot Password" to recover. After 3 wrong attempts, your profile gets locked for 24 hours.

### Q3. Canara Bank OTP not coming — what to do?
Ensure your registered mobile has network signal, wait 3-5 minutes, and try resending. Check DND settings by sending START to 1909. If nothing works, call 1800-425-0018.

### Q4. How do I reset my CANDI app MPIN?
Open CANDI → tap "Forgot MPIN" → enter registered mobile number → verify with debit card details and OTP → set new MPIN.

### Q5. Can I use Canara Bank net banking on my mobile phone?
Yes, you can access net banking via mobile browser at the same URL. However, the CANDI app is recommended for a better mobile experience with MPIN-based quick login.

### Q6. My Canara Bank account shows as inactive on net banking. What do I do?
If your account is dormant/inactive, net banking access is restricted. Visit your branch with KYC documents to reactivate. See our [dormant account reactivation guide](/guide/bank-account-dormant-inactive-reactivate) for details.

### Q7. Is Canara Bank net banking available 24/7?
Yes, except during scheduled maintenance windows (usually 11:00 PM – 1:00 AM). Some services like NEFT operate in batches during specific hours, though IMPS and UPI work 24/7.
