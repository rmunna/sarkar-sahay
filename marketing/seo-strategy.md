## 3. Broken Link Building Opportunities (12+)

### Strategy
Indian government websites frequently go down, change URLs, or reorganize. Find pages linking to broken government URLs and offer CitizenNest guides as replacements.

### Known Broken/Problematic Government URLs to Target
| # | Broken/Problematic URL | What It Was | CitizenNest Replacement Guide |
|---|----------------------|-------------|-------------------------------|
| 1 | aaplesarkar.mahaonline.gov.in (frequent downtime) | Maharashtra citizen services | /guides/aaple-sarkar-portal |
| 2 | serviceonline.gov.in (old URLs) | Various state services | Relevant state guide |
| 3 | edistrict.up.nic.in (old format) | UP e-District services | /guides/up-e-district |
| 4 | meeseva.gov.in (Telangana, old URLs) | Telangana services | /guides/meeseva-portal |
| 5 | edistrict.delhigovt.nic.in (old) | Delhi e-District | /guides/delhi-e-district |
| 6 | rtps.bihar.gov.in (downtime) | Bihar RTPS services | /guides/bihar-rtps |
| 7 | emitra.rajasthan.gov.in (old URLs) | Rajasthan eMitra | /guides/emitra-rajasthan |
| 8 | serviceonline.bihar.gov.in | Bihar services | Relevant Bihar guide |
| 9 | csc.gov.in (old structure) | Common Service Centers | /guides/csc-locator |
| 10 | sarathi.parivahan.gov.in (old) | Driving license services | /guides/driving-licence-online |
| 11 | umang.gov.in (specific service pages) | UMANG app services | /guides/umang-app |
| 12 | digilocker.gov.in (old help pages) | DigiLocker | /guides/digilocker |

### How to Find Pages Linking to These
Use these Google search operators:
```
inurl:aaplesarkar.mahaonline.gov.in -site:mahaonline.gov.in
"aaplesarkar.mahaonline.gov.in" -site:gov.in
"edistrict" "not working" OR "down" OR "alternative"
"government service" "page not found" india
"meeseva" "link broken" OR "moved" OR "not available"
```

### Outreach Template
```

Best,
```

## 6. Technical SEO Checklist

### Core Web Vitals & Performance
- [ ] Run Lighthouse audit — target 90+ on all metrics
- [ ] Optimize LCP (Largest Contentful Paint) < 2.5s
- [ ] Minimize CLS (Cumulative Layout Shift) < 0.1
- [ ] Enable image lazy loading on all guide pages
- [ ] Serve images in WebP/AVIF format
- [ ] Implement preconnect for external resources (fonts, analytics)
- [ ] Review and minimize JavaScript bundle size

### Indexing & Crawlability
- [ ] Submit XML sitemap to Google Search Console (sitemap.xml)
- [ ] Submit XML sitemap to Bing Webmaster Tools
- [ ] Verify robots.txt is not blocking important pages
- [ ] Check for crawl errors in Search Console weekly
- [ ] Ensure all guide pages return 200 status codes
- [ ] Set up proper 301 redirects for any changed URLs
- [ ] Implement canonical URLs on all pages

### On-Page SEO
- [ ] Every guide has unique title tag (< 60 chars) with primary keyword
- [ ] Every guide has unique meta description (< 160 chars) with CTA
- [ ] Use proper heading hierarchy (H1 → H2 → H3) on all pages
- [ ] Add internal links between related guides (minimum 3 per guide)
- [ ] Optimize image alt text with descriptive keywords
- [ ] Add breadcrumb navigation with BreadcrumbList schema
- [ ] Ensure mobile-friendly layout on all pages

### Structured Data (Schema.org)
- [ ] HowTo schema on step-by-step guides
- [ ] FAQPage schema on FAQ sections
- [ ] Article schema on all guide pages
- [ ] BreadcrumbList schema for navigation
- [ ] WebSite schema with SearchAction (sitelinks search box)
- [ ] Organization schema on homepage
- [ ] Validate all schema with Google Rich Results Test

### Content & Keywords
- [ ] Create keyword map — assign primary + secondary keywords per guide
- [ ] Add FAQ section to every guide (targets People Also Ask)
- [ ] Create state-wise landing pages (e.g., /maharashtra, /delhi, /karnataka)
- [ ] Add "Last Updated" dates on all guides (freshness signal)
- [ ] Create comparison pages (e.g., "Aaple Sarkar vs CSC — Which to Use?")
- [ ] Target long-tail keywords in Hindi + English (transliterated queries)

### Local & Regional SEO
- [ ] Create Google Business Profile
- [ ] Target "near me" queries with CSC/office locator content
- [ ] Add hreflang tags if creating Hindi/regional language versions
- [ ] Create location-specific pages for major cities

### Link Profile & Authority
- [ ] Set up Google Search Console and monitor backlinks
- [ ] Disavow any spam backlinks
- [ ] Monitor brand mentions (set up Google Alerts for "citizennest")
- [ ] Track referring domains monthly

### Security & Technical
- [ ] Verify SSL certificate is valid and auto-renewing
- [ ] Ensure all pages load over HTTPS (no mixed content)
- [ ] Implement security headers (CSP, X-Frame-Options, etc.)
- [ ] Set up proper 404 page with search and popular guides

### Analytics & Monitoring
- [ ] Google Analytics 4 set up with conversion tracking
- [ ] Google Search Console verified and monitored
- [ ] Set up Bing Webmaster Tools
- [ ] Track keyword rankings weekly (use free tools like Ubersuggest)
- [ ] Monitor Core Web Vitals monthly
- [ ] Set up uptime monitoring (UptimeRobot — free)
