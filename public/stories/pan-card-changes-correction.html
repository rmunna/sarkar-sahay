What Can Be Changed?

• Name correction or update

• Date of birth correction

• Father's name correction

• Address update

• Photo and signature update

• Gender correction

Online Process — NSDL

• Visit onlineservices.nsdl.com

• Select 'Changes or Correction in PAN data'

• Fill Form for PAN Change Request

• Upload supporting documents

• Pay ₹107 (Indian address) or ₹1,017 (foreign)

Online Process — UTIITSL

• Visit pan.utiitsl.com

• Select 'PAN Card Correction/Change'

• Fill application with correct details

• Upload scanned documents

• Pay fee and submit

Documents for Name Change

• Gazette notification (for name change)

• Marriage certificate (for women)

• Passport with updated name

• Aadhaar with correct name

• Affidavit + newspaper publication

Track & Receive

• Track status on respective portal

• Enter acknowledgment number

• Processing takes 15–20 working days

• New PAN card delivered via post

• Download e-PAN from incometax.gov.in
