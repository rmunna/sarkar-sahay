mAadhaar App - Complete Guide

Use mAadhaar app to carry Aadhaar on phone, share via QR, lock biometrics, and update details easily.

What is mAadhaar?

• Official UIDAI mobile app

• Carry Aadhaar on your smartphone

• Available on Android and iOS

• Acts as valid Aadhaar proof

Key Features

• View and share Aadhaar profile

• Show QR code for verification

• Lock/unlock biometrics

• Generate VID and TOTP

How to Set Up

• Download from Play Store/App Store

• Enter Aadhaar number

• Verify with OTP on registered mobile

• Set 4-digit PIN for security

Share Aadhaar Safely

• Generate VID (Virtual ID) for sharing

• Use QR code instead of number

• Lock biometrics when not in use

• TOTP replaces OTP for authentication

Additional Services

• Check Aadhaar update status

• Locate nearest enrollment center

• View Aadhaar authentication history

• Raise grievance directly from app
