Types of Connections

• Domestic (residential) — most common

• Commercial (shops, offices)

• Industrial (factories)

• Agricultural (farm, pump sets)

• Temporary (construction, events)

How to Apply

• Visit state electricity board website

• Register and fill online application

• Select load requirement (1kW–5kW for homes)

• Upload required documents

• Pay application fee online

Documents Required

• Identity proof (Aadhaar, Voter ID)

• Address/ownership proof

• Property tax receipt or sale deed

• Passport size photograph

• NOC from landlord (if rented)

Fees & Charges

• Application fee: ₹100–500 (varies by state)

• Security deposit: ₹500–2,000

• Meter cost: Included or separate

• Total: ₹1,000–5,000 approximately

• Connection within 7–30 days of approval

After Getting Connection

• Note your consumer number

• Register on state discom portal

• Set up auto-pay for electricity bills

• Report outages on helpline

• Apply for load enhancement if needed later
