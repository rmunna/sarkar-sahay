## PM Surya Ghar Consolidation

Canonical pillar:

- `/guide/pm-surya-ghar-muft-bijli`

Redirected to canonical:

- `/guide/pm-surya-ghar-muft-bijli-yojana-solar`
- `/guide/pm-surya-ghar-solar-apply`
- `/guide/pm-surya-ghar-solar-rooftop`
- `/guide/solar-rooftop-subsidy-apply`
- `/guide/electricity-solar-rooftop-subsidy`
- `/guide/national-solar-rooftop-subsidy-residential`

Why: all six duplicates target the same core intent: PM Surya Ghar apply, rooftop solar subsidy, free electricity, eligibility and subsidy amount. Keeping all of them indexable splits internal links, sitemap entries and future official updates.

## Internal Linking Rule

For each cluster:

- Link broad mentions to the canonical pillar.
- Link specific troubleshooting intent to the specific support page.
- Do not create a new guide for an official update if an existing canonical pillar can absorb a "Latest Official Update" row.
- Create state-level pages only when state implementation details differ and official state evidence exists.
